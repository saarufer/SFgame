# 地形

| 地形 | 代码 | 开阔度 | 守方地利 | 说明 |
|---|---|---|---|---|
| 平原 / 灌区 | plain | 1.0 | 无 | 骑兵施展得开 |
| 草原 / 沙碛 | steppe | 1.0 | 无 | 骑兵最得势 |
| 河岸 / 渡口 | river | 0.5 | ×1.1 | 渡河冲击要减速，冲劲打折 |
| 林地 | forest | 0.4 | ×1.05 | 骑兵冲不起来，弓弩视线受阻 |
| 山地 | mountain | 0.3 | ×1.15 | 骑兵冲不起来 |
| 隘口 | pass | 0.2 | ×1.25 | 正面狭窄，守方最占便宜 |
| 城池 | city | 0.2 | 见下 | 守城步兵、弓弩 ×1.5，攻城骑兵 ×0.6，另加城防 |

- **开阔度**决定败方被追杀的程度：越开阔，胜方骑兵越能追。
- **守方地利**只加给守方的步兵和弓弩；山地、林地、隘口里，守方骑兵用不上地利（河岸照给）。
- 城池的城防值（0 到 100）让守方再乘 (1 + 城防/200)，每回合围城可以降低城防，详见 combat.md。守城一方自动算作“严整”，弓弩自动有掩护。
- 骑兵对步兵的系数按地形不同，见 combat.md 的“骑兵对步兵系数”表。
- 地形代码也可以写中文：平原、草原、沙碛、河、渡口、林、山、山地、隘口、关隘、城、城池。

亲临指挥的仗，地形按格子细分（河、林、高地、营垒），见 `rules/tactics.md`。
