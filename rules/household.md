# 家宅与家人

主角有母亲、妻妾、儿女、弟妹。他们各过各的日子，各有心愿，也会记事。
帅府的大事会落到家里：妹妹的婚事可以换来一门盟约，弟弟可以领一支兵，妻子的娘家能递上话，几个儿子长大了会有人站队。
家里的事也会走到帅府：被冷落的人会走远，被逼着出嫁的人会另有打算，敌方会盯着后宅。

几条底线：

- **家事不直接改兵马钱粮。** 家事牵到主线，都要走规则：联姻改势力态度一档、结亲改将领的账、喜事丧事的用度走 `economy.py --extra-cost`。
- **每一条怨气都有来处。** 家人的心结和将领一样，有时间、有事由、有强度。卡上没写的，不算数。
- **大事先问本人。** 议亲、为质、远行，GM 先召 kin agent 问本人的意思，再照“愿意 / 勉强 / 不愿”记账。
- **家人只知道家里能知道的事。** 战争迷雾和将领一样。

本文的例子取自唐末朔方剧本，标作“例（唐末朔方）”。剧本的 `scenario.json` 里 `newgame.family.enabled` 为 `false` 时，这一局没有主角的家宅，前八节的步骤都不用。
宫中、某个大族这样的别的家宅，见第九节。

## 一、家宅存档：`world/household.json`

由 `scripts/household.py` 读写，`vignette.py --family` 读取。开局模板在 `scenarios/<剧本>/world/household.json`，`/newgame` 会按玩家的回答重写。
纪年（第 1 回合是哪一年、年号怎么写）读 `world/scenario.json` 的 `start` 和 `calendar`；旧存档的 `household.json` 里自带 `calendar` 的，以它为准。

例（唐末朔方）：

```json
{
  "protagonist": {"name": "韩逊", "born": 865, "sex": "男", "card": "characters/han-xun.md", "where": "灵州"},
  "members": {
    "ayiguli": {"name": "阿依古丽", "relation": "妻", "sex": "女", "born": 877, "residence": "灵州·帅府后宅",
                "health": "健朗", "closeness": "亲近", "busy": "教女儿回鹘话", "card": "characters/kin-ayiguli.md",
                "status": "在", "spouse": "韩逊", "mother": null, "father": null, "line": "",
                "last_seen_turn": 1, "neglect_limit": 3, "milestones": {}, "deferred": {}, "trait": "一句性情"}
  },
  "heir": null, "budget": {"tier": "常"}, "rules": {"cap_peace": 2, "cap_war": 1, "cap_away": 1},
  "pregnancies": [], "plans": [], "events": [], "visits": [], "pending_triggers": {}, "last_season_turn": 0
}
```

| 字段 | 说明 |
|---|---|
| born | 公元生年，公元前写负数。年纪不存，按回合推算**虚岁**：生年算一岁，每年春天长一岁。第 1 回合的年份是 `scenario.json` 的 `start.year`（例（唐末朔方）：902 年，天复二年春） |
| relation | 母、父、妻、妾、子、女、弟、妹、兄、姊、弟妇、妹夫、侄、侄女…… |
| residence | `地区·去处`，例（唐末朔方）：`灵州·帅府后宅`、`盐州·周府`。地区名决定“在不在身边” |
| health | 健朗 / 小恙 / 多病 / 病重；亡故的 status 写“亡” |
| closeness | 亲疏。有家人卡的，以卡上的“亲疏”为准，`season` 会同步过来；没卡的（襁褓里的孩子、弟妇）由 GM 手填 |
| status | 在 / 出嫁 / 为质 / 被掳 / 离去 / 亡 |
| line | 子女的嫡庶：嫡（正妻所出）/ 庶 |
| last_seen_turn | 主角最后一次陪伴或写信的回合，冷落从这里算 |
| neglect_limit | 几季不见就记心结。默认：妻妾、子女 3，母亲、弟妹 4，出嫁、为质在外的 8 |
| milestones | 已过的人生节点和定下的走向；`deferred` 是缓议到第几回合 |
| heir | 嗣子的名字 |
| budget | 家中用度档位（第六节）。平日用度已经含在帅府开支里，不另扣 |
| plans | 约好的婚期等事，到期 `season` 会提醒 |
| events | 喜事、丧事、病、其他 |
| visits | 每季的家事记录（陪伴、家书） |
| pending_triggers | 议亲、为质、废立时脚本记下的触发事件，下一次 `season` 用掉 |

**家人卡**：`characters/kin-<拼音>.md`，模板 `characters/_template_kin.md`。孩子满六岁（启蒙）前不建卡，只在 `household.json` 里记一句性情。
家人卡也带十一项属性、特长、短处、识人、伤势（`rules/people.md`）：照性情填，孩子照身份表“少年”“孩童”一行取个大概，长大了 GM 每年重写近况时顺手调。
弟妇、妹夫这样的姻亲，平常只记在 `household.json` 里；他要在家事或主线里拿主意了，再建卡。

**主角卡**：`characters/<拼音>.md`，模板 `characters/_template_protagonist.md`。主角由玩家扮演，不跑账本，卡上只记背景、性格、执念、记忆，给 GM 和别的角色作参照。

## 二、家人的人心账本与亲疏阶梯

家人卡的账本和将领卡格式相同（需求、心结），用 `loyalty.py need / grudge / ease` 改。不同的地方：

- **需求换成家里的说法**，每人两三项，例如：
  - 妻：被敬重、子女前程、母族体面
  - 弟：建功立业、被兄长当回事
  - 妹：嫁个好人家，或者不想被当筹码
  - 子：被父亲看见
  - 母：一家和睦、儿孙平安
- **没有“开价”，改记“牵扯”**：外头的人对他的拉拢、离间、许诺（`household.py tie`）。来自母族、敌方、意中人、朝中某一派都算。
- **心结多一种外传途径：`家中可闻`**。乳母、仆妇、管家会说起，玩家经家里人听到。

### 亲疏阶梯

四级：**亲近 → 疏淡 → 怨怼 → 另有打算**。

为什么不沿用将领的六级：家人不是部将，没有“投敌”这一说，也没有兵可以带走。家人走远，是心里先淡下来，再有了怨，最后各自盘算：
妻子转向娘家，弟弟另立门户，妹妹自作主张，儿子投向某一派。将领阶梯里“留后路”“暗通”“举事”三级，在家里分不出那么细，合成一级“另有打算”；
举兵这件事，只有领了兵的兄弟才做得到，那时他改走将领的阶梯（第五节）。

每季末（`household.py season`）：

```
疏离分 = 未解心结总强度 + 需求缺口（Σ 权重 × (3 − 满足) ÷ 3）
```

| 疏离分 | 账面级别 |
|---|---|
| 小于 4 | 亲近 |
| 4–6 | 疏淡 |
| 6–8 | 怨怼 |
| 8 以上 | 另有打算 |

分档比将领高一分：家里的心愿多是长年的事（女儿没定亲、儿子还没长大），落空一两项是常态，不该一开局就冷下来。

封顶：

- 没有未解的心结：最多“疏淡”。光是心愿落空，人会冷淡，说不出怨谁。
- 有心结：最多“怨怼”。
- 未解心结 ≥ 3，**并且**外头有牵扯，或本季出了触发事件：才能到“另有打算”。

每季最多走一级，近一级远一级都一样。心结消了、心愿补上了、牵扯撤了，就一季近一级。

触发事件（`--trigger id=事件`；议亲、为质、立嗣时脚本会自动记下）：

| 事件 | 说明 |
|---|---|
| 逼婚 | 不顾本人不愿，定下或办了婚事。从定亲到成婚那一季，`season` 每季自动带上 |
| 送质 | 不顾本人不愿，送去别家为质 |
| 至亲受害 | 因主角之过，他的至亲（子女、母族、配偶）被囚、被杀、被逐 |
| 废立 | 已有的名分被夺：嫡子被废、正妻被降、许下的嗣位改给别人 |
| 当众羞辱 | 当着外人、下人的面被斥骂、责打 |

### 每一级能做什么、看得见什么

| 级别 | 行动上限（kin agent 不能超出） | 可观察的迹象（GM 经家里人透露） |
|---|---|---|
| 亲近 | 说心里话，替主角在家里周旋、在外头说好话；娘家来信拿给主角看 | 没有异样 |
| 疏淡 | 话少，不主动开口；家事照办，不多操心 | 请安答得规矩；不再来书房；不再问主角的意思 |
| 怨怼 | 顶撞、哭闹、冷脸、托病，向娘家、兄弟、乳母诉苦；不合意的安排拖着不办。不和外人密谋 | 当着下人冷脸；乳母说夜里哭过；托病不见；往娘家的信使勤了 |
| 另有打算 | 私下和外头往来，给自己安排后路（私蓄、私定终身、结交将领），逃婚、出家、回娘家；有人拉拢时可以递消息。不行刺、不举兵 | 生面孔出入后宅；首饰细软往外挪；和某位将领、某家走得近；打听出城的路，或忽然肯答应原先不肯的事 |

**理由校验**和将领一样（`rules/loyalty.md` 第七节）：kin agent 要做“另有打算”一级的事，“私下盘算”里得引用未解的心结编号，说清外头是谁（牵扯）或本季出了什么事（触发）。
行动超出级别、引用不成立的，GM 驳回，改按这一级能做的最高一档结算，驳回记进 GM 备注。

## 三、陪伴与冷落

主角每季可以做一两件家事：陪母亲说话、教儿子射箭、听妻子说娘家的事、给远嫁的妹妹写信。

- **不占帅府亲裁的限额**（`rules/governance.md` 第六节），但每季有上限：太平季 2 件，战事季 1 件，主角出征在外 1 件（只能写家书，或陪同在军中的家人）。上限可在 `household.json` 的 `rules` 里改。
- 每一件用 `household.py visit` 记下。人在身边的叫**陪伴**，不在身边的写**家书**（`--letter`）。

**冷落**：

- 有家人卡、满六岁的人，连续 `neglect_limit` 季没见（没有陪伴、没有家书），季末记一条心结：强度 1，外传“家中可闻”，事由“已经三季没来看过她”，末尾带“冷落”。
- 再过同样长的时间还不见，这条心结加深到强度 2。冷落最多到 2；要到 3，得是真伤了人的事。
- 还差一季到期时，`season` 和 `show` 会提醒“再一季不见就记心结”。
- 没有卡的人（襁褓里的孩子、姻亲）只提醒，不记心结；写家事小景时可以用上（“已经三季没见过幼子，他见了生人一样往乳母身后躲”）。

**陪伴怎么消解**：

| 做法 | 效果 |
|---|---|
| 陪伴或家书 | 冷落计时归零，冷落的心结不再加深 |
| 用心陪伴（`--earnest`） | 冷落的心结强度 −1，同一人同一季只算一次。“用心”是说做的事对上了这个人的心愿：教想被父亲看见的儿子射箭、听妻子说娘家的难处、替妹妹回绝一门她不想要的亲。GM 判断，写明依据 |
| 用心陪伴正对上一项需求 | GM 可另用 `loyalty.py need` 把那项需求上调一档 |
| 家书 | 消不了心结，只能让它不再加深 |
| 时间 | 和将领一样：强度 1 的四季没人再提就淡忘，强度 2 的八季降为 1 |

别的心结（婚事、为质、继承）用 `loyalty.py ease` 照 `rules/loyalty.md` 第三节消解：抵消、补偿、道歉（当面认错，同一条一次）。

## 四、成长与时间

`household.py season` 每季推进一次，打印到点的事，GM 写成家事交给玩家定。

### 人生节点

| 节点 | 谁 | 虚岁 | 可选的走向（脚本会列出） |
|---|---|---|---|
| 启蒙 | 子女、弟妹 | 6–8 | 请塾师；送寺学；由母亲教母族的话；再缓一年 |
| 习武 | 子女、弟妹 | 9–12 | 主角亲自教；交给一位将领带；入亲军少年营；偏重读书 |
| 及笄 | 女 | 15–16 | 在家行礼；大办；从母族风俗 |
| 从仕 | 男 | 16–18 | 授牙内职；随军出征；读书应举或入朝；留在身边 |
| 冠礼 | 男 | 20–21 | 请将领或幕僚做宾；主角亲自加冠；简办 |
| 议亲 | 未婚的子女、弟妹 | 女 14、男 16 起 | 联姻；结亲（部将家）；本地大族；本人自择；暂缓 |
| 成婚 | 定了亲的 | 婚期 | 用度三档（第六节） |
| 立嗣 | 两个以上儿子、长子满 12 | — | 嫡长；择贤；暂不立 |

- 节点到点那一季列出全部走向，以后每季只提一句“仍待定”，直到定下或缓议。定了走向用 `milestone id 节点 --choice …` 记下；不想定的 `--defer 季数`，到时再提。
- 走向牵到将领、母族的（例（唐末朔方）：“交给薛崇带”“请周延嗣做宾”），按第五节记账：那位将领和这个孩子结下情分，GM 在将领卡的记忆里记一笔，日后立嗣、站队时用得上；第一次可以给那位将领“被信任 / 被重用”一类需求 +1。
- 孩子启蒙时建家人卡。卡上的需求从“被父亲看见”“被母亲护着”这类起步。

### 添丁

- 正妻、侧室 16–40 岁，和丈夫同住一州，上一个孩子出生满一年：每季 12% 有孕；这一季主角陪过她，再加 12%。弟妇等同理，看她丈夫在不在。
- 脚本只提示，GM 用 `pregnant id` 记下。三季后临盆，`season` 掷男女和顺逆：平安 85%；难产 12%（母子都保住，产妇身体差一档，`birth … --hard`）；凶险 3%（GM 写成家事交给玩家）。
- 出生用 `birth 母亲id --id … --name … --sex …` 记下。正妻所出为嫡，侧室所出为庶。

### 身体

- 50 岁以上：每季有 (年纪 − 45)% 的机会身体差一档，最多 40%。
- 6 岁以下：每季 5% 病一场。其余：2%。
- 小恙下季 60% 自愈；多病在 60 岁以下每季 10% 好转（请了名医 25%）。
- 病重：每季有凶险，25% 加上 60 岁以上每多一岁 1%，最多 60%；孩子 20%。请名医（`--care id`）降一成。熬过来的 15% 转为多病。
- 脚本掷出“亡故”只是提示，GM 确认后 `set id status=亡`。丧事见第六节，生平记进 `world/history.json`，人格卡移到 `archive/`。

## 五、家事与主线

### 联姻

- 妹妹、女儿、弟弟、儿子都可以拿来联姻。议亲前，GM 召 kin agent 问本人，按回答记 `match … --consent 愿意|勉强|不愿`：

| 本人意思 | 记账 |
|---|---|
| 愿意 | 不记心结。“嫁个好人家 / 婚事”一类需求按这门亲合不合心意改为 0–3（`--fit`，GM 依 kin agent 的回答定）；“不被当筹码”一类需求 ≥ 2（问过她了） |
| 勉强 | 心结 1“点了头，心里不情愿”，家中可闻；婚事需求按 `--fit`，默认 1 |
| 不愿 | 心结 3“不顾她不愿”，家中可闻；婚事、筹码一类需求降到 0；从定亲到成婚那一季，每季末都带触发事件“逼婚” |

愿意的不记心结，只记一条记忆。这是她自己点的头，日后过得不好，怨的是夫家；但嫁出去以后照旧会被冷落，冷落照记（出嫁的期限 8 季，家书算数）。
不愿记强度 3：婚姻是一辈子的事，本人明说了不愿还被许出去，在她心里和将领被夺兵权一样重。

- **对主线的好处**：成婚那一季，对方势力的态度上调一档（GM 改 `factions.json`）。盟约稳不稳，看嫁过去的人和主角的亲疏：
  - 亲近：会替娘家说话，夫家要动娘家的主意，她会递信回来；
  - 疏淡：不帮也不害；
  - 怨怼：娘家的事不管，夫家问起，她照实说；
  - 另有打算：可能帮夫家打娘家的主意，把她知道的家事、城里的事告诉夫家。
- **结亲**（许给部将或部将之子）：那位将领“被信任 / 被重用”一类需求 +1，或者抵消一条对得上的心结。将领的家眷和主角成了一家，GM 可把他卡上的“名分”或“家眷”相应调整，写明依据。
- **本地大族**：可有一次捐输，走 `economy.py --extra-income`，不超过帅府一季钱收入的一成。
- **自择**：政治上没有所得；本人的婚事需求另 +1。

### 兄弟带兵、做官

- 弟弟可以带兵，也可以做官。委任他统领一方或一支兵马时，把他的家人卡改成将领卡：`身份` 改为“将领”，补齐将领字段（模板里注释掉的那几行；统、武、智等属性卡上本来就有），部曲从 10 上下起。
  此后他照 `rules/loyalty.md` 走六级离心阶梯，委任时照 `rules/governance.md` 第五节涨部曲；家里的需求（被兄长当回事）照旧留在账本上，冷落照旧会记。
  改卡时，账本里加上 `### 开价`（写“无”），“牵扯”里还有效的拉拢，GM 照 `rules/loyalty.md` 第四节换算成开价记进去；将领卡不再保留“牵扯”一节。阶梯记录里记一行“改为将领卡，离心从安分起”。
- 兄弟的“名节”：投胡、投藩镇的损失照常；“自立”对兄弟来说就是取兄长而代之，按他的性子定，一般不低于 1。
- 兄弟的“家眷”：妻儿住在主公治所的，写“主公手里”。
- 做官（无兵）的弟弟仍是家人卡，官职写在基本信息里。他在帅府办事，可以当幕僚用（`directives.json` 的 staff），能力取卡上智和政里高的那一项，开局不超过 5。

### 妻子的母族

- 妻子的娘家是一门外交关系。妻子“亲近”时，娘家来信她会拿给主角看，主角托她写信，GM 可以让那一方的态度上调一档，或者带回一条情报；“怨怼”以下，她不肯写，或写了也只是家常。
- 娘家可能借她要东西（互市免税、借兵、要一块牧场）。答应了，“母族体面”上调；拒绝了，GM 视情记心结 1。
- 和娘家开战、扣娘家的人：妻子记心结 2，严重的（娘家人因主角而死）记 3 并带触发“至亲受害”。

### 继承

- 两个以上儿子、长子满 12 岁，`season` 会提醒立嗣。用 `heir id --why …` 立下：
  - 嫡长子以外被跳过的嫡子、年长的同母兄：心结 2“嗣位给了某某”；已经立过、又被改掉的：心结 3，并带触发“废立”。
  - 生了儿子却没被立的妻妾：心结 2。
  - 还没建卡的孩子，脚本只提示，日后建卡时写进心结。
- 将领站队：诸子启蒙、习武、冠礼时和哪位将领结下情分，GM 记在将领卡的记忆里。立嗣时，和落选那位有情分的将领，GM 可以记一条心结 1（“没有听他的话”），或者记一条牵扯在落选那位的卡上（“来自 某将｜所图 拥立”）。
- 不立嗣也是一种选择。几年不立，家里、军中会有人来问，GM 写成家事。
- 主角战死、伤重不治时谁接手、接手那一季怎么记账，见 `rules/contest.md` 第八节。

### 敌方盯上家人

ruler agent 的“收买”可以指向主角的家人。GM 按种类处理：

| 图谋 | 怎么结算 |
|---|---|
| 收买、离间 | 不掷骰子，记成牵扯（`tie`）。心结浅的，来人被打发走，多半还会告诉主角；心结 ≥ 3 的，才有“另有打算” |
| 绑架、行刺 | `plot id --kind 绑架|行刺 --by 谁 [--guard 0-2] [--seed N]` 掷一次：在帅府 10%，在别的州 20%，在路上或在别家 35%；行刺减半；看护每档 −5%，最低 2%。失手的四成败露，能审出主使 |

- 家人被掳：status 记“被掳”。对方会拿人谈条件，GM 用 ruler agent 开价。家人被掳不算主角之过，不记家人对主角的心结；主角不肯赎、不肯换，才按“至亲受害”记给他的至亲。
- 领兵的兄弟的妻儿被掳，照 `rules/loyalty.md` 改他卡上的“家眷”。

### 为质

`hostage id --to 势力 --consent …`：

| 本人意思 | 他本人 | 他的母亲、配偶 |
|---|---|---|
| 愿意 | 心结 1“被送去为质（自己答应的）” | 心结 1 |
| 勉强 | 心结 2 | 心结 2 |
| 不愿 | 心结 3，下一季带触发“送质” | 心结 2 |

对方手里有了玩家一方的人，态度可上调一档。为质的人在那边照旧跑账本：亲近的会替娘家说话，到了“另有打算”可能替对方递话。

## 七、家事小景

每季结算时，“见闻”之外加一段“家事”：

```
python3 scripts/vignette.py --family [--seed N] [--war] [--apply]
```

## 八、GM 每回合怎么做

1. **玩家下令时**：家事（“去陪母亲”“教洙儿射箭”“给妹妹写信”）用 `visit` 记，看上限；议亲、为质、立嗣，先召 kin agent 问本人，再用 `match`、`hostage`、`heir`。这几件大事算帅府亲裁的一件（人事），陪伴、家书不算。
2. **召见家人**：`household.py hint id` 拿亲疏提示，写进 kin agent 的 prompt，连同场景和主角原话。只给他家里能知道的事。
3. **结算之后、回合数 +1 之前**：`household.py season --when <本季> [--seed N] [--care id] [--trigger id=事件]`，看过再加 `--apply`。
   - 到点的节点、有孕、出生、病重，GM 写成家事，交给玩家定（下一季的命令里回）。
   - “可以经家里人透露的迹象”择一两条，写进汇报的家事里；心结和亲疏级别只进 GM 备注。
4. **家事小景**：`vignette.py --family`，依种子写，定稿后同一 seed 加 `--apply`。
5. **记账**：本季家里的事按第二、五节记（`loyalty.py need / grudge / ease`、`household.py tie`），重要的事追加到家人卡的“记忆”；每年一次重写“近况”。

## 九、别的家宅：宫中、大族

主角不是君主时，最要紧的那一家往往不是自己家：宫里的天子病了没有、哪位皇子得宠、外戚是谁。`household.py` 能管多个家宅：

- **主角家**照旧是 `world/household.json`（`--house main`，默认）。本文前八节说的都是它。
- **别的家宅**放在 `world/households/<名字>.json`，用 `--house <名字>` 指定，例如 `--house palace`。`kind` 写 `palace`（宫中）或 `clan`（某个大族）。
- `household.py houses` 列出所有家宅。

```json
{
  "kind": "palace", "title": "宫中", "head": "tianzi", "succession_issue": "立储",
  "members": {
    "tianzi": {"name": "李承", "relation": "天子", "sex": "男", "born": 899, "residence": "京城·大内", "health": "多病",
               "status": "在", "card": "characters/li-cheng.md",
               "illness": {"name": "风疾", "stage": 1, "stages": ["隐疾", "时发", "沉疴", "弥留"], "pace": 0.15,
                           "major_from": 2, "known_by": ["王太医", "崔皇后", "高力"], "secret": "S1", "log": []}},
    "huanghou": {"name": "崔皇后", "relation": "皇后", "sex": "女", "born": 912, "favor": 1, "clan": "崔氏", "…": "…"},
    "licong": {"name": "李琮", "relation": "皇子", "sex": "男", "born": 935, "mother": "xianfei", "line": "庶", "favor": 2,
               "card": "characters/li-cong.md", "milestones": {"冠礼": "开局前已过"}}
  },
  "heir": null,
  "clans": {"崔氏": {"head": "崔琰", "faction": "将门", "note": "皇后的母家"}},
  "pregnancies": [], "plans": [], "events": [], "last_season_turn": 0
}
```

| 字段 | 说明 |
|---|---|
| `head` | 家主（宫中是天子）。添丁看后妃在不在他身边；他的病重了，宫中就少有喜事 |
| `relation` | 宫里的称呼照家里的算：皇子、公主是子女；皇后是正妻（所出为嫡）；贵妃、淑妃、德妃、贤妃、妃、嫔、昭仪、婕妤、美人、才人等是侧室 |
| `favor` | 宠爱 0–3：失宠、平常、得宠、专宠。后妃、皇子、公主都可以有 |
| `clan` | 后妃的母家。`clans` 里写这一家的家主、在朝属哪一派（`court.json`） |
| `illness` | 病程（下面） |
| `succession_issue` | `court.json` 里立储那个议题的名字，储位形势从那里看各派拥立谁 |

别的家宅能用的命令：`show`、`season`、`add`、`set`、`event`、`pregnant`、`birth`、`milestone`、`match`、`tie`、`plot`、`heir`，外加 `illness`、`favor`。
`visit`、`hint`、`where` 只用于主角家：主角去宫里、去别家拜访，记识人（`persona.py know`）和关系（`relations.py`）。宫里的人用朝臣卡（`characters/_template_courtier.md`），由 `courtier` agent 扮演；他们的心迹由 `court.py season` 推进（`rules/court.md` 第七节），不走家人的亲疏阶梯。

### 季末：`household.py --house palace season`

1. **年纪**：春天各长一岁。
2. **病程**：有 `illness` 的人走病程，没有的照第四节的身体规则掷。
3. **添丁**：后妃 16–40 岁、在天子身边、天子没病到要 GM 确认的那一档：每季 3% + 4% × 宠爱（大族照主角家的 12%）。生育有功，宠爱 +1。
4. **宠爱**：列出来。宠爱不随季漂，只由事件改：`favor id --delta N --why …`，写明来由（侍疾、生子、母家获罪、被人告了一状）。外戚在朝有派系的，宠爱升降时 GM 可以给那一派的声量 ±1（`court.py faction … --voice-delta`）。
5. **人生节点**（宫中的表）：

   | 节点 | 谁 | 虚岁 | 走向 |
   |---|---|---|---|
   | 就学 | 皇子、公主 | 6–8 | 请一位大臣做师傅（记“师生”，那位大臣和他那一派从此和这位皇子连在一起）；宫中内学；缓一年 |
   | 习武 | 皇子 | 9–12 | 请禁军将领教骑射；只读书 |
   | 出阁 | 皇子 | 14–16 | 封王开府、出居宫外（有了僚属，能结交朝臣，离天子远了）；留在宫中 |
   | 冠礼 | 皇子 | 16–20 | 天子亲临加冠；照常例；简办 |
   | 及笄 | 公主 | 15–16 | 照常例；大办 |
   | 议亲 | 皇子 16、公主 14 起 | | 皇子：选妃于大族（添外戚）、选于小户、暂缓；公主：下嫁大族重臣之子、下嫁将门、暂缓 |

   大族（`clan`）用前面第四节的节点表。
6. **储位形势**（宫中）：每位皇子的年纪、嫡庶、母亲和他自己的宠爱、外戚和外戚在朝属哪一派、哪几派拥立他（`court.json` 立储议题里 `want` 写着他的）、名望、心迹。**不掷骰**，给 GM 掂量；储位未定、长皇子过了十二岁，提醒会有人上奏请立储。立储用 `heir id --why …`：落选的皇子里，嫡出被跳过的、比他年长的同出兄长记心结 2，原先立过又被废的记心结 3（季末 `court.py season --trigger 名=储位被夺`）；生了儿子却没被立的后妃记心结 2。落选皇子卡上“储位”一类需求，GM 照提示用 `loyalty.py need` 降到 0。朝中立储的议题改为已决，拥立落选皇子的那一派照 `court.py feud` 记积怨。

### 病程

天子（或哪位重臣、太后）的病，是一条暗线。`illness id --name 病名 [--stages a,b,c,d] [--pace 0.12] [--major 2] [--known-by 名,…] [--secret S1]` 建一条病程：

- 默认四档：隐疾、时发、沉疴、弥留。剧本可以写自己的（`--stages`）。
- 每季：

  ```
  加重的机会 = 底数（pace，默认 0.12） + 1% × (年纪 − 55，不小于 0) + 本季劳神动怒 15%（--strain id） − 请了名医 6%（--care id）
  好转的机会 = 8% + 请了名医 10%（只在第二档到倒数第二档之间）
  到了最后一档：每季凶险 35%，名医 −10%，劳神 +10%
  ```

- **重大转折要 GM 确认**：病到 `major_from`（默认第三档“沉疴”）以上的每一步、以及亡故，脚本只打印“待 GM 确认”和要跑的命令，不自动改。GM 看剧情需要确认（`illness id --stage N --apply`、`set id status=亡 --apply`），也可以缓一季、换个写法。较轻的那几步（隐疾 ↔ 时发）照掷骰的结果写回。
- 档位和身体对应：时发记“多病”，沉疴以上记“病重”。
- 病情多半是一条秘密（`secrets.json`，`--secret` 连上）：知情人是御医、贴身的宦官宫人、皇后。病程推到沉疴，GM 照提示调这条秘密的外象（`secrets.py expose`），泄露的机会跟着涨。

| 档 | 外头看得见的 | 哪些圈子可闻 |
|---|---|---|
| 隐疾 | 没有外象；只有御医和贴身的人知道 | — |
| 时发 | 隔些日子罢朝一两日，说是偶感风寒；医官进出勤了 | 宫中 |
| 沉疴 | 久不视朝，奏章由近臣代批；宫中有人私下议论后事 | 宫中、朝堂 |
| 弥留 | 宫门戒严，夜里召重臣入宫；各处的人都在打听宫里的消息 | 宫中、朝堂、市井 |

### 宫里的事，玩家怎么知道

玩家多半看不见宫里。GM 只经这几条路透露：

- **关系网**：玩家和宫里的人（宦官、宫人、外戚、皇子的僚属）有交情的，那人按自己知道的说（召他的 agent，带情报包）。
- **流言**：宫中的流言季末往朝堂、市井传（`rules/rumors.md`），玩家在哪个圈子就听到哪个圈子的。
- **秘密**：病情、宫闱的事登记成秘密，玩家得知了才知道（`secrets.py learn`），知道多少给多少。
- **看得见的外象**：季末 `season` 打印的“可以经旁人透露的迹象”只列外头看得见的（上表），GM 择一两条，从玩家熟的人嘴里带出来。
- **邸报和朝会**：立储、封王、选妃、丧事，定下来的是公开的。

不经这几条路，宫里的事不告诉玩家：宠爱的数字、储位形势、病程的档位，都只进 GM 备注。

## 十、例子（唐末朔方，草稿副本试验）

开局：韩逊三十八岁，将门之后；母亲卢氏，妻阿依古丽，子韩洙十二岁，女阿兰七岁，弟韩昭二十六岁（好勇），妹韩婉十八岁（有主见，未嫁）。

**冷落与陪伴**：头三季主角只陪了母亲、韩洙、阿依古丽、韩婉、韩昭各一两回，阿兰一次没见。第四季（天复二年冬）季末：

```
韩洙：3 季没见 → 记心结 [1]“已经三季没来看过他”强度 1（家中可闻）
阿兰：3 季没见 → 记心结 [1]“已经三季没来看过她”强度 1（家中可闻）
```

第五季主角带阿兰去马市挑了一匹小马（用心陪伴），又路过书房问了韩洙一句功课（普通陪伴）：

```
阿兰：冷落的心结 [1] 强度 1 → 0｜已解（天复三年春，带她去城外马市，挑了一匹枣红小马……）
韩洙：冷落的心结 [1] 不再加深；要消解，得用心陪
```

母亲卢氏一直没去看：第五季记心结 1，第九季（八季没见）加深到 2；冷落还在继续时，这条心结不随时间淡忘。

**妹妹的婚事**（第五季，先召 kin agent 问韩婉）：

| | 丰州天德军使次子（隔帘见过一面后问她） | 宥州李仁福长子（当着定难使者宣布） |
