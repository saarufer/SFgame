# 秘密与知情

有些事只有几个人知道：天子的病到了哪一步、户部的账短了多少、谁构陷了谁、某位将领和敌国通过信。
谁知道、知道多少、怎么知道的、证据在谁手里，记在 `world/secrets.json`，由 `scripts/secrets.py` 读写。

秘密会泄露：知情的人多了、嘴松了、证据放在外头，每季就有机会说漏，漏出去的变成流言（`rules/rumors.md`）。
秘密也能拿来要挟人。调用任何角色 agent 之前，GM 用 `secrets.py brief` 生成一份“此人知道什么”的情报包，只把这些传给 agent。

几条底线：

- **知道多少给多少。** 全知的人知道真相；只知大略的，细处不清；风闻的，只知道“背后有事”。
- **泄露掷骰子，要挟不掷。** 秘密传不传出去是小概率的事，按口风掷；被要挟的人怎么应，由他的 agent 按人格卡定。
- **战争迷雾的总闸。** 给 agent 的东西照情报包来：他知道的秘密、他听过的流言、他和在场之人的关系。别的不给。

本文的例子用一个中性的示例朝廷，标作“例（示例朝廷）”。和唐末朔方那样的剧本一样用：`world/gm_secrets.md` 仍是 GM 自己的笔记，要结算的秘密（会泄露、能要挟、要进情报包的）登记进 `secrets.json`。

## 一、存档：`world/secrets.json`

```json
{"id": "S1", "title": "天子病情", "truth": "天子患风疾，入秋后发作一次比一次重，王太医估计撑不过两年",
 "cover": "圣躬偶感风寒", "about": ["李承"], "danger": 3, "exposure": 0, "status": "隐",
 "knowers": [{"name": "王太医", "depth": "全知", "how": "亲历"}, {"name": "崔皇后", "depth": "大略", "how": "亲见"},
             {"name": "高力", "depth": "风闻", "how": "亲见"}],
 "evidence": [{"id": "E1", "kind": "账册", "desc": "御药房的脉案", "holder": "王太医", "status": "在"}],
 "rumor": null, "leak_log": [], "uses": []}
```

| 字段 | 说明 |
|---|---|
| `truth` / `cover` | 真相；外面的说法 |
| `about` | 说的是谁 |
| `danger` | 分量：1 传出去难堪，2 丢官、失宠，3 掉脑袋、动摇大位 |
| `exposure` | 外象 0–3：旁人从外面看得出多少端倪（病中久不视朝、账目对不上） |
| `knowers` | 知情人：`depth` 全知 / 大略 / 风闻，`how` 亲历 / 亲见 / 转述 / 推测 / 供状 / 书信，`from` 听谁说的；`knows`（可选）他知道的那一截——大略、风闻的人写了它，情报包照它给，不给全部真相 |
| `evidence` | 证据：书信、人证、物证、账册；`holder` 在谁手里；`status` 在 / 毁 / 失 / 呈上 |
| `status` | 隐 / 已泄 / 公开 / 作废 |
| `rumor` | 泄露后变成的流言编号 |
| `uses` | 拿它要挟过谁 |

## 二、登记、得知、证据

```
secrets.py add --title 题目 --truth 真相 [--cover 外面的说法] [--about 名] [--danger 1-3]
               --knower 名=全知|大略|风闻[:怎么知道的] … [--evidence 账册:描述@持有人 …]
secrets.py learn 编号 --who 名 --depth 大略 --how 转述 [--from 名] [--knows 他知道的那一截]
secrets.py evidence 编号 --add 书信:描述@持有人 | --move E2 --to 名 | --status E2=毁|失|呈上
secrets.py expose 编号 --level 0-3 --why …
```

- 什么时候登记：GM 写进 `gm_secrets.md` 的事里，要泄露、要拿来要挟、要进情报包的，就登记。开局的秘密由剧本写进 `secrets.json`。
- **得知**：有人告诉他、他自己撞见、审出了供状、读到了信。知道得更多的，往全知那边改，不往回改。
- 拿到证据的人，脚本算他知道了大略（可以用 `learn` 改）。
- **证据呈上**：摆到朝堂、定夺者面前。说这件事的流言可以坐实（`rumors.py confirm`），奏疏里算一件凭据（`court.py memorial --evidence`）。
- **外象**：病中罢朝、账上对不上、某人突然阔绰，旁人看得出端倪。每档每季泄露的机会 +5%。宫中的病程推到“沉疴”（`rules/household.md` 第九节），脚本会提醒把病情这条秘密的外象跟着调。

## 三、泄露：`secrets.py season`

每条“隐”着的秘密，每季掷一次。每个知情人说漏的机会：

```
口风 = 3% + 特长短处：嘴不严 12%，贪杯 6%，消息灵通 5%，能说会道 3%，好面子 2%
       智 ≥7 −1%，胆 ≤3 −1%（怕事）
风闻的 ×0.5；秘密说的就是他自己 ×0.3
他看秘密里说到的人（关系网）≥ 交好 ×0.5（护着他）；≤ 交恶 ×2（巴不得他出事）
秘密的分量：1 ×1.3，2 ×1，3 ×0.6（越要命的越不敢说）
每人夹在 0–40%
```

另外：每件“在”外头的证据 2%（书信 3%）；外象每档 5%。合起来：

```
泄露的机会 = 1 − Π(1 − 每一项)
```

掷中了，按各项的大小挑出是谁说漏的，生成一条流言：

| 说漏的人知道多少 | 流言的内容 | 可信 |
|---|---|---|
| 全知 | 真相 | 3 |
| 大略 | 真相（GM 可删细处） | 3 |
| 风闻 | 外面的说法，加一句“听说另有隐情” | 2 |

说漏的人手里有证据的，可信 +1。流言落在他所在的第一个圈子，热度 1（嘴不严、消息灵通的 2）。秘密改为“已泄”。
GM 可以改流言的措辞，再用 `rumors.py` 给它补名望的影响（`effects`）。

**故意说出去**（`leak 编号 --by 名 [--circle 圈子]`）不掷骰：谁、在哪个圈子说的，照写。被说的人知道是他说的，关系网里记一笔“背约”。

## 四、把柄：`secrets.py leverage`

`leverage 编号 --by 甲 --on 乙 --demand 要他做什么`

甲得知道这件事（风闻也算，只是分量轻）。分量：

```
分量 = 秘密的分量（1–3） + 甲手里有证据 1 + 甲全知 1 − 甲只是风闻 1 − 说的不是乙本人 1
```

乙怎么应，不掷骰：GM 召乙的 agent（`courtier`、`general`、`kin`），把甲的话、乙眼里的分量（甲有没有亮出证据）告诉他，按人格卡定：

- **从**：照办。
- **拖**：敷衍、讨价还价，看甲有没有真凭据。分量 ≤2 的多半会拖。
- **反制**：拿甲的把柄回敬（`secrets.py known 乙` 看乙知道甲什么）、先去定夺者面前自首。
- **灭口、毁证**：灭口走 `household.py plot` 一类的规矩；毁证用 `evidence --status Ex=毁`。

记账（`--apply`）：乙对甲记怨 2（两人知道），记进 `uses`；乙若还不在知情人里，算他知道了大略。另外：

| 乙是 | 怎么记 |
|---|---|
| 将领 | 要他背主的要挟，照 `rules/loyalty.md` 第四节记成开价（性命、家眷平安一类，按秘密的分量折算），照旧走算盘，不直接改离心 |
| 家人 | 记成牵扯：`household.py tie 乙 --from 甲 --aim … --promise 守住秘密` |
| 朝臣卡 | 记成牵扯（卡上“牵扯”一节），季末 `court.py season` 照心迹推进 |

## 五、情报包：`secrets.py brief`

**GM 调用任何角色 agent 之前**（`general`、`ruler`、`kin`、`courtier`），可以先跑：

```
python3 scripts/secrets.py brief 名 --with 在场的人,… [--json]
```

情报包只含这个人知道的：

| 一节 | 内容 |
|---|---|
| 身份 | 官职、派系、上司，平常在哪些圈子走动 |
| 他知道的秘密 | 按他知道的程度给（全知给真相，大略给大略，风闻只给外面的说法和“另有隐情”）；他手里的证据 |
| 他听到过的流言 | 他所在圈子里热度 ≥2 的（消息灵通的 ≥1），说到他的、他放出去的；附“听的人信几分”。**不给真假** |
| 他读过的文献 | 摘要；是否已禁 |
| 他和在场的人 | 他看对方的亲疏，他以为对方怎么看他（只算他知道的恩怨），他知道的关系标签（暗的标明“外人不知道”，不列别的知情人），他记着的恩怨，他知道对方记着他的恩怨；他眼里对方是个什么样的人（`persona.py impress`） |
| 朝中眼下的事 | 悬而未决的议题和他那一派的主张，待议的奏疏 |
| 朝中提示 | 心迹和行动上限、党争的上限、上司的器重（`court.py hint`）。他心里的事，不要原样说出来 |

GM 把它照原样或改写后写进 agent 的 prompt，再加上场景、主角原话、人心提示（将领）、亲疏提示（家人）。情报包里没有的，不给 agent。
`--json` 给结构化的版本，GM 想自己挑的时候用。

## 六、GM 怎么用

1. **有了秘密就登记**；有人得知，`learn`；证据转手，`evidence`。
2. **调 agent 前**：`brief`。
3. **季末**：`secrets.py season`，看过加 `--apply`；泄出去的流言会写进 `rumors.json`，同一季再跑 `rumors.py season`。
4. **玩家想打听、想拿把柄**：他知道的用 `known 主角` 看；派人打听，GM 照打听的门路（关系网、细作）决定他能知道多少（多半是风闻），`learn` 记下。

### 命令一览

```
python3 scripts/secrets.py add --title … --truth … [--cover …] [--about 名] [--danger 1-3] --knower 名=全知:亲历 … [--evidence 账册:描述@持有人 …] --apply
python3 scripts/secrets.py learn 编号 --who 名 --depth 全知|大略|风闻 [--how …] [--from 名] [--knows 他知道的那一截] --apply
python3 scripts/secrets.py evidence 编号 [--add 种类:描述@持有人] [--move E2 --to 名] [--status E2=毁|失|呈上] --apply
python3 scripts/secrets.py expose 编号 --level 0-3 --why … --apply
python3 scripts/secrets.py show [编号]
python3 scripts/secrets.py known 名
python3 scripts/secrets.py season [--seed N] --apply
python3 scripts/secrets.py leak 编号 --by 名 [--circle 圈子] --apply
python3 scripts/secrets.py leverage 编号 --by 甲 --on 乙 --demand … --apply
python3 scripts/secrets.py brief 名 [--with 在场的人,…] [--json]
```

所有命令都有 `--world 目录`。脚本名和 Python 标准库的 `secrets` 模块同名：`scripts/` 里的脚本不要 `import secrets` 去用标准库的那个。

## 七、例（示例朝廷，草稿副本试验）

S1 天子病情：王太医全知、崔皇后大略、宦官高力风闻（嘴不严、消息灵通），脉案在王太医手里。分量 3，每季泄露约 11%：

```
王太医 1.8%（3% × 0.6）  崔皇后 1.8%  高力 6%（(3%+12%+5%) × 0.5 × 0.6）  证据 E1 2%
```

天子病到“沉疴”、久不视朝以后，外象调到 2，每季泄露约 20%。
沈砚手里有东郡漕仓的出入簿（S2 的证据 E2），拿它要挟崔琰交出底账：分量 3（秘密的分量 2 + 手里有证据 1）；崔琰怎么应，召他的 agent 定。
