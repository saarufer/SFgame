# 人心账本

有兵权的将领和主要君主，各有一张人格卡（`characters/<名字>.md`，模板见 `characters/_template.md`）。
将领会不会离心，看卡上的“人心账本”：他想要什么（需求），心里记着哪几件事（心结），
外面有没有人出价（开价），出走划不划算（出走的算盘）。账本由 GM 依据存档和记忆来记，
数字由 `scripts/loyalty.py` 计算和写回。
本文的例子取自唐末朔方剧本（周延嗣、薛崇、李思谏、杜昶等），标作“例（唐末朔方）”；称谓照当前剧本 `world/scenario.json` 的 `terms` 换。

几条底线：

- 每一条怨气都有来处。卡上没写的怨气，不算数。
- 没有人出价，就走不到“暗通”。开价来自敌方 ruler agent 实际做的收买，或 GM 扮演的势力实际派来的人。
- 离心一季最多升一级，也可以降。走到“举事”，要上一季已在“暗通”、出走的算盘成立、这一季又出了触发事件。
- 骰子只管拖延、变通、超额执行这类日常小事，不决定暗通和叛变。

## 一、人格卡里有什么

### 数值块（yaml）

| 字段 | 范围 | 说明 |
|---|---|---|
| 统 / 武 / 智 等十一项属性 | 1–10 | 人物属性（统、武、智、骑、射、体、胆、辩、学、政、魅），连同特长、短处、性情、识人、伤势，写法见 `rules/people.md`。人心账本的公式不用它们；战斗、较量（`rules/contest.md`）、识人用 |
| 部曲 | 0–100 | 麾下兵马对他本人的私人依附。举事时大约这个比例的兵马跟他走。受委任统领一方时每季自动上涨，收回、轮换时往回扣（见 `rules/governance.md` 第五节） |
| 门槛 | 0–9 | 天性。出走的价值要比留下的价值**多出这么多**，他才会动念。重恩义、认死理的人高，自负才干、不把一家一姓看死的人低 |
| 名节 | 每种去处 0–5 | 天性。写成 `投胡4 投藩镇1 自立1 归朝廷0`。投到这种去处，他背上的名节损失 |
| 急进 | 0–3 | 天性。日常检定里“超额执行”的倾向 |
| 持重 | 0–3 | 天性。日常检定里“变通、保存实力”的倾向 |
| 家眷 | 随身 / 主公手里 / 对方手里 / 无 | 家人在哪里 |
| 名分 | 0–3 | 留下来名正言顺的程度。主公受朝命、自己官职正当是 2；主公被朝廷诏责、成了“逆臣”可降到 1 或 0；主公新得朝廷大封可到 3 |
| 离心 | 六级之一 | 安分 / 不满 / 怨言 / 留后路 / 暗通 / 举事。由 `season` 推进 |

君主只填 姓名、身份、属性（`rules/people.md`）、部曲。

**去处**四种。这四个词是引擎的分类，卡片和脚本里照写；各剧本里具体指什么，写在 `scenario.json` 的 `dest_labels`：

- `投胡`：投外族之主（中原以外、风俗不同的势力）。
- `投藩镇`：改投别的割据势力，或中央的权臣。
- `自立`：据城自守，或借外力取主公而代之。
- `归朝廷`：直接归附名义上的中央、受它的任命。

例（唐末朔方）：投胡是投契丹、党项、回鹘、吐蕃；投藩镇是改投朱全忠、李茂贞、晋王等；归朝廷是受唐廷之命。

### 天性与近况

- **天性**：一辈子不太会变的东西，比如谨慎、爱惜兵力、脾气急、一见某支宿敌的骑兵就冲动。写成具体的做事倾向，不写“有野心、会另找出路”这种结论。
- **近况**：GM **每年一次**，或者遇到重大事件（升降、大胜大败、家变、主从变更）之后，依据记忆重写两三句，写明重写的时间。写他眼下在意什么、怎么看自己的处境，例（唐末朔方）：“已在朔方安身，以宰执自许”。
- agent 按“近况”加“天性”行事。近况和开局时的描写冲突，按近况。

### 人心账本

卡片里 `## 人心账本` 一节，四个小节，每条占一行，字段用全角竖线“｜”分隔。例（唐末朔方）：

```
### 需求
- 权柄｜权重 3｜满足 1｜盐务被杜昶接管，盐利全失

### 心结
- [2] 天复二年夏｜杜昶来劳军，接管盐务，断我财路｜强度 2｜状态：未解｜外传：幕僚可闻｜已历 1 季

### 开价
- 来自 李思谏｜去处 自立｜所给 权柄=3,家眷平安=3,读书人被认可=1｜追杀 2｜接家眷 否｜时间 天复二年冬｜条件 盐利四成、许以联姻

### 阶梯记录
- 天复二年冬：留后路 → 暗通｜心结 6｜缺口 3.3｜留10/走17动念
```

可以手改，但多数时候用脚本改。

## 二、需求

每张将领卡列两三项**具体**的需求。例（唐末朔方）：

- 周延嗣：权柄、家眷平安、读书人被认可。
- 薛崇：替兄报仇、有仗可打、被重用。

**权重** 1–3：这件事在他心里有多重。
**满足** 0–3，由 GM 依据存档和记忆评定，写上依据：

| 满足 | 意思 | 例 |
|---|---|---|
| 0 | 完全落空 | 兵权被夺；家人被囚 |
| 1 | 差得远 | 财路被断；位在后进之下 |
| 2 | 大体过得去 | 独当一面，但上头还有人压着 |
| 3 | 称心 | 总管一方大政；家眷厚养、儿子在帅府任职 |

名称里带“家眷”的需求，算盘里按家眷处理（见第五节）。

满足度什么时候改：发生了改变处境的事（升迁、夺权、家眷迁移、仇人授首），GM 当季就用 `need` 改，写明依据。

## 三、心结

格式：`[编号] 时间｜事由｜强度｜状态｜外传｜已历 N 季`

**强度**：

| 强度 | 什么样的事 | 例 |
|---|---|---|
| 1 | 小委屈 | 大事没知会他；私下训诫；赏得比别人薄；被当面责问 |
| 2 | 实打实的损失或难堪 | 财路被断；派监军盯他；外人、降将、后进位在其上；当众斥责；调离旧部 |
| 3 | 伤筋动骨 | 被夺兵权；家眷因主公之过受害；主公在大事上失信；性命受威胁 |

**状态**只算“未解”。其余几种写明缘由：

- `已抵消（…）`：主公后来给的东西，正好补上了当初失去的。例：盐利被夺，后来让他总管盐铁。整条消掉。
- `已解（…）`：补偿或道歉把强度减到 0。
- `已淡忘（…）`：时间久了。
- `不计（…）`：事情还在，但不算在当前主公的账上，比如对旧主的怨、主从已经变了。

**怎么消解**（`ease` 命令）：

| 方式 | 效果 | 说明 |
|---|---|---|
| 抵消 | 整条消掉 | 补偿对上了这件事本身：夺了的兵权还回来、断了的财路换成更大的权柄 |
| 补偿 | 强度 −1 | 补偿沾边但不对等：厚赏、加官，却没还他失去的那样东西 |
| 道歉 | 强度 −1 | 主公当面认错、单独召见开解（“推心置腹”）。同一条心结只算一次 |
| 时间 | 自动 | 强度 1 的，满 4 季没人再提就淡忘；强度 2 的，满 8 季降为 1；强度 3 的不会自己消 |
| 加深 | 强度 +1，重新计时 | 同一件事又被触动：又让外人居上、又派人查他 |
| 不计 | 不再计入 | 主从关系变了 |

一件事算不算心结，看他自己当时怎么想（记忆里写着“平静接受”的，就不记）。
自己犯错受罚、事后也认了的，通常不记；记的话写强度 1。

**外传**：这条心结玩家可能通过谁听说。

- `幕僚可闻`：当众发生的、他发过牢骚的。幕僚议事、酒席上会有人提起。
- `细作可探`：私下的事，派细作、耳目才探得到。
- `家中可闻`：家人卡用（`rules/household.md`）。乳母、仆妇、管家会说起，玩家经家里人听到。
- `不外传`：只在他心里。

GM 不直接把账本告诉玩家，只在幕僚议事、细作回报里，按“外传”透露一两条，用白描的说法（“周将军那日酒后说，盐务的事他到今天还想不通”）。

### 针对某个人的心结

心结记在所事之人（主公）的账上，但有的心结同时是对一个具体的人的：例（唐末朔方）“杜昶接管盐务，断我财路”，账算在主公头上，人恨的是杜昶。
记的时候加 `--toward 杜昶`：卡上的心结末尾多一段“对 杜昶”，关系网（`world/relations.json`，`rules/relations.md`）里同时记一笔怨，强度相同，两边相连。
以后 `ease` 这条心结，关系网里那一笔跟着改。和主公无关的私怨（同僚当众羞辱、政敌弹劾），只记关系网，不记心结。

### 常见的事怎么记

旧的事件表不再加减数值。发生这些事时，按下表记账：

| 发生的事 | 记账 |
|---|---|
| 受赏、厚赏 | 有对应心结的：补偿 −1；没有的：不记 |
| 升迁、加兵、独当一面 | 相应需求（权柄、被重用）的满足度上调；对上了旧心结就“抵消” |
| 单独召见、推心置腹 | 道歉 −1（每条一次） |
| 家眷被救、被厚养 | 家眷需求上调；家眷改为“主公手里”的，同时改 `家眷` 字段 |
| 打了胜仗 | 有“有仗可打”“立功”一类需求的上调；部曲可由 GM 手改 +5 |
| 私下训诫、当面责问 | 心结 1 |
| 当众斥责、他人居上、派监军、查账、调离旧部、主公失信 | 心结 2 |
| 降职 | 心结 2，权柄需求下调 |
| 被夺兵权 | 心结 3，权柄需求下调，并且是触发事件 |
| 家眷因主公之过受害 | 心结 3，家眷需求降到 0，并且是触发事件 |
| 家眷为敌所害 | 不是对主公的心结；他对敌方的仇写进近况，或加一项“报仇”需求 |
| 敌方送礼、遣密使、许官 | 记成开价（见下节） |
| 朝廷诏责主公 / 加封主公 | 名分 −1 或 −2 / +1 |

## 四、开价

开价必须是真的：敌方 ruler agent 在“收买”字段里实际提出的，或者 GM 扮演的势力实际派人来谈的。
ruler 的收买写成结构化字段（见 `.claude/agents/ruler.md`），GM 据此记成开价：

- **来自**：谁开的价。
- **去处**：投胡 / 投藩镇 / 自立 / 归朝廷。
- **所给**：对**这位将领的每一项需求**，开价能满足到几分（0–3）。ruler 不知道对方的账本，它只说给什么（官职、钱帛、地盘、联姻、接家眷）；GM 对照将领的需求换算。没说到的需求按 0。
- **追杀**：0–3。出走后被原主公追杀、讨伐的可能。远投塞外 1；就地据城自立、和主公接壤 2；孤身逃往主公兵锋所及之处 3。
- **接家眷**：对方许诺接出家眷，而且确实有能力做到（有人在主公治所接应、有路可走），才写“是”。
- **条件**：开价原话摘要。

开价一直有效，直到对方撤回、被拒绝得很干脆，或者形势变了让它落空（对方败亡）。撤回用 `offer --withdraw`。
卡上只留最新的一条开价；同一季有两家开价，用 `reckon` 各试算一遍，记分数高的那家。

## 五、出走的算盘

```
留下 = Σ(权重 × 满足) + 名分 − 未解心结的总强度
出走 = Σ(权重 × 开价所给) − 风险
风险 = 家眷 + 追杀 + 名节[去处] − 部曲减免（不小于 0）
动念：出走 − 留下 > 门槛
```

部曲减免：去处为“自立”时，部曲 60 以上减 1，80 以上减 2。兵认他，据地自立的底气足。其他去处不减。

家眷一项：

| 家眷 | 风险 | 另外 |
|---|---|---|
| 随身 | 0 | |
| 主公手里，对方没许诺接出 | 2 | 名字带“家眷”的需求，开价所给一律按 0 |
| 主公手里，对方许诺并能接出 | 1 | |
| 对方手里 | 0 | 留下这边，家眷需求的满足度由 GM 调低 |
| 无 | 0 | |

心结算在“留下”这边：心里记着事，留下的好处就打了折扣。

没有开价，就没有“出走”这一项，算盘不成立。

## 六、离心阶梯

六级：**安分 → 不满 → 怨言 → 留后路 → 暗通 → 举事**。

每季末（`season` 命令）先算账面目标：

```
缺口 = Σ 权重 × (3 − 满足) ÷ 3
离心分 = 未解心结总强度 + 缺口
```

| 离心分 | 账面级别 |
|---|---|
| 小于 3 | 安分 |
| 3–5 | 不满 |
| 5–7 | 怨言 |
| 7 以上 | 留后路 |

再按心结封顶、按开价抬升：

- 未解心结为 0：最多“不满”。光是需求没满足，会不痛快，但说不出怨谁。
- 未解心结 1–2：最多“怨言”。
- 有开价、动念、未解心结 ≥ 3：目标“暗通”。
- 有开价、动念，但未解心结不足 3：目标最多“留后路”。
- 上一季已在“暗通”、本季仍然动念、本季出了触发事件：目标“举事”。

然后**每季最多升一级、降一级**。降级同理：心结消了、需求补上了、开价撤了，就一季降一级。

触发事件（`--trigger`）：

| 事件 | 说明 |
|---|---|
| 被夺兵权 | 收回兵马、派人接替、监军带兵入城夺他的城 |
| 性命之危 | 被拘审、将被问罪处死、遇刺，或确知主公要杀他 |
| 主公大败 | 主公主力新败，治所危急，自身难保 |
| 家眷受害 | 家人因主公之过被囚、被杀 |
| 接应已到 | 对方兵马已到城下，或约定的接应就在眼前 |

### 每一级能做什么、看得见什么

| 级别 | 行动上限（agent 不能超出） | 可观察的迹象（GM 经幕僚、斥候、细作透露） |
|---|---|---|
| 安分 | 按天性拖延、变通、超额执行；不和外人私下往来，敌方来使就上报或打发走 | 没有异样 |
| 不满 | 推诿、少出主意；牢骚不出门，不和外人往来 | 回禀简短；领赏谢得淡；不再多出主意 |
| 怨言 | 对旁人发牢骚、当面顶撞、讨价还价，命令不合意可以拖延打折扣；不收敌礼、不回敌信 | 酒后说主公偏心；议事顶撞；接令先要钱要人；部下跟着发牢骚 |
| 留后路 | 收礼不答复、不揭发来使、私蓄钱财、给家眷安排去处；不回信许诺，不透露军情 | 生面孔出入府邸；收礼不报；挪钱财、想搬家眷；对监军格外客气或格外提防 |
| 暗通 | 回信、讲条件、透露军情、放走敌方的人、遇敌不救；不举兵、不开城、不出奔 | 夜里有人出城；亲兵换防异常；俘虏被悄悄放走；遇敌不救；斥候在敌境见到他的信使；对入觐调防一再推托 |
| 举事 | 时机合适可以举兵、开城、出奔；去不去、怎么做，按天性和眼前形势自己定 | 关城门、杀监军、城头换旗；或者人连夜不见了 |

玩家看到迹象后可以对症处理：召见开解（道歉）、补上他失去的（抵消）、把家眷接来（家眷改为主公手里）、
派人盯着、调离、甚至先下手。这些都按本规则记账。

## 七、agent 的理由校验

general agent 每次都会收到它当前的**离心级别**、**出走的算盘**结果和**行动上限**（`season` 或 `show` 打印的那一句“人心提示”）。

agent 若想做“暗通”或“举事”一级的事（回信许诺、透露军情、放敌、开城、举兵、出奔），必须在“私下盘算”里：

1. 引用账本上的心结编号和事由，例（唐末朔方）：“[2] 杜昶断我财路、[4] 白守忠来盯我”；
2. 说明出走的算盘：谁开的价、给了什么、家眷怎么办。

GM 结算前核对：

- 行动有没有超出当前级别的上限？
- 引用的心结是不是卡上“未解”的那几条？
- `season` / `reckon` 算出来，是不是“动念”？

有一条不成立，就**驳回**：这件事按他这一级能做的最高一档结算（例如“安分”级想给敌方回信许诺，改成礼送来使出境、不回信；
“留后路”级想开城，改成闭门观望）。驳回记进 chronicle 的 GM 备注。这是要求事出有因，不是偏袒玩家：
理由成立的背叛，GM 照实结算；理由不成立的，同样照规则驳回。

agent 在自己级别以内的行动，GM 照实结算，不替玩家“纠正”。

## 八、日常小波动（骰子）

拖延、变通、超额执行、抗小命，这类日常行为还用骰子（`roll`）。派发军令前掷一次：

| 结果 | 概率（%） |
|---|---|
| 抗命 | (级别 − 1) × 4，级别从 0（安分）数起，最低 0 |
| 拖延 | 3 + 级别 × 5 |
| 变通 | 持重 × 5 + 级别 × 3 |
| 超额执行 | 急进 × 8 − 级别 × 3，最低 0 |
| 照办 | 其余 |

- `--risky`（命令凶险：强攻坚城、孤军深入、舍己救人）：抗命、拖延、变通 ×1.5。
- 前四项合计超过 90 时按比例压到 90。
- 这里的“抗命”只是对这一道命令推辞或改做别的，不是离心。骰子不会掷出暗通、叛变。

脚本打印一句“日常提示”，GM 写进 agent 的 prompt。这是倾向，agent 照性格和处境决定怎么做。

## 九、君主的账本

君主卡只记**需求**和**心结**：

- 需求：他想要的东西（盐池、部众归心、基业安稳……）。谈判、议和、收买时，GM 拿来衡量对方开的条件合不合他的意。
- 心结：他对玩家一方的仇怨，每一条都有来由。ruler agent 读了，自己决定记不记仇、怎么报。
- 君主不走离心阶梯，`season`、`reckon`、`roll` 只用于将领。君主的心结不会自动淡化，GM 按“消解”的办法手动处理（玩家遣使示好、归还俘虏，可算补偿或道歉）。
- 君主手下有兵权的大将，用将领卡，主公写这位君主。玩家收买敌将，同样按第四节记开价、走算盘。

## 十、GM 每回合怎么做

1. **派发前**：对每位有兵权的将领跑 `show`，把“人心提示”一句写进 general agent 的 prompt（离心级别、算盘、行动上限）；
   有军令的再跑一次 `roll`（凶险命令加 `--risky`），把“日常提示”也写进去。
2. **收到 agent 回复后**：按第七节核对，超出上限或理由不成立的驳回。
3. **敌方收买**：ruler 回复里有“收买”字段的，记成对方将领的开价（`offer … --apply`，或在季末 `season` 里一并给出）。
4. **结算后记账**：本季发生的事，按第三节的表，用 `grudge`、`ease`、`need`、`state` 记进去，先看输出，再加 `--apply`。
5. **季末推进**：每位有兵权的将领跑一次 `season --when <本季> [--trigger …]`，看过再加 `--apply`。
   把“可观察的迹象”和“玩家可能听说的心结”记进 chronicle 的 GM 备注，择一两条经幕僚、斥候透露给玩家。
6. **每年一次**（或大事之后）：重写各卡的“近况”。重要经历照旧追加到“记忆”。

### 命令一览

例（唐末朔方）：

```
python3 scripts/loyalty.py show   characters/zhou-yansi.md [--public]
python3 scripts/loyalty.py need   characters/zhou-yansi.md 权柄 1 --why "盐务被杜昶接管" --apply
python3 scripts/loyalty.py grudge characters/zhou-yansi.md --when 天复二年夏 --what "杜昶接管盐务，断我财路" --strength 2 --heard 幕僚可闻 [--toward 杜昶] --apply
python3 scripts/loyalty.py ease   characters/zhou-yansi.md 2 --by 抵消 --note "天祐八年冬总管盐铁" --apply
python3 scripts/loyalty.py offer  characters/zhou-yansi.md --from 李思谏 --dest 自立 --give 权柄=3,家眷平安=3,读书人被认可=1 --pursuit 2 --terms "盐利四成、联姻" --apply
python3 scripts/loyalty.py offer  characters/zhou-yansi.md --withdraw --apply
python3 scripts/loyalty.py reckon characters/zhou-yansi.md [开价参数]           # 试算，不写卡
python3 scripts/loyalty.py season characters/zhou-yansi.md --when 天复二年冬 [--trigger 被夺兵权] [开价参数] --apply
python3 scripts/loyalty.py state  characters/zhou-yansi.md --standing 0 --why "朝廷诏责朔方" --apply
python3 scripts/loyalty.py roll   characters/zhou-yansi.md [--risky] [--seed 7]
python3 scripts/loyalty.py corps  characters/zhou-yansi.md --delta 5 --why "大胜，弟兄们服他" --apply
```

`season` 会读 `world/directives.json`：这位将领正受委任统领一个方面，就按 `rules/governance.md` 第五节自动加部曲，
并打印涨幅的来由。试验时用 `--world 目录` 指向存档副本。部曲的其他变动（打了胜仗 +5 之类）用 `corps` 手改，会记进阶梯记录。

开价参数：`--from 谁 --dest 去处 --give 需求=满足,… [--pursuit 0-3] [--extract] [--offer-when 时间] [--terms 摘要]`。

`state` 用于 GM 直接改离心级别、家眷、名分，例如举事失败被擒、主从关系变了（例（唐末朔方）：`--level 安分 --why "北去契丹，主公改为耶律阿保机"`）。改动会记进阶梯记录。

## 十一、委任与人心

分层托管（`rules/governance.md`）和人心账本连在一起的地方：

- 受委任：“权柄”一类需求满足度 +1。
- 委任中：部曲每季上涨（第五节的表在 governance.md）。
- 收回、轮换：部曲往回扣；按期轮换不记心结，未满期轮换记心结 2，召回入朝权柄 −1（未满期另记心结 1），夺权记心结 3 并且是触发事件。
- 方面大将执行方针时的偏差（拖延、变通、超额执行、抗命）用本规则第八节的概率掷，路远再加；偏差本身不记心结。

## 十二、家人

主角的家人也用人格卡和账本（`characters/kin-*.md`），规则见 `rules/household.md`：需求换成家里的说法，外头的拉拢记成“牵扯”，
亲疏阶梯四级（亲近 → 疏淡 → 怨怼 → 另有打算），由 `scripts/household.py season` 推进。本脚本的 `need`、`grudge`、`ease` 可以直接用在家人卡上；
`season`、`offer`、`reckon`、`roll` 只用于将领。心结的外传多一种“家中可闻”。

没有兵权的朝臣——文臣、宦官、宫人、皇子、公主、后妃、外戚、宗室——用朝臣卡（`characters/_template_courtier.md`），账本记需求、心结、牵扯，心迹阶梯（恭谨 → 怠慢 → 怨望 → 异志）由 `scripts/court.py season` 推进，规则见 `rules/court.md` 第七节。
本脚本的 `need`、`grudge`、`ease` 一样用在朝臣卡上；`season`、`offer`、`reckon`、`roll` 只用于将领。朝臣手里有了兵，改成将领卡，照本规则走。

兄弟领了兵，家人卡改成将领卡，从此照本规则走：离心阶梯、开价、算盘、日常检定都和别的将领一样，家里的需求（被兄长当回事）留在账本上一起算。
他的妻儿住在主公治所的，“家眷”写“主公手里”。他对兄长的“名节·自立”按性子定，一般不低于 1。

## 十三、两个例子（唐末朔方）

**周延嗣，天复二年**（家眷随身在盐州，门槛 2，名节 自立1）：
夏季杜昶接管盐务（心结 2，权柄满足降到 1），秋季取丰州没知会他（心结 1），冬季派白守忠来做监军（心结 2）。
定难五次遣使，第五次开价盐利四成、许以联姻，前议助他取韩公而代之。
冬季算盘：留下 = 14 + 2 − 6 = 10，出走 = 20 − 2 = 18（风险：追杀 2 + 名节 1 − 部曲 75 减免 1），差 +8，动念。阶梯一路是 安分 → 不满 → 怨言 → 留后路 → 暗通，每季一级。
天复三年秋，监军带兵进了他的城（被夺兵权），上季已在暗通，算盘仍成立，可以举事。

**周延嗣，天祐十一年春**（总管使节、民政、盐铁，家眷在灵州厚养，儿子在节度府，旧心结都已抵消或淡忘）：
阿保机许他汉儿司总管、开国宰相。算盘：留下 = 22 + 2 − 0 = 24，出走 = 15 − 7（家眷 2、追杀 1、名节 4）= 8，差 −16，不动念。
离心分 0.7，停在“安分”。这一季他能做的，是婉拒、把马匹礼物报上来；给阿保机“留话头”超出了“安分”的上限，GM 驳回。
就算阿保机许诺接出家眷，出走也只有 18，仍然不动念。
