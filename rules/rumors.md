# 流言、名望与文献

话会传。宫里的一句闲话，几季后可能满城都在说；一本书里的一段旧事，可能被人拿来做文章；一个人在士林、军中、市井的名声，会跟着这些话起落。
流言和文献记在 `world/rumors.json`，名望记在每个人的人格卡或名册上，由 `scripts/rumors.py` 读写。

几条底线：

- **流言有真有假，GM 知道，传话的人不知道。** 每条流言记着真假和来源；agent、玩家只知道自己听到了什么、听的人信几分。
- **传得多远、信几分，都有数。** 每个圈子里的热度（0–5）、可信度（0–5），季末按规则扩散或消退，掷骰子；骰子只管传播这种小事。
- **流言改名望，名望改朝议和人心。** 传开了、多半信了，说到的人名望升降；名望进 `court.py` 的朝议计分，也是将领名分的一个由头。
- **文献是实物。** 一本书、一道檄文、一封信，谁手里有、哪些圈子读到过，都记着；它能生出流言，也能在辩论里被引用。

本文的例子用一个中性的示例朝廷，标作“例（示例朝廷）”。

## 一、圈子

消息在哪些人群里流传。剧本在 `rumors.json` 的 `circles` 里定（引擎有一套中性的默认值）：

| 圈子 | 口碑算进哪种名望 | 和别的圈子的往来（0–1） | 是谁 |
|---|---|---|---|
| 宫中 | — | 朝堂 0.5，市井 0.15 | 后妃、宫人、宦官、近侍 |
| 朝堂 | 士林 | 宫中 0.3，士林 0.6，市井 0.3，军中 0.25 | 在朝的官员 |
| 士林 | 士林 | 朝堂 0.5，市井 0.35 | 读书人、举子、在野的名士 |
| 市井 | 市井 | 士林 0.25，军中 0.3，朝堂 0.15 | 城里的百姓、商贩、酒肆茶坊 |
| 军中 | 军中 | 市井 0.3，朝堂 0.2，诸蕃 0.15 | 将校、士卒 |
| 诸蕃 | 诸蕃 | 军中 0.2，市井 0.1 | 外族、外藩、互市的胡商 |

往来是单向的（宫里的话传到朝堂容易，朝堂的话传进宫里难一些），剧本可以照自己的时代改：加“江南”“北地”“某国”，改往来的数。
例（第二部可能的写法）：把“诸蕃”拆成“契丹”“诸蕃”，加一个“江南”，市井改叫“长安市井”。

**谁在哪个圈子**：`rumors.json` 的 `members` 写明的为准（`{"沈砚": ["朝堂", "士林"]}`），再加上推得出来的：在朝有官的在朝堂，天子和宫中家宅里的人在宫中，将领卡的人在军中，朝臣卡按身份。

```json
{
  "version": 1,
  "fame_kinds": ["士林", "军中", "市井", "诸蕃"],
  "circles": {"宫中": {"fame": null, "links": {"朝堂": 0.5, "市井": 0.15}, "note": "后妃、宫人、宦官"}, "…": {}},
  "members": {"沈砚": ["朝堂", "士林"]},
  "rumors": [], "docs": [], "next": {"R": 1, "D": 1}, "last_season_turn": 0
}
```

## 二、流言

```json
{"id": "R1", "text": "户部的漕粮，三成进了崔家的仓", "truth": "真", "source": "刘晏", "about": ["崔琰"],
 "heat": {"市井": 2}, "cred": 2, "status": "流传", "effects": {"崔琰": {"士林": -1, "市井": -2}}, "applied": {},
 "since_turn": 1, "age": 0, "gm_note": "", "log": []}
```

| 字段 | 说明 |
|---|---|
| `truth` | 真 / 假 / 半真。只给 GM |
| `source` | 谁放出来的（“不明”也行）。只给 GM；是谁放的，本身可以是一条秘密 |
| `about` | 说的是谁 |
| `heat` | 每个圈子里的热度 0–5 |
| `cred` | 可信度 0–5：听的人信几分 |
| `effects` | 传开了以后，谁的哪种名望升降多少 |
| `status` | 流传 / 坐实 / 已辟 / 消退 |

| 热度 | 说法 | 可信 | 说法 |
|---|---|---|---|
| 0 | 无人提起 | 0 | 没人信 |
| 1 | 私下耳语 | 1 | 姑妄听之 |
| 2 | 小范围流传 | 2 | 将信将疑 |
| 3 | 传开了 | 3 | 多半信了 |
| 4 | 人人在说 | 4 | 深信不疑 |
| 5 | 满城风雨 | 5 | 已经坐实 |

### 造谣：`rumors.py spread`

`spread --text … --truth … --circle 圈子 --source 谁 --about 名 [--heat 1-3] [--cred N] [--effect 名:士林=-1,市井=-2]`

- 起头的热度默认 1；有人刻意散布（雇人、贴揭帖）的，GM 给 2–3。
- 可信度不写时按来源定：2 起；来源在这个圈子对应的名望 ≥6 的 +1，≤1 的 −1。拿出凭据、说得有鼻子有眼的，GM 写 `--cred` 高一点。
- 放假话的人是谁，本身是一条秘密：GM 照提示用 `secrets.py add` 登记，它会泄露。
- 流言也会从别处来：秘密泄露（`rules/secrets.md`）、文献里的说法（第四节）、宫中的病情外象（`rules/household.md` 第九节）。

### 季末传播：`rumors.py season`

每条“流传”“坐实”的流言，每个热度 > 0 的圈子：

```
往外传：  对每个有往来的圈子（那里的热度比这里低），机会 = 往来 × (热度 ÷ 3) × (0.5 + 可信 ÷ 10)，最多 90%
          传过去了，那里的热度 +1
越传越开：可信 ≥3、热度 <5、流言出来不满四季：机会 25% + 5% × (可信 − 3)，热度 +1
淡下去：  机会 max(5%, 45% − 8% × 可信) + 10% × (出来的季数 − 4，不小于 0)，热度 −1
          坐实了的：15% + 10% × (季数 − 6，不小于 0)；这一季刚冒出来的流言，这一季不会淡
```

各圈子都降到 0，流言“消退”。同一个 `--seed` 在同一份存档上结果相同；不写 seed 按回合数定。

### 辟谣：`rumors.py refute`

`refute 编号 --by 谁 [--circle 圈子] [--evidence 凭据] [--point -1..2]`

```
辟谣的力 = 1 + 名重（辟谣的人在这个圈子的名望 ≥7）1 + 有凭据 1 + 说辞的论点分（正的才算）
          − 本人出来辩白 1 − 说辞离题 1
可信 − 力，这个圈子的热度 −1
```

- 流言是**真的**、又拿不出凭据：先掷“越描越黑”，机会 25% + 5% × 可信；掷中了，可信 +1、热度 +1。
- 辟到可信 ≤1：流言“已辟”；它已经造成的名望损失，回一半（向上取整）。
- 替人辟谣，被说的人记辟谣的人一份情（`relations.py event 辟谣`）。

### 坐实：`rumors.py confirm`

证据摆出来了（`secrets.py evidence --status Ex=呈上`、朝议上查实）：可信到 5，状态“坐实”，`effects` 里的名望影响全部落下。

## 三、名望

每个有名有姓的人，在几种口碑里各有一个名望（0–10）：默认四种，士林、军中、市井、诸蕃（剧本可在 `fame_kinds` 里换）。

| 名望 | 说法 |
|---|---|
| 0–2 | 无闻 |
| 3–4 | 小有名气 |
| 5–6 | 有名 |
| 7–8 | 名重一时 |
| 9–10 | 名满天下 |

- 人格卡记在数值块的一行：`名望: 士林6 军中3 市井4 诸蕃1`。名册记在条目的 `名望` 字段；宫中、大族家宅里没有卡、也不在名册里的人，记在家宅条目的 `名望` 字段。没写的按 2（无闻）。
- 剧本作者写卡时照人物定；名册里的小人物一般不用写。

### 名望怎么变

| 事 | 名望 |
|---|---|
| 流言在某个圈子传开了（热度 ≥3）、多半信了（可信 ≥3） | 这个圈子对应的那种名望，按流言的 `effects` 升降一次 |
| 流言坐实 | `effects` 全部落下 |
| 流言被辟清 | 已经掉的回一半 |
| 廷辩胜（说服、驳倒、对方恼羞成怒） | 朝议看的名望 +1；恼羞成怒的一方 −1（`court.py session --apply`） |
| 弹劾得准，罢官、下狱、流放 | 被弹劾的人 −1；诬告反坐的人 −2 |
| 当众较量胜（单挑、比射） | GM 照 `rules/contest.md` 第七节写进见闻；要记数时用 `fame --delta 军中=+1 --why …` |
| 写了一部有分量的书、一道传诵的奏疏 | GM 用 `fame --delta` 记，写明缘由 |

### 名望用在哪里

- **朝议**（`rules/court.md` 第四节）：上奏的人名重 +0.5、人微言轻 −0.5；被弹劾的人名重 −1（动他要掂量）。
- **流言的可信度**：放话的人、辟谣的人名重，可信度、辟谣的力各 +1。
- **人心**：一位主公在军中的名望从 3 以上跌到 3 或更低（流言说他得位不正、临阵脱逃之类），`rumors.py` 会提醒：奉他为主的将领，名分可 −1（`loyalty.py state --standing`），GM 看流言说的是什么再定。说的是天子的，所有“归朝廷”的名节、名分都可以照此掂量。
- **识人之外的印象**：GM 写人时，名望是旁人对他的评价，不是他的本事；一个名满天下的人可能口才平平。

## 四、文献

```json
{"id": "D1", "title": "《北庭纪闻》", "kind": "书", "author": "冯道", "summary": "老臣记先帝北伐旧事……",
 "claims": [{"text": "先帝在北庭收养过一个孤儿", "truth": "真"}, {"text": "收养的孤儿就是当今天子", "truth": "假"}],
 "reach": {"士林": 2, "朝堂": 1}, "holders": ["冯道", "沈砚"], "weight": 2, "status": "流传"}
```

| 字段 | 说明 |
|---|---|
| `kind` | 书、檄文、奏疏、诗文、书信、告示、其他 |
| `claims` | 书里的说法，各有真假（GM 知道）。说法会生出流言 |
| `reach` | 每个圈子里的流布 0–5：多少人读过、听人讲过 |
| `holders` | 手里有这部书（这封信）的人 |
| `weight` | 分量 1–3：一封私信 1，一部有名的书、一道传檄天下的檄文 3 |
| `status` | 流传 / 禁毁 / 秘藏（秘藏的不流布，只在 holders 手里） |

**谁读过**：手里有的、作者，加上所在圈子里流布 ≥2、又识字（学 ≥3）的人。情报包（`secrets.py brief`）里列出。

### 季末流布

- 每个圈子流布 > 0、不到上限（分量 + 2）的，每季 25% + 5% × 分量 +1。
- 流布 ≥2 的圈子，往有往来的圈子传过去（机会 = 往来 × 0.4，那里从 1 起）。
- **禁毁**的：各圈子每季一半的机会 −1；市井里两成的机会越禁越传，+1。
- 书里还没生出流言的说法，在流布 ≥2 的圈子里每季四分之一的机会被人拿出来说；脚本只打印提议，GM 确认后跑 `doc spawn 编号 --claim-no N --circle 圈子`。生出的流言可信度 2 起，分量 3 的 +1，作者在那个圈子名望 ≥7 的 +1。

### 在辩论里引用：`rumors.py cite` / `contest.py --cite-a`

引用一部文献作论据，看引得当不当（GM 判断，和打论点分一样看话本身）：

| 引用 | 每轮加减 |
|---|---|
| 得当 | +0.5；在座的人多半读过（这个场合的圈子里流布 ≥2）、文献分量 ≥2 的，再 +0.5 |
| 牵强 | 0；在座的人都读过（流布 ≥3），看得出是牵强附会，−0.5 |
| 失当（引错了、断章取义） | −1 |
| 引的是禁书 | 另 −0.5，引的人也担风险（GM 可以记一条流言、一笔怨） |

合计夹在 −1.5..+1。场合对应的圈子：朝堂 → 朝堂；酒肆、街市、众目睽睽 → 市井；营中、校场 → 军中；私下不看流布。
`contest.py run --kind 辩论 … --cite-a "北庭纪闻=得当"`；奏疏里引用写 `court.py memorial --cite …`，算进朝议的分。

## 五、GM 怎么用

1. **有人放话、写书、泄密**：`spread`、`doc add`；秘密泄露由 `secrets.py season` 自动生成流言。
2. **调用 agent 前**：情报包里有他听过的流言、读过的文献，只给这些。他不知道流言的真假。
3. **写见闻**：`vignette.py` 的张力会抽到传开了的流言；小人物嘴里说出来的流言，照他的圈子和知情程度写，可以说错。
4. **季末**：`rumors.py season`，看过加 `--apply`。名望的升降一并写回卡片、名册；打印的“文献生出流言”GM 看过再跑。
5. **向玩家汇报**：玩家所在圈子里热度 ≥2 的流言，经幕僚、同僚、仆人、街头说起（`rumors.py heard <主角>`）。不说真假，不说来源（除非玩家查到）。

### 命令一览

```
python3 scripts/rumors.py spread --text … --truth 真|假|半真 --circle 圈子 [--source 谁] [--about 名,名] [--heat 1-3] [--cred 0-5]
        [--effect 名:士林=-1,市井=-2] [--note GM 备注] --apply
python3 scripts/rumors.py refute 编号 --by 谁 [--circle 圈子] [--evidence 凭据] [--point -1..2] [--seed N] --apply
python3 scripts/rumors.py confirm 编号 --why … --apply
python3 scripts/rumors.py season [--seed N] --apply
python3 scripts/rumors.py circle 圈子 [--gm]
python3 scripts/rumors.py heard 名
python3 scripts/rumors.py show [编号] [--all]
python3 scripts/rumors.py fame 名 [--set 士林=6,军中=3] [--delta 士林=-1 --why …] --apply
python3 scripts/rumors.py doc add --title 题目 --kind 书 [--author 谁] --summary 摘要 [--claim 说法=真 …] [--reach 士林=2] [--holders 名,名] [--weight 1-3] --apply
python3 scripts/rumors.py doc show [编号] | doc spawn 编号 --claim-no N --circle 圈子 [--about 名] [--effect …] --apply
python3 scripts/rumors.py doc ban 编号 --why … --apply | doc give 编号 --holders 名 --apply
python3 scripts/rumors.py cite 编号 --fit 得当|牵强|失当 [--audience 圈子]
```

所有命令都有 `--world 目录`。

## 六、例（示例朝廷，草稿副本试验）

开局两条流言、一部书：

- R1“户部的漕粮，三成进了崔家的仓”（真，来源京兆尹刘晏），市井小范围流传，将信将疑；传开了，崔琰士林 −1、市井 −2。
- R2“当今天子并非先帝亲生，本是外姓之子”（半真：先帝确曾收养过一个孤儿，但不是天子），士林私下耳语。
- D1《北庭纪闻》，老臣冯道著，写到先帝在北庭收养过一个孤儿；士林流布 2，朝堂 1。

八季下来（草稿副本，`--seed` 按回合）：

- 宦官高力第二季放出 R3“天子已经半年没上朝，奏章都是贤妃身边的人代批”（半真），宫中可信 3：当季“传开了”，第三季“人人在说”，第四季起往朝堂漏。宫中的口碑不算进哪种名望，贤妃的名望起先没动；第七季它在朝堂也“传开了”，贤妃的士林名望 2 → 1。
- 第三季，冯道拿《北庭纪闻》作凭据替天子辟谣 R2：力 = 1 + 有凭据 1 + 说辞 1 = 3，可信 2 → 0，辟清了。
- R1（漕粮）在市井将信将疑，往军中漏过两次，没人接着传，第七季消退。
- 《北庭纪闻》在朝堂、士林越读越多，第五季传进军中、第七季传进市井；书里两句说法几次被人拿出来说，脚本提议生出流言，GM 没有跑。
- 天子的病第四季到“沉疴”，外象调到 2；第八季秘密从外象漏出去，变成朝堂里一句“圣躬偶感风寒，听说另有隐情”（风闻，可信 2）。
