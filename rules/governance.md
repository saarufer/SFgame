# 分层托管

开局时帅府只有几千兵、两三个地区，每一百人都值得算清楚。到了几万兵、几十个地区，玩家要管的是方面大将和大方向。
这套规则让管理的粒度跟着规模走：近处亲自管，远处交给人管，交出去的有代价。

本文的“地区”就是剧本里的行政单位（`world/scenario.json` 的 `terms.region_unit`：州、郡、国……），脚本输出里也用那个字。例子取自唐末朔方剧本，标作“例（唐末朔方）”。

存档里的数字始终精确。分层只改两件事：**谁来结算**（GM 逐条结算，还是脚本按方针代办），**汇报到什么精度**。

---

## 一、三层

| 层级 | 谁管 | 怎么结算 | 汇报 |
|---|---|---|---|
| 亲领 | 帅府直辖 | 每条命令单独结算，和从前一样 | 精确到个位 |
| 委任 | 方面大将或地方长官 | 玩家下一道方针，每季由 `governance.py season` 代办补员、钱粮、练兵 | 约数和档位，加例外 |
| 羁縻 | 名义归附的割据势力、部落 | 不结算钱粮，自养；GM 按态度决定他们做什么 | 只报态度和动向 |

- 不在委任、羁縻里的己方地区和军，都算亲领。
- 玩家随时可以委任、改方针、收回、轮换。每一次都算帅府本季亲裁的一件事（第六节）。
- 打仗不分层：委任方面的军队遇敌，照样用 `resolve_battle.py` 逐场结算。方面大将出兵，照样走 `general` agent。

## 二、存档：`world/directives.json`

由 `scripts/governance.py` 读写，`report.py`、`economy.py` 读取。开局模板在 `scenarios/<剧本>/world/directives.json`，`council.seat` 写主公的治所。

例（唐末朔方）：

```json
{
  "council": {"seat": "灵州", "staff": [{"name": "裴元礼", "ability": 9, "forte": ["谋略", "外交"], "lean": "持重"}], "log": []},
  "establishment": {"骁骑营": {"cavalry": 3000, "infantry": 500}},
  "commands": {
    "定东军": {
      "holder": "康怀贞", "card": "characters/kang-huaizhen.md", "seat": "洛阳",
      "regions": ["洛阳", "华州", "潼关"], "armies": ["白毦兵", "骁骑营"],
      "since_turn": 78, "term": 8, "corps_start": 50,
      "directive": {
        "words": "东线守势；缺员自行补到八成；有大股敌军犯境再报",
        "posture": "守", "refill": 0.8, "tribute": 0.3,
        "latitude": {"tier": "中", "money": 3000, "grain": 0, "horses": 0},
        "report": {"缺员": 0.3, "士气": 60, "敌军": 3000, "粮季": 1}
      },
      "store": {"money": 30000, "grain": 80000},
      "in_transit": {}, "seen_grudges": [], "log": []
    }
  },
  "loose": {"王宗播（两川）": {"regions": ["成都", "东川"], "armies": ["蜀降军"], "attitude": "恭顺", "movement": "遣使朝贺"}},
  "hostile": [],
  "last_settlement": {}
}
```

| 字段 | 说明 |
|---|---|
| `council` | 帅府。`seat` 治所（缺省取 `kingdom.json` 的 `player.seat`）；`staff` 幕僚，每人 `ability` 1–10、`forte` 所长、`lean` 偏好、`status`（在 / 病 / 出使）；`log` 交办记录 |
| `establishment` | 各军建制。委任时按当时兵力自动记下，GM 可改高（比如打残了的军，按原编制记）。缺员、补员都对照它。亲领的军也可以写，写了就会查缺员 |
| `commands` | 委任的方面，见下 |
| `loose` | 羁縻。这些地区、军不进府库明细，自养；GM 每季改一句 `attitude`、`movement` |
| `hostile` | 额外当作敌军的势力名前缀。`factions.json` 里态度带“敌”的自动算 |
| `last_settlement` | `governance.py season` 写的本季结算：上供、请拨、各方面执行偏差、例外 |

方面（`commands` 下每一项）：

| 字段 | 说明 |
|---|---|
| `holder`、`card` | 主将和他的人格卡。没有人格卡的（小刺史），执行一律按“照办”，也不算部曲 |
| `seat` | 方面治所。方面内的政令衰减按离这里的远近算 |
| `regions`、`armies` | 辖下的地区和军 |
| `since_turn`、`term` | 委任起始回合、任期（季）。任期事先说定，到期轮换不记心结 |
| `corps_start` | 委任时他的部曲。收回、轮换时按“委任期间涨了多少”往回扣 |
| `directive` | 方针，见第四节 |
| `store` | 方面库。辖区收入扣掉上供后存在这里，粮饷、补员从这里出 |
| `in_transit` | 本季募的兵，下季到营 |

## 三、汇报精度：`scripts/report.py`

```
python3 scripts/report.py              # 分层汇报（给玩家）
python3 scripts/report.py --exceptions # 只列例外
python3 scripts/report.py --gm         # 加上 GM 才看的：离心、部曲
python3 scripts/report.py --exact      # 全部按亲领精确列出，对照用
```

只读不写。GM 向玩家汇报时，委任方面的数字就用这里的说法。

**约数**：一万以上取到千（“两万三”），一千以上取到五百（“四千五”），一百以上取到百（“八百”），不足一百说“数十”。

**档位**：

| 项 | 档位 |
|---|---|
| 兵（现有 ÷ 建制） | 满编（≥95%）、堪战（≥80%）、缺员（≥60%）、残破（不足六成） |
| 士气（按人数加权） | 高昂（≥85）、平稳（≥70）、低落（≥55）、涣散 |
| 粮、钱（方面库 ÷ 每季粮饷） | 充裕（≥4 季）、够用（≥2 季）、吃紧（≥1 季）、告急（不足一季） |

委任方面的一段汇报，大致是：

```
【委任】定东军（康怀贞，治所洛阳；方针：守，任期 5/8 季）
  辖 10 州：华州、潼关、洛阳……
  兵：步骑弓约四万二，民兵约两千，缺员；士气平稳
  库：粮够两季（够用），钱够用
```

**例外报告**：只有这些事单独列出，委任方面的门槛用它自己方针里的“上报条件”：

- 某军缺员超过门槛（默认三成）；
- 某军士气低于门槛（默认 60）；
- 方面库粮不够门槛（默认一季）；
- 敌军入境或压境（在辖区或相邻地区，人数过门槛，默认 3000）；
- 方面库不够发饷，府库代垫；
- 骑兵缺马，等帅府拨马；
- 任期已满；
- 方面大将本季没照方针办（“抗命”）；
- 方面大将新添了一条心结，而且是“幕僚可闻”或“细作可探”的（只说“幕僚听说某某为某事心里不痛快”，不报账本）；
- 府库欠饷、断粮。

离心级别、部曲、“不外传”的心结只在 `--gm` 里出现，不告诉玩家。玩家看到的异样，照旧按 `rules/loyalty.md` 择迹象透露。

## 四、方针令

玩家对一个委任方面说一段话，例如“西线守势；缺员自行补到八成；有大股敌军犯境再报”。GM 把它拆成下面几项，记进 `directive`，原话记进 `words`：

| 项 | 取值 | 作用 |
|---|---|---|
| 姿态 `posture` | 攻 / 守 / 养 | 攻：可以出境袭扰（出兵仍由 GM 召 general agent 结算），士气每季 −2，部曲涨得快。守：不出境，士气低于 80 的每季 +2。养：练兵，士气每季 +5（到 90 为止），每千人花练兵费 100 贯 |
| 补员目标 `refill` | 0–1 | 补到建制的几成。0 表示不补 |
| 上供 `tribute` | 0–1 | 辖区收入（钱、粮）先按这个比例上缴府库，余下进方面库 |
| 钱粮权限 `latitude` | 档：严 / 中 / 宽；`money`、`grain`、`horses` | 每季可以自行动支的上限（补员、练兵）。先用方面库，不够再向府库请拨，仍在上限以内。马匹只能向府库支取。档位影响部曲（第五节） |
| 上报条件 `report` | 缺员、士气、敌军、粮季 | 第三节例外的门槛 |

权限档参考：严，`money` 1000 以下，不许支马；中，2000–4000；宽，5000 以上或许支马。档位由玩家的话定（“钱粮你自己看着办”是宽，“每季不得过两千贯”是中），数额照写。

### 每季代办（`governance.py season`）

按顺序：

1. **执行偏差**：用方面大将人格卡的急进、持重和离心级别，按 `rules/loyalty.md` 第八节的概率掷一次。方面治所离帅府每多一程（超出两程的部分），拖延、变通各 +2 个百分点；新官上任第一季，拖延 +5。姿态为“攻”的按凶险命令算。
2. **上季募的兵到营**。
3. **收入**：辖下各地区的钱粮，乘季节系数、按地区修正、战乱减半，再按离方面治所的远近打折（第七节）。先按上供比例上缴，余下进方面库。
4. **粮饷**：辖下各军的粮饷从方面库出。库里不够，府库代垫，记一条例外。
5. **补员**：各军按建制补到目标，每个地区每季最多募 800 人，钱在权限以内。骑兵每千人要马一千匹，从权限里的马匹额度出；没有额度就记一条“待帅府拨马”。募的兵下季到营。
6. **练兵**：按姿态改士气。
7. **例外**：按上报条件检查，列出来。

执行偏差的默认效果：

| 结果 | 效果 |
|---|---|
| 照办 | 按方针 |
| 超额执行 | 补员目标多一成，权限钱额多两成（只从方面库出）；姿态为“攻”的，GM 可以让他多打一仗 |
| 变通 | 补员目标少一成；上供截留两成，留在方面库，自行犒军（当季部曲多涨 1） |
| 拖延 | 本季不补员、不练兵 |
| 抗命 | 只在离心“怨言”以上才会掷出。不补员，上供减半，记一条例外 |

偏差不是“照办”的，GM 可以召一次 `general` agent，让方面大将回禀缘由，prompt 里写方针原话和本季偏差。回禀写进史书。偏差本身不记心结；玩家为此当面斥责、派人查账，才按 `rules/loyalty.md` 第三节记。

上供和请拨不在 `governance.py` 里写府库：它记进 `last_settlement`，由 `economy.py` 当季一并计入（收入里多一行“委任方面上供”，支出里多一行“委任方面请拨、代垫”，马匹从府库扣）。所以每季要先跑 `governance.py season --apply`，再跑 `economy.py --apply`；顺序反了，`economy.py` 会拒绝写入。

## 五、托管的代价

### 权柄与部曲

- **委任**：主将人格卡上“权柄”一类的需求（名称含 权柄、重用、独当一面、兵权、被信任）满足度 +1。`governance.py delegate` 自动改。
- **部曲每季上涨**：`loyalty.py season` 读 `directives.json`，主将正统领一个方面，就按下表加部曲，最高到 90。

| 条件 | 每季部曲 |
|---|---|
| 委任中 | +1 |
| 委任已满四季 | 再 +1 |
| 钱粮权限为“宽” | 再 +1 |
| 姿态为“攻” | 再 +1 |
| 本季“变通”截留了上供 | 再 +1 |
| 方面治所离帅府四程以上 | 再 +1 |

一个守势、中等权限、离得不远的方面，第一年每季 +1，以后每季 +2。宽权限、攻势、远镇的，一季可以涨到 +5。

- **部曲高的后果**：举事时约部曲这个比例的兵马随他走（`rules/loyalty.md`）；部曲 60 以上，出走的算盘里去处为“自立”的风险 −1，80 以上 −2（兵认他，据地自立的底气足）。方面库也在他手里。

### 收回与轮换

| 做法 | 命令 | 部曲 | 人心账本 |
|---|---|---|---|
| 按期轮换（任期已满） | `rotate` | 委任期间涨的扣一半 | 不记心结（事先说定的） |
| 未满期轮换 | `rotate` | 委任期间涨的扣一半 | 心结 2“未满任期被调离旧部” |
| 召回入朝（给新职） | `recall --mode 入朝 --post 新职` | 委任期间涨的扣七成半 | 权柄 −1；未满任期再记心结 1 |
| 夺权 | `recall --mode 夺权` | 委任期间涨的全扣 | 权柄 −2，心结 3“被夺兵权”；当季 `season` 加 `--trigger 被夺兵权` |

接任的人权柄 +1，部曲从他自己原来的数起算，第一季拖延概率 +5。方面撤销时，方面库里的钱粮归府库，用 `economy.py --extra-income/--extra-grain` 记入。

## 六、帅府亲裁的限额

帅府每季能亲自过问的大事有限：

```
每季亲裁件数 = 3 + 能力 6 以上、眼下在帅府的幕僚人数（最多 +3）
```

什么算一件：亲领军队的一道军令；一项内政工程；一次遣使、议和；一次人事（委任、收回、轮换、改方针、升降）；一场审讯、一桩案子。召见问话、听幕僚议事、查地图库存不算。委任方面按方针代办的日常事务不算。

玩家本季的命令超过限额时，GM 先和玩家商量哪几件亲裁，其余交给幕僚（玩家可以点名，不点名由 GM 按所长分派），每件跑一次：

```
python3 scripts/governance.py council --assign 王从训 --task "核查关中流民户籍" --kind 内政 [--seed N] --apply
```

检定：幕僚能力 + 一枚六面骰 + 对口（所长对上 +1，对不上 −1）。

| 合计 | 结果 |
|---|---|
| 13 以上 | 办得漂亮：照办，另有一点添头（GM 依所长添一笔） |
| 10–12 | 办妥 |
| 7–9 | 打折：效果减半，或拖到下季见效 |
| 6 以下 | 走样：按幕僚自己的偏好改了办法，GM 照偏好叙述（“持重”的把进攻改成守，“省钱”的少花一半钱也少办一半事） |

幕僚有人格卡的（重要谋臣），偏好以人格卡为准。

## 七、政令衰减

地盘越大、离治所越远，帅府收得越少。`economy.json` 里有 `governance` 这一块参数时生效（开局模板里有；上一局的存档里没有，结算结果不变）：

```
政令系数 = 1 − 0.05 × (离帅府的程数 − 2，不小于 0) − 0.01 × (亲领地区数 − 8，不小于 0)，最低 0.6
```

- 亲领地区的钱、粮都乘这个系数（例（唐末朔方）：`economy.py` 明细里写“政令×0.85（距灵州5程，亲领23州）”）。程数按 `map.json` 的相邻关系数。
- 委任方面的地区，按离**方面治所**的程数算，不计亲领地区数那一项。远处的地区交给人管，收得比帅府隔空管多；代价是上供只交一部分、部曲上涨、执行偏差随路远加大。
- 固定收入（屯田、剧本的特色收入等）是帅府的项目，不打折，也不随地区委任出去。

参数可在 `economy.json` 的 `governance` 里改：`decay_free_steps`、`decay_per_step`、`scale_free_regions`、`scale_decay_per_region`、`decay_floor`，以及补员、练兵、亲裁的几项。

## 八、GM 每回合怎么做

1. 玩家的命令先分层：亲领的照旧逐条结算；对委任方面的话，拆成方针，用 `directive`（或首次 `delegate`）记下；羁縻的由 GM 决定反应。
2. 数一数亲裁件数，超出的交幕僚（第六节）。
3. 结算移动、战斗（委任方面的仗照样打）。
4. `python3 scripts/governance.py season --season <季> [--war 地区,地区]`，看过再加 `--apply`。偏差不是“照办”的，可召 `general` agent 回禀。
5. `python3 scripts/economy.py --season <季> …`，看过再加 `--apply`。
6. 人心账本：方面大将照旧跑 `loyalty.py season`，部曲自动上涨。
7. 汇报：`python3 scripts/report.py` 取数字。亲领的写精确数，委任的写约数和档位，羁縻的写一句态度；例外逐条写。`--gm` 的内容只进 GM 备注。

### 命令一览

例（唐末朔方）：

```
python3 scripts/governance.py show
python3 scripts/governance.py delegate 西线 --holder 没藏讹多 --card characters/mozang-eduo.md \
    --regions 凉州 --armies 凉州守军,安西新军 --seat 凉州 --term 8 \
    --posture 守 --refill 0.8 --latitude 中 --money 3000 --tribute 0.3 \
    --report 缺员=0.3,敌军=3000 --words "西线守势；缺员自行补到八成；有大股敌军犯境再报" --grant 5000,20000 --apply
python3 scripts/governance.py directive 西线 --posture 养 --apply
python3 scripts/governance.py season --season 冬 [--war 凉州] [--seed N] --apply
python3 scripts/governance.py recall 西线 --mode 入朝 --post 枢密副使 --apply
python3 scripts/governance.py recall 西线 --mode 夺权 --apply
python3 scripts/governance.py rotate 西线 --holder 论悉诺 --card characters/lun-xinuo.md --term 8 --apply
python3 scripts/governance.py council [--assign 幕僚 --task 事由 --kind 内政|军务|外交|人事] --apply
python3 scripts/report.py [--exceptions] [--gm] [--exact]
```

所有脚本都有 `--world 目录`，可以拿一份存档副本试算，不碰 `world/`。

## 九、例子（唐末朔方）

### 上一局天祐十九年秋，四军委任后的汇报

拿上一局存档（只读），在草稿目录造一份层级配置：定东、镇南、安西、靖北四军各成一个方面，王宗播、杨崇本、贺兰诸部为羁縻，灵州、盐州、邠州、长安亲领。`report.py` 的分层汇报 39 行、约 1070 字；`--exact` 全部精确列出 70 行、约 2770 字，短了六成。委任方面一段：

### 薛崇领东路六季（人格卡副本试验）

委任时部曲 60，方针“攻”、权限“宽”、任期 6 季；“被重用”满足 2 → 3。每季部曲 +3，满四季后 +4：60 → 63 → 66 → 69 → 72 → 76 → 80。到 80 时，“自立”的风险 −2。

六季后收回：

- 按期入朝：部曲 80 → 65，“被重用”3 → 2，不记心结。
- 夺权：部曲 80 → 60，“被重用”3 → 1，心结 3“被夺东路兵权”。
- 任期定为 10 季、第六季就调走：轮换部曲 80 → 70，心结 2“未满任期被调离东路旧部”；召回入朝部曲 80 → 65，另记心结 1“任期未满被召回东路”。
