# 关系网

人心账本记的是一个人对他所事之人（主公、天子、上司、家里的长辈）的账。人和人之间还有别的账：谁是谁的门生，谁和谁结了亲，谁欠谁一份情，谁记着谁一笔仇，这些关系哪些是公开的、哪些只有两三个人知道。
这一本账记在 `world/relations.json`，由 `scripts/relations.py` 读写。朝议（`rules/court.md`）、秘密（`rules/secrets.md`）、情报包都从这里取。

几条底线：

- **每一笔恩怨都有来处。** 和心结一样，写明时间、事由、强度。没有记下的恩怨，不算数。
- **亲疏是算出来的。** 两人之间的亲疏 = 关系标签的底子 + 恩 − 怨，GM 不凭感觉定。
- **暗的关系守迷雾。** 暗的标签、暗的恩怨，只有当事人和知情人知道；给 agent、给玩家的东西只含他知道的那部分。
- **亲疏是有方向的。** 甲看乙和乙看甲可以不一样：乙欠甲一份情，乙看甲亲；甲未必记得。

本文的例子用一个中性的示例朝廷（中书侍郎张籍、枢密使郭崇、监察御史沈砚等），标作“例（示例朝廷）”。

## 一、存档：`world/relations.json`

```json
{
  "version": 1,
  "pairs": [
    {"a": "杜牧之", "b": "沈砚",
     "tags": [{"tag": "师生", "roles": {"杜牧之": "师", "沈砚": "生"}, "since": "景和二十年"}],
     "base": {"杜牧之": null, "沈砚": null}, "note": ""},
    {"a": "崔琰", "b": "王溥", "tags": [{"tag": "私交", "hidden": true, "knowers": ["高力"]}], "base": {}}
  ],
  "deeds": [
    {"id": 2, "holder": "张籍", "toward": "郭崇", "kind": "怨", "s": 2, "what": "朝会上讥他是写字的穷酸",
     "when": "景和二十七年春", "turn": 1, "status": "未了", "age": 0, "known": "公开", "knowers": [], "source": "羞辱"}
  ],
  "next_id": 3, "last_season_turn": 0
}
```

| 字段 | 说明 |
|---|---|
| `pairs` | 两人之间的关系标签。`tags` 每条：`tag` 标签、`roles` 两头的称呼（有方向的标签才写）、`since`、`hidden`（暗的）、`knowers`（除了两人，还有谁知道） |
| `base` | GM 改过的“底子”（−2..+2），按人分两头写；`null` 表示按标签算 |
| `deeds` | 恩怨。`holder` 记着这份恩或怨的人，`toward` 对谁；`s` 强度 1–3；`status` 未了 / 已报（…）/ 已解（…）/ 已抵偿（…）/ 已淡忘（…）/ 不计（…）；`known` 公开 / 两人 / 暗；`source` 来自哪件事；`ref` 和人格卡上的心结相连时写 `card:<卡片>#<编号>` |

开局存档里可以没有这个文件，第一次 `--apply` 时自动建。剧本可以在开局存档里写好人物之间的旧关系。

## 二、标签和亲疏

### 标签

| 标签 | 底子 | 有方向 | 说明 |
|---|---|---|---|
| 姻亲 | +1 | | 两家结了亲（`household.py match` 之后记） |
| 亲族 | +1 | | 同宗、近亲 |
| 师生 | +1 | 师 / 生 | 受过业；座主和门生也算 |
| 同门 | +1 | | 同一位老师门下 |
| 同年 | +1 | | 同一年登第、同一批出仕 |
| 同乡 | +1 | | |
| 旧部 | +1 | 旧主 / 旧部 | 在谁手下做过事 |
| 同袍 | +1 | | 一起打过仗 |
| 主仆 | +1 | 主 / 仆 | 家仆、门客、幕宾 |
| 私交 | +2 | | 朋友、酒友、诗友 |
| 盟好 | +1 | | 约定互相照应 |
| 私情 | +2 | | 多半是暗的 |
| 世交 | +1 | | 两家上一辈的交情 |
| 上下级 | 0 | 上司 / 下属 | 眼下的上司和下属；冷暖看器重（`rules/court.md` 第六节）和恩怨 |
| 政敌 | −2 | | 在朝中立场相对，彼此都知道 |
| 世仇 | −2 | | 上一辈结下的仇 |

一对人可以有几个标签，底子相加，夹在 −2..+2。标签只说两人之间有这一层，人心冷暖靠恩怨记。表里没有的标签也可以记，底子按 0。

### 亲疏

```
甲看乙 = 底子 + 甲记着乙的恩（未了的强度合计）− 甲记着乙的怨（未了的强度合计）    夹在 −3..+3
```

| 亲疏 | 说法 |
|---|---|
| −3 | 势同水火 |
| −2 | 交恶 |
| −1 | 不睦 |
| 0 | 平常 |
| +1 | 有交情 |
| +2 | 交好 |
| +3 | 生死之交 |

**看人的眼光**：`relations.py show 某人 --as 观者` 只算观者知道的标签和恩怨。玩家眼里的关系网，就是 `--as <主角>`。

## 三、恩怨

### 强度

| 强度 | 恩 | 怨 |
|---|---|---|
| 1 | 小人情：说情、附议、一份礼、指点门路 | 小难堪：当众被驳倒、被讥讽一句、弹章没成 |
| 2 | 实打实的好处：举荐做官、替他担了干系 | 实打实的损失：被弹劾外放、被抢了位子、被当众羞辱、被要挟 |
| 3 | 救命、救了他的至亲、在大祸里保住了他 | 因这个人罢官、下狱、流放；至亲被他所害；被他构陷 |

### 常见的事怎么记（`relations.py event`）

`event 事件 --by 做事的人 --to 受者`，脚本按下表记：

| 事件 | 谁记着谁 | 恩/怨 | 强度 | 默认谁知道 |
|---|---|---|---|---|
| 举荐 | 受者记着做事的人 | 恩 | 2 | 两人 |
| 提携 | 同上 | 恩 | 1 | 两人 |
| 援手（附议、说情、解围） | 同上 | 恩 | 1 | 两人 |
| 厚赠 | 同上 | 恩 | 1 | 两人 |
| 救命 | 同上 | 恩 | 3 | 两人 |
| 辟谣 | 同上 | 恩 | 1 | 公开 |
| 驳倒（当众辩论驳倒） | 同上 | 怨 | 1 | 公开 |
| 恼羞成怒（辩论驳得下不来台） | 同上 | 怨 | 2 | 公开 |
| 羞辱 | 同上 | 怨 | 2 | 公开 |
| 弹劾 | 同上 | 怨 | 2 | 公开 |
| 罢官（因此人罢官、下狱、流放） | 同上 | 怨 | 3 | 公开 |
| 抢功（夺位、抢功劳） | 同上 | 怨 | 2 | 两人 |
| 背约（失信、出卖） | 同上 | 怨 | 2 | 两人 |
| 要挟 | 同上 | 怨 | 2 | 两人 |
| 构陷（他知道是谁干的） | 同上 | 怨 | 3 | 两人 |
| 杀亲 | 同上 | 怨 | 3 | 公开 |
| 联姻、结亲 | 两人记“姻亲”标签 | — | — | 公开 |
| 拜师 | “师生”标签 | — | — | 公开 |
| 结交 | “私交”标签 | — | — | 公开 |
| 结盟 | “盟好”标签 | — | — | 公开 |

强度可以用 `--strength` 改，写明缘由。表外的事用 `add 持有者 --toward 对方 --kind 恩|怨 --what … --strength N` 手记。

几个系统自动记、或者打印好命令的：

| 来处 | 记什么 |
|---|---|
| `contest.py run --kind 辩论`，当众驳倒、恼羞成怒 | 打印 `relations.py event 驳倒|恼羞成怒 …`，GM 看过再跑 |
| `court.py session --apply` 里的廷辩 | 直接记：输的一方对赢的一方怨 1（驳倒）或 2（恼羞成怒） |
| `court.py decide --apply` | 弹劾、举荐、提议的后果照 `rules/court.md` 第四节自动记 |
| `household.py match`（联姻） | GM 跑 `relations.py event 联姻 --by 主角 --to 对方家主` |
| `secrets.py leverage --apply`（要挟） | 被要挟的人对要挟的人怨 2 |
| `loyalty.py grudge … --toward 某人` | 心结针对某个具体的人时，关系网里同时记一笔怨，两边相连（见下） |

### 知情：公开、两人、暗

| known | 谁知道 |
|---|---|
| 公开 | 人人都知道（当众发生的事、朝议上的事） |
| 两人 | 记着的人和对方，外加 `knowers` |
| 暗 | 只有记着的人自己，外加 `knowers`（对方都不知道：暗中记仇、不知是谁举荐了自己） |

暗的关系被人知道了，用 `know 观者 --pair 甲,乙` 或 `--deed 编号` 记下。秘密泄露（`rules/secrets.md`）牵出暗的关系时，GM 一并记。

### 怎么了结

`settle 编号 --by …`：

| 方式 | 效果 | 说明 |
|---|---|---|
| 报答 | 恩：已报 | 还了这份人情。还了以后不再加亲疏；底子不变 |
| 报复 | 怨：已报 | 报了仇。报复本身是一件新事，对方因此记的怨另记 |
| 和解 | 强度 −1 | 当面赔礼、请人说和。同一笔一次 |
| 抵偿 | 整笔消掉 | 补上了当初失去的东西：还了位子、替他平了反 |
| 加深 | 强度 +1，重新计时 | 同一件事又被触动 |
| 淡忘、不计 | 不再计入 | 写明缘由 |

### 时间

`season` 每季给未了的恩怨计时：

| | 强度 1 | 强度 2 | 强度 3 |
|---|---|---|---|
| 恩 | 4 季没人再提就淡忘 | 8 季降为 1 | 不会自己淡 |
| 怨 | 6 季淡忘 | 12 季降为 1 | 不会自己淡 |

怨比恩记得长一些：小人情过一年就淡了，小难堪要记一年半。

### 和人格卡上的心结相连

人心账本的心结记的是对所事之人（主公、天子、上司）的账。有的心结同时是对一个具体的人的：例（唐末朔方）“杜昶接管盐务，断我财路”，账记在主公头上，人恨的是杜昶。
这时用 `loyalty.py grudge 卡片 … --toward 杜昶`：卡上的心结末尾多一段“对 杜昶”，关系网里同时记一笔怨（强度相同，`ref` 指向这条心结）。

- 心结的外传决定这笔怨谁知道：幕僚可闻 → 公开，家中可闻 → 两人，细作可探、不外传 → 暗。
- 以后用 `loyalty.py ease` 消解这条心结，关系网里那一笔跟着改；`relations.py season` 季末也会照卡对一次账，不另行淡化。
- 对同僚、政敌、外人的怨，和所事之人无关的（被同僚当众羞辱、被政敌弹劾），只记关系网，不记心结。

## 四、引荐：`relations.py path`

“谁能替我引荐到某某面前”：从“我”出发，经过熟人，一跳一跳走到目标。

- **一跳的条件**：听话的人看说话的人 ≥ 有交情（+1），说话的人看听话的人不交恶（≥ 0）。同在一派的人（`court.json` 的派系，公开的）没有别的恩怨时，按“有交情”算。
- 默认最多三个中间人，先列最短的，再按最弱的一环排。
- `--known-by 我`：只走“我”知道的关系，给玩家的答案就用它。GM 全知时可以加 `--gm-mark 我`，看哪几跳玩家其实不知道。
- 找不到路时，列出目标看重的几个人，玩家可以先去结交他们。
- 托人引荐算欠一份人情：成了，记 `event 提携` 或 `援手`（受者是“我”，做事的是中间人）。中间人是 agent 扮演的，GM 先问他肯不肯；肯不肯看他的性子和他眼里的“我”，路找到了不等于事成。

## 五、GM 怎么用

1. **发生了事就记**：朝议、辩论、联姻、救命、要挟，照第三节记。脚本打印的建议命令，看过再跑。
2. **调用角色 agent 前**：`secrets.py brief 名 --with 在场的人` 生成情报包，里面有他和在场之人的关系（只含他知道的）。
3. **玩家问“谁能替我说上话”**：`path 主角 目标 --known-by 主角`。
4. **季末**：`relations.py season`，看过再加 `--apply`。

### 命令一览

```
python3 scripts/relations.py show 名 [--as 观者] [--all]
python3 scripts/relations.py pair 甲 乙
python3 scripts/relations.py tag 甲 乙 --tag 师生 [--roles 甲=师,乙=生] [--hidden] [--knowers 名,名] [--since 时间] [--remove] --apply
python3 scripts/relations.py base 甲 --toward 乙 --value -2..2 --why … --apply      # --clear 恢复按标签算
python3 scripts/relations.py add 持有者 --toward 对方 --kind 恩|怨 --what … --strength 1-3 [--known 公开|两人|暗] --apply
python3 scripts/relations.py event 弹劾 --by 做事的人 --to 受者 [--what …] [--strength N] --apply
python3 scripts/relations.py settle 编号 --by 报答|报复|和解|抵偿|加深|淡忘|不计 [--note …] --apply
python3 scripts/relations.py know 观者 --pair 甲,乙 | --deed 编号 --apply
python3 scripts/relations.py path 我 目标 [--max 3] [--known-by 我] [--gm-mark 我]
python3 scripts/relations.py season --apply
```

所有命令都有 `--world 目录`，拿存档副本试。

## 六、例（示例朝廷，草稿副本试验）

监察御史沈砚是御史中丞杜牧之的门生（师生）；杜牧之和中书侍郎张籍是同年；户部尚书崔琰和礼部侍郎王溥私交甚笃，是暗的，只有宦官高力知道。

```
$ relations.py show 崔琰 --as 沈砚
  张籍   崔琰看他：交恶（-2）  他看崔琰：交恶（-2）   关系：政敌
  郭崇   崔琰看他：有交情（+1） 他看崔琰：有交情（+1） 关系：姻亲
（王溥那一层，沈砚看不到）

$ relations.py path 沈砚 张籍 --known-by 沈砚
  · 沈砚 →（杜牧之 看他 有交情） 杜牧之 →（张籍 看他 有交情，同派） → 张籍
```

沈砚弹劾崔琰得准，崔琰外放；`court.py decide --apply` 记下“崔琰对沈砚 怨 2（被沈砚弹劾，外放）”，公开。
从此崔琰看沈砚“交恶”：他日后回朝、在朝议上表态，或者有人托他引荐沈砚，都会算进这一笔。
