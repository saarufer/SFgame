# 较量

玩家想和谁单挑、打一架、比一回射、辩一场，交给 `scripts/contest.py` 结算。几种较量共用一套框架：双方按属性、打法、体力（辩论是气势）一合一合地比，加骰子，外加场外的变数。
属性、特长、短处、伤势从人格卡或名册读（`rules/people.md`）。

几条底线：

- **数字交给脚本。** 胜负、伤势、死活都由脚本掷，GM 不凭感觉定；GM 只把脚本给的摘要改写成白描。
- **玩家说一句就够。** 玩家说一句打法（“稳住，等他力竭”），或者什么都不说；对手的打法由他的 agent 按人格卡定，名册里的人按性情自动选。
- **辩论看玩家的原话。** 玩家亲口说的论点，GM 按第四节的刻度打一个论点分，作为修正。说得好，就能赢一个口才比主角好的人。
- **较量有后果。** 伤要养，人会死，两军的士气会动，旁人会记着。主角战死不是游戏结束（第八节）。

本文的例子取自唐末朔方剧本，标作“例（唐末朔方）”。

## 一、种类

| 种类 | 别名 | 每合比什么 | 单位 | 最多 | 会不会死人 |
|---|---|---|---|---|---|
| 马战 | 马上单挑、单挑 | 武×0.45 + 骑×0.35 + 胆×0.20 | 合 | 30 | 看场合 |
| 步战 | 步下单挑 | 武×0.55 + 体×0.20 + 胆×0.25 | 合 | 20 | 看场合 |
| 打架 | 斗殴 | 武×0.40 + 体×0.40 + 胆×0.20 | 回合 | 12 | 不会（至多重伤） |
| 比射 | 比箭 | 射（马上射：射×0.6 + 骑×0.4） | 轮 | 3 轮，每轮 3 箭 | 不会 |
| 辩论 | 舌辩、说服 | 辩×0.45 + 智×0.30 + 学×0.25（打法可以换） | 轮 | 6 | 不会 |

以后要加马球、下棋、刺杀与护卫，在 `contest.py` 的 `KINDS`、`STYLES`、`COUNTER` 里各加一项，结算沿用相近的一种（马球照马战，下棋照辩论，刺杀照步战再加场外变数），再在本文补一节。

### 场合

| 场合 | 会不会死人 | 本阵抢救 | 打架时旁人拉开（每回合，第三回合起） | 当众 | 偏向的打法 |
|---|---|---|---|---|---|
| 阵前 | 会 | 50% | — | 是 | |
| 私下 | 会 | 没有 | — | 否 | |
| 营中 | 不会 | — | 10% | 是 | |
| 校场 | 不会 | — | 6% | 是 | |
| 朝堂 | 不会 | — | 20% | 是 | 引经据典 +0.4 |
| 酒肆、街市、众目睽睽 | 不会 | — | 8% | 是 | 以情动人 +0.4 |

- 不写场合时：单挑按阵前，打架按酒肆，比射按校场，辩论按私下。
- “不会死人”的场合，打到落马、倒地就算认输，伤也轻一些（第六节）。营中、校场的比武是点到为止。
- 主角落马时，本阵抢救的机会再 +20%（亲兵一直盯着）；`--lead-a/--lead-b`（他是这一军的主将）再 +10%。GM 也可以用 `--rescue-a/--rescue-b` 直接给一个数（对方阵中已经有人冲出来接应、主角是单骑出阵……）。

## 二、打法与相克

打法可以写名字，也可以写一句话，脚本从里面认关键词（“稳住，等他力竭”认出“稳”→ 稳守）；前面带“别、不、莫、勿、休、免得、防着”的不算（“别让他抱住”不是要抱摔）。一个都认不出，或者什么都没写，按性情自动选：
数值块里“性情”那一行（算两倍）和卡上“天性”“性情”“性格”一节，按下表数关键词，最多的那种；都没有，本事强的猛攻、弱的稳守。
`python3 scripts/contest.py styles` 列出全部打法和关键词。

### 单挑（马战、步战）

| 打法 | 每合耗体力 | 特点 | 自动选的关键字 |
|---|---|---|---|
| 猛攻 | 1.3 | 前六合 +0.5 | 骄 勇 急 猛 躁 狠 粗 抢 冲 悍 |
| 稳守 | 0.7 | 守势：体力过半时才有相克的加成 | 谨慎 慎 稳 持重 沉住 深沉 细心 守成 |
| 缠斗耗力 | 1.0 | 让对方每合多耗 0.5 体力 | 倔 韧 耐 磨 |
| 诈败回马 | 1.0 | 诈术，一场只用一次（见第三节） | 狡 诈 计 滑 谋 算计 |
| 游走骑射 | 1.2 | 只能马上用；改比 射×0.5 + 骑×0.35 + 胆×0.15 | 射艺比武艺高两点以上的人，自动选它 |

相克（本方每合加成，反过来对方减同样多）：

| 打法 | 克 | 加成 |
|---|---|---|
| 稳守 | 猛攻 | +0.4（稳守的人体力不到一半，就不再有） |
| 猛攻 | 缠斗耗力 | +0.4 |
| 缠斗耗力 | 稳守 | +0.4 |
| 游走骑射 | 稳守 | +0.5 |
| 猛攻 | 游走骑射 | +0.4 |
| 游走骑射 | 缠斗耗力 | +0.3 |

所以：稳守克猛攻，但体力差的人守不久；猛攻的人前几合占便宜，耗得也快，体力见底时每合 −2.5；诈败对谨慎的人没用。

### 打架

| 打法 | 每回合耗体力 | 特点 |
|---|---|---|
| 猛扑 | 1.5 | 前四回合 +0.4 |
| 招架 | 0.7 | 守势 |
| 缠抱摔跤 | 1.2 | 让对方每回合多耗 0.4；会“摔跤”的人自动选它 |
| 使绊子 | 1.0 | 诈术，一场一次 |
| 游斗 | 0.9 | |

相克：缠抱摔跤克猛扑 +0.5；猛扑克游斗 +0.4；游斗克缠抱摔跤 +0.4；招架克猛扑 +0.4（体力过半时）；缠抱摔跤克招架 +0.3。

### 比射

| 打法 | 特点 |
|---|---|
| 稳射 | 照常 |
| 求险 | 射难的靶：每箭命中率 −20%，中一箭算三分（平常中一箭两分） |
| 抢快 | 自己 −5%，对方被催得 −4% |

### 辩论

| 打法 | 改比 | 自动选的关键字 |
|---|---|---|
| 引经据典 | 学×0.45 + 辩×0.35 + 智×0.20 | 经史 典故 读书 引书 引经 |
| 以理服人 | 智×0.45 + 辩×0.35 + 学×0.20 | 讲理 道理 算账 利害 先算 |
| 以情动人 | 魅×0.45 + 辩×0.40 + 智×0.15 | 重情 动情 和气 厚道 仁厚 心善 义气 念旧 恩 |
| 抓破绽 | 智×0.50 + 辩×0.35 + 学×0.15 | 刻薄 多疑 挑剔 精明 心思细 较真 |
| 拖延搅局 | 辩×0.60 + 智×0.40 | 圆滑 油滑 拖延 躲事 打哈哈 |

相克：抓破绽克引经据典 +0.6；引经据典克以情动人 +0.5；以情动人克以理服人 +0.5；以理服人克拖延搅局 +0.6；以理服人克抓破绽 +0.3；拖延搅局克抓破绽 +0.3。
拖延搅局：只要有一方用它，双方每轮掉的气势减半；用它的一方即便把对方搅得说不下去，结局也只是“各执一词”。它是落了下风时保住面子的打法。
性情里看不出偏好的，按他最拿手的那种（拖延搅局除外）。

## 三、每合怎么算（单挑、打架）

每合双方各算一个分：

```
分 = 0.5 ×（属性加权 + 特长加成） + 打法相克 + 开头几合的加成 + 0.1 × 对对方的识人进度 + 围观起哄
     − 体力不济（体力不到三成五 −1，见底 −2.5） + 骰子（正态，标准差 2）
```

- **属性加权**照第一节的表；带伤的人按伤势打折（第六节）。**特长加成**：特长、短处表的“较量”一栏（`rules/people.md` 第五节），种类、打法、场合对得上的才算，正的合计最多 +1。
  本事乘 0.5，是为了让打法、体力和临场的运气有分量：本事差两三点的人，打法对了，也有一两成的机会。
- **识人**：知道对方的底细，每级 +0.1。
- **围观起哄**：`--crowd A|B`，偏向的一方每合 +0.3。
- **体力**：上限 = 8 + 2.2 × 体（“能吃苦”多一成，“久战不支”少四分之一）。每合按打法耗，这一合输了 1.2 分以上再多耗 0.4。

两边的分相减，差：

| 差 | 结果 |
|---|---|
| 不到 1.2 | 相持 |
| 1.2–3 | 占上风，输的一方多耗体力 |
| 3–5 | 击中，对方伤 +1 |
| 5 以上（打架是 6 以上） | 重击，对方伤 +2 |

伤累到 3，落马（倒地）。体力见底、伤又不比对方轻的人想退：阵前、私下要本阵抢得回去才走得了，营中、校场就算认输；占着上风的人咬牙再斗。打满了合数，伤少、体力多的一方算赢，差不多就是平手。

**诈术**（诈败回马、使绊子）：落了下风（伤比对方重，或体力比对方少一成以上）或斗到第八合，用一次。

```
成算 = 45% + 8% ×（本方智 − 对方智） + 特长“善谋”10%
       对方猛攻 +25%；对方稳守、招架 −35%；对方“易中诈”+15%、“不易中诈”−20%；对方对本方的识人每级 −10%
       夹在 5%–90%
```

得手，这一合 +3.5（多半就是一下重击）；落空，这一合 −1.5。

## 四、辩论

每轮：

```
分 = 0.6 ×（属性加权 + 特长加成） + 打法相克 + 场合偏向的打法 + 论点分 × 1.0 + 引用文献（见下）
     + 主事者偏向 0.8 + 听众偏向 0.4 + 0.1 × 识人 + 骰子（标准差 1.6）
```

**气势** = 6 + 0.4 × 胆 + 0.3 × 魅。每轮分差不到 1，双方各 −0.5；1–3，输的一方 −2.5；3 以上，输的一方 −4（“一句话问住了”）。气势见底的一方落败。六轮下来都没见底，就是各执一词（气势差 3 以上的，写“某某略占上风”）。

### 论点分（GM 给玩家的原话打）

玩家说出口的那几句，GM 照下表打一个分，用 `--point-a`。对手的话由他的 agent 写出来，GM 照同一张表打 `--point-b`（不打就是 0）。

| 分 | 叫法 | 什么样的话 |
|---|---|---|
| −1 | 离题 | 答非所问、说错了事实、强词夺理，或者只是骂人 |
| 0 | 平平 | 说得通，但对方早想到了，没有新东西 |
| +1 | 切中 | 抓住了对方的要害或者眼前的利害，有一两句让人没法回 |
| +2 | 绝妙 | 切中要害，又给了对方台阶，或者一个他没法拒绝的理由；在场的人都会记住这句话 |

打分只看话本身，不看玩家平时的表现；拿不准的往低打半档（取整往 0 靠）。打的分和理由记进 GM 备注。
论点分每一分每轮 +1，大约抵得上口才差四五点。所以 +2 的话，能赢一个口才比主角好得多的人；−1 的话，本来占上风也可能被拖成各执一词。

**主事者**：`--judge A|B`，在朝堂上拍板的人、请来评理的长者偏向哪一边（按他的立场和他与双方的交情，GM 定）。**听众**：`--crowd A|B`。

**引用文献**：`--cite-a "文献=得当|牵强|失当"`（`--cite-b` 同）。文献登记在 `world/rumors.json`，引得当不当由 GM 判断，每轮的加减照 `rules/rumors.md` 第四节：得当 +0.5（在座的人多半读过、文献有分量的再 +0.5），牵强 0（在座的人都读过的 −0.5），失当 −1，引禁书另 −0.5；合计夹在 −1.5..+1。
场合决定“在座的人”是哪个圈子：朝堂 → 朝堂；酒肆、街市、众目睽睽 → 市井；营中、校场 → 军中。

**朝议上的廷辩**由 `court.py session --debate` 调用本节的辩论（`rules/court.md` 第四节），主事者、听众的偏向由朝议算出来。

### 结局

| 结局 | 什么时候 |
|---|---|
| 说服 | 赢的一方用的是引经据典、以理服人、以情动人：对方心里认了 |
| 驳倒 | 赢的一方用的是抓破绽：对方理屈词穷，但心里未必服 |
| 恼羞成怒 | 落败的一方翻脸：机会 12%；“易怒”+25%；胆≥7 而智≤5 +10%；当众 +10%；智≥7 −10%（夹在 2%–70%） |
| 各执一词 | 六轮没分出来，或者搅局的一方占了上风 |

## 五、比射

每轮每人射三箭（`--arrows`），每箭命中率：

```
20% + 7% × 射（马上射：射×0.6 + 骑×0.4） + 特长加成 × 6%
打法：求险 −20%（中一箭三分，平常两分）；抢快 −5%，对方 −4%
最后一轮：+2% ×（胆 − 5）；当众：每轮 +1.5% ×（胆 − 5）；围观偏向 +2%
夹在 3%–97%
```

三轮合计分高的赢；打平了加射，一人一箭，最多五次，还平就是平手。比射不伤人。

## 六、场外变数、结局与伤势

### 场外变数

| 变数 | 怎么来 |
|---|---|
| 冷箭 | 阵前才有。每合每一方阵中放冷箭的机会 0.3%，这一方的人落了下风翻倍，`--dirty A|B`（那一方阵中有人存心）再乘 4。射中的一半，被射的人伤 +1；不管中没中，单挑都打不下去了。放冷箭的一方士气 −5，被射的一方 +5 |
| 本阵抢救 | 阵前落马时，按第一节的抢救机会掷：抢回去就是“负伤退走”，抢不回去由赢的一方定斩还是擒 |
| 天黑收兵 | `--dusk N`：天黑前只能再斗 N 合 |
| 旁人拉开 | 打架时，按场合每回合掷一次 |
| 围观起哄 | `--crowd A|B` |
| 主事者偏袒 | 辩论的 `--judge A|B` |

### 斩还是擒

阵前、私下落马、抢不回去时，赢的一方定：`--intent-a/--intent-b 斩|擒`，由他的 agent 按性格说（ruler、general 的回复里写），名册里的人按性情：性情里带“狠、骄、悍”的六成斩，其余四成斩。
斩：八成当场身死（伤到 4 以上的九成五），没死透的重伤被擒。擒：活捉，重伤（伤到 4 以上的是危）。

### 结局一览

| 种类 | 结局 |
|---|---|
| 单挑（阵前、私下） | 斩、擒、负伤退走（被本阵抢回）、力竭退走、平手、冷箭作罢 |
| 单挑（营中、校场） | 落败认输、力竭认输、点数落败、平手 |
| 打架 | 打服、两败俱伤、被人拉开、平手 |
| 比射 | 胜、负、平手 |
| 辩论 | 说服、驳倒、各执一词、恼羞成怒 |

### 伤势

| 伤势 | 怎么来 | 养几季 | 养伤期间 |
|---|---|---|---|
| 轻伤 | 单挑挨了一下；营中、校场比武落败的约一半、挨了两下的四分之一；打架挨得重了（三四成） | 1 | 武、骑、射、体打九折 |
| 重伤 | 单挑挨了两下；落马被抢回、被擒；营中比武、打架偶尔（5%） | 2（体≤4 的 3） | 武、骑、射、体打七折，胆 −1；带兵的统帅修正不算（战斗输入里统率按 5，不写 charge；亲临时将领状态写“负伤”） |
| 危 | 落马时伤到 4 以上；被斩没死透 | 3（体≤4 的 4） | 打四折，胆 −2；下不了场（`--force` 除外）；每季末掷一次凶险 |

- **季末养伤**：`contest.py heal`。每季余下的季数减一；危的先掷凶险 20%（`--care 名`：有名医或懂医的人照料，减半），熬过去、只剩两季时转为重伤；重伤只剩一季时转为轻伤；养满了痊愈。
- 重伤、危养好时，有两成落下“旧伤”（短处加一个“旧伤”，体 −1，较量里久战不支）。
- 伤记在人格卡数值块的“伤势”（`重伤｜左臂｜余 2 季｜原为危`）或名册的 `injury` 里。打仗里负的伤也用 `contest.py wound 名 --level 重伤 --where 左臂 --apply` 记下，一样逐季养。
- 伤势和家人的身体（`household.json` 的 health）是两回事：病归 `household.py`，伤归 `contest.py`。

## 七、后果

`run` 打印过程摘要（只列关键的几合），后面跟一段 JSON。GM 把摘要改写成白描，照 JSON 记账。

### 士气（阵前单挑）

| 结局 | 赢的一方 | 输的一方 |
|---|---|---|
| 斩 | +12 | −15 |
| 擒 | +10 | −12 |
| 负伤退走 | +6 | −8 |
| 力竭退走 | +4 | −5 |
| 平手 | 0（斗过二十合的，两边各 +2，两阵喝彩） | 0 |

- 输的人是这一军的主将（`--lead-a/--lead-b`），那一方再 −5。冷箭另算（上一节）。
- **接到 `resolve_battle.py`**：这一仗的输入里，A 方那一边（attacker 或 defender）加 `"morale_bonus": N`，B 方加它的数。脚本开战前把它加到士气上（夹在 0–100）。主将重伤、阵亡、被俘的一方，统率按 5 写，不写 `charge`；阵亡、被俘的，GM 照常换人统兵。
- **接到 `tactical.py`**：单挑在开战前的，初始战例的 `sides.X` 里写 `"morale_bonus": N`，`new` 时加到该方各部；打到一半才单挑的，用
  `python3 scripts/tactical.py morale --state 战场.json --side A --delta N [--leader 名=负伤|阵亡|被俘] --why 阵前单挑`。JSON 里 `battle.tactical` 一行已经写好，GM 换上战场文件和代号。
- 没有打仗、只是对阵叫骂时的单挑，士气的加减留到下一仗，写进 GM 备注，下一仗开打时加上；隔了一季的不再算。

### 名声

当众的较量，赢的人名声在军中、城里传开：GM 在见闻、部将回禀里带一笔，名册里的人记一条出场。阵前斩将的，敌我两边的将领卡“记忆”里各记一条。

### 识人

交过手的双方，互相 +1（到 3 为止）。`--apply` 自动记。

### 人心账本（建议，GM 看过再记）

- 当众（朝堂、营中、众目睽睽）把一位将领、家人**驳倒**：建议心结 1（`--heard 幕僚可闻`）；他**恼羞成怒**或者短处是“易怒”一类的：心结 2。**说服**了的不记心结；说服的事正对上他的某项需求，GM 可以上调满足度。
- 营中、校场当众比武赢了一位骄横、好面子的将领：建议心结 1。比武点到为止的，其余人不记。
- 主角下手重了，把自己人打成重伤：GM 看缘由记心结 1–2。
- 脚本把建议写成 `loyalty.py grudge …` 命令，`<本季>` 换成日期再跑。

### 关系网（建议，GM 看过再记）

当众（朝堂、营中、众目睽睽）辩论，一方**驳倒**对方、或者对方**恼羞成怒**，不论是不是人格卡上的人，脚本都打印一条 `relations.py event 驳倒|恼羞成怒 --by 赢的人 --to 输的人` 的命令：输的人对赢的人记怨 1 或 2（`rules/relations.md` 第三节）。
说服了的不记怨。朝议上的廷辩由 `court.py session --apply` 直接记，不另跑。

## 八、几条规矩

### 应不应战

- **主角要出阵单挑**：GM 先把这件事告诉在场的将领（`general` agent，prompt 里写主角的原话和对手的印象）。将领按性格回禀：猛将多半抢着请战，持重的会劝“主公千金之躯”（例（唐末朔方）：薛崇、周延嗣）。劝阻不拦玩家：玩家坚持，照打。
- **主角叫阵**：对手是 ruler 或 general agent 的，GM 问他应不应战，prompt 里给他对主角的印象（`persona.py impress <主角> --by <对手>`）、两军的态势、主角的原话。他按性格回：应战（写打法，阵前的写斩还是擒），或者不应（写怎么回话）。名册里的人由 GM 按性情和胆定：胆 3 以下的多半不敢。
- 阵前当众拒绝叫阵的，不算胜负；GM 可以给拒绝的一方士气 −3，写进名声。
- **主角命部将出阵**：照一道军令，`general` agent 按性格接或不接；日常检定（`loyalty.py roll --risky`）照常。
- 伤到“危”的人下不了场。

### 主角战死

主角战死、被斩、伤重不治，游戏不结束，由继承人接手，玩家改扮他：

1. **有嗣子**（`household.json` 的 `heir`）：嗣子接手。
2. **没立嗣**：照 `rules/household.md` 第五节“继承”的顺序：嫡长子、年长的儿子；儿子都不满十六岁的，仍由长子接位，母亲（主角的妻子）或祖母摄事，GM 请玩家挑一位将领辅政；没有儿子的，弟弟接手。几个人都有份的，落选的人照“立嗣”记心结（`household.py heir`）。
3. **家里没人能接**（家宅没启用，或家人都不在了）：军中推举。己方将领里部曲加统兵最高的那位，GM 也可以列两三位请玩家挑。他的将领卡改成主角卡（身份改“主角”，账本停用），其余将领各记名分 −1。
4. **己方一个人都没有了**：本局结束，写 `chronicle/终章.md`。

接手的那一季：

- 改存档：`kingdom.json` 的 `player.name`、`factions.json` 里己方的 `leader`、`world/scenario.json` 的 `player.protagonist` 和 `player.card`、`household.json` 的 `protagonist`（关系照新主角重排）。旧主角卡移到 `archive/`，生平记进 `world/history.json`。
- 新主角卡：从他的家人卡或将领卡改，属性照搬，身份改“主角”，“与主角”“与主公”两节改写成他对先主的记忆。
- 人心：每位有兵权的将领这一季 `loyalty.py season` 带触发“主公大败”（主公身死，人心浮动）。继位的人不满十六岁、或者没立过嗣的，各将领名分 −1（`state --standing`）。和先主有旧恩的，“被重用 / 被信任”一类需求重新评定。
- 先主怎么死的写进史书；敌方 ruler agent 这一季知道这件事。

### 伤势的恢复

每季回合数 +1 之前跑 `contest.py heal`，看过再加 `--apply`（`.claude/commands/turn.md` 第 8 步）。名医、懂医的人照料的，加 `--care 名`。

## 九、GM 怎么用

1. 玩家说要和谁较量。GM 按上一节问在场的人、问对手应不应战。
2. 定种类、场合，把玩家的话交给 `--style-a`（一句话就行）；对手的打法照他 agent 的回复写 `--style-b`，不写就自动选。辩论给玩家的原话打论点分。
3. 先不加 `--apply` 跑一次，看摘要和后果；定稿后同一 `--seed` 加 `--apply`，把伤势、识人、名册里的死亡写回。人格卡上的人死了、被擒了，照打印的步骤处理。
4. 把摘要改写成白描给玩家：写招式、写马、写阵上的人，不写数字（伤势、士气写成看得见的样子：“左臂抬不起来”“阵上一片喊声”）。数字只进史书的 GM 备注。
5. 后果里的士气接到这一仗的输入上；名声写进见闻；心结的建议看过再记。

### 命令一览

```
python3 scripts/contest.py run --kind 马战|步战|打架|比射|辩论 --a 名 --b 名 [--style-a 一句话] [--style-b 打法]
        [--occasion 阵前|私下|营中|校场|朝堂|酒肆|街市|众目睽睽] [--crowd A|B] [--judge A|B]
        [--point-a −1..2] [--point-b −1..2] [--cite-a 文献=得当] [--cite-b 文献=得当] [--intent-a 斩|擒] [--intent-b 斩|擒] [--rescue-a 0–1] [--rescue-b 0–1]
        [--lead-a] [--lead-b] [--dirty A|B] [--dusk N] [--mounted] [--arrows N] [--rounds N]
        [--seed N] [--json] [--trials N] [--force] [--apply]
python3 scripts/contest.py styles [--kind 种类]
python3 scripts/contest.py wound 名 --level 轻伤|重伤|危|无 [--where 部位] [--seasons N] [--apply]
python3 scripts/contest.py heal [--care 名 ...] [--seed N] [--apply]
```

`--trials N` 同一场跑 N 次，只看胜负和伤亡的比例，给 GM 掂量轻重、调平衡用，不拿来结算正式的较量，也不要告诉玩家具体的胜算。
所有命令都有 `--world 目录`。

## 十、测试摘录（例（唐末朔方），草稿副本）

主角韩逊（统 7 武 6 智 7 骑 7 射 6 体 6 胆 7，骑术好）对一张自建的轻卡“李存勖”（武 9 骑 9 胆 9 体 8 射 8，使槊、冲阵、善射，骄横；性情“骄勇，喜抢攻”，自动选猛攻），阵前马上单挑，各跑 1000 次：

| 韩逊的打法 | 韩逊胜 | 李存勖胜 | 不分胜负 | 平均合数 | 韩逊战死 |
|---|---|---|---|---|---|
| 猛攻 | 4% | 92% | 4% | 7 | 13% |
| 稳守 | 19% | 76% | 5% | 9 | 10% |
| 缠斗耗力 | 1% | 96% | 3% | 5 | 15% |
| 诈败回马 | 6% | 91% | 3% | 7 | 12% |
| 游走骑射 | 0.4% | 97% | 3% | 5 | 15% |

（数字是写本文时的测试，调参以后以 `--trials` 为准。韩逊落马时七成能被亲兵抢回，所以输了多半是重伤退走；“危”的伤每季末还要掷一次凶险。）

玩家说“稳住，先守几合，等他马乏了再说”，`--seed 21` 的一场：

```
A 韩逊：打法“稳守”（从“稳住，先守几合，等他马乏了再说”里认出“守”）
B 李存勖：打法“猛攻”（按性情（骄勇，喜抢攻，每战亲自冲在前头）自动选）
第一合，两马相交，李存勖占了先手
第二合，李存勖一槊刺中韩逊手腕，见了血
第五合，李存勖一槊刺中韩逊后背，伤得重
第五合，韩逊落马，本阵的人拼死抢了回去
结果：李存勖胜，韩逊负伤退走（共 五合）
伤势：韩逊 重伤（后背），约 2 季养好；养伤期间武、骑、射、体打7折，胆−1
士气：韩逊一方 −8，李存勖一方 +6（接进这一仗的 morale_bonus）
识人：双方互相 0 → 1
```

**打架**：韩逊对酒肆壮汉马大（武 7 体 9，会摔跤，自动选缠抱摔跤），酒肆，各 1000 次：招架 韩逊胜 0.5%、马大胜 62%、被拉开或两败俱伤 37%；游斗（克缠抱摔跤）韩逊胜 11%、马大胜 32%、不分 57%；使绊子 4% / 43% / 53%。
玩家说“绕着他打，别让他抱住”，认出“绕着”→ 游斗（“别让他抱住”是不要这样打，不算）。

**辩论**：书生柳文远（学 9 智 8 辩 6，熟读经史）在朝堂上对两个人，各 1000 次，只改书生的论点分：

| 对手 | 论点分 −1 | 0 | +1 | +2 |
|---|---|---|---|---|
| 幕僚杜昶（智 8 学 8 辩 5） | 书生胜 34%，杜昶胜 21% | 71% / 4% | — | 99.6% / 0% |
| 周延嗣（辩 8 学 8 智 8，能言善辩、熟读经史，好面子） | 5% / 51% | 28% / 16% | 66% / 3% | 92% / 0%（其中三成多是周延嗣恼羞成怒） |

口才比书生好两点的周延嗣，书生说得平平时各有输赢，说出 +2 的话就能赢下来；说离了题，反过来多半输。
