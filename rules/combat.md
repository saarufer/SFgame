# 战斗结算（托管）

托管的仗由 `scripts/resolve_battle.py` 执行。GM 只负责准备输入、解读输出。
玩家亲临指挥的仗，改用 `scripts/tactical.py`，规则见 `rules/tactics.md`。

## 输入

旧格式照样能用。新增字段都可以省略：

- `terrain`：plain、steppe、river、forest、mountain、pass、city（也可写中文，见 terrain.md）。
- 每一方可加 `"formed": true`，或 `"tactic": "formed"`：表示步阵严整、有准备（列阵待敌、设了拒马、阵脚已稳）。
  - 守城一方自动算严整。
  - 本方 `tactic` 是 `surprised`，或对方 `tactic` 是 `ambush` 时，一律不算严整。
  - 什么时候算严整由 GM 判断：守方提前得到斥候消息、在阵地上等着，通常算；行军途中遇敌、夜里被袭，不算。
    攻方步兵稳步推进、列阵而前，也可以算。
- 兵种代码见 units.md，可用别名。
- 每一方可加 `"morale_bonus": N`：开战前士气的加减，加完夹在 0–100。阵前单挑的胜负由 `scripts/contest.py` 给出这个数（`rules/contest.md` 第七节）。
- `统率`、`武勇` 取主将人格卡上的“统”“武”（`rules/people.md`）。主将带着重伤或危的伤势，统率按 5 写、不写 `charge`；轻伤照常。
- 每一方可加 `"armor"`（护甲）和 `"drill"`（操练），不写就用兵种默认值（units.md“护甲与操练”）。
  可以整方写一个值（`"drill": "elite"`），也可以按兵种写（`"armor": {"heavy_cavalry": "barded", "infantry": "light"}`）。
  护甲：`none` 无甲、`light` 皮甲、`heavy` 铁甲、`barded` 人马俱甲；操练：`raw` 新募、`regular` 堪战、`elite` 精锐。中文也认。
  某支军平时就是精锐、披重甲的，在 `world/armies.json` 那支军上写同样的 `armor`、`drill`，GM 准备输入时照抄过来。

## 战力计算

```
战力 = Σ 各兵种 [人数/1000 × 基础战力 × 对阵系数 × 地形修正] × 士气/80 × 统帅修正 × 战术修正 × 随机修正
```

- **对阵系数**：本兵种对敌方每个兵种的优势系数 e，开平方后按敌方人数比例加权。
  e 只写一个方向；反过来取倒数。开平方是为了把一个系数分到双方身上：e = 1.44 时，骑兵一方 ×1.2，步兵一方 ×1/1.2。
- 统帅修正 = 1 + (统率 - 5) × 0.04
- 操练、护甲修正（每个兵种单算，只在和默认值不同时起作用，按比值乘）：
  操练 新募 0.85、堪战 1.0、精锐 1.15；护甲 无甲 0.9、皮甲 1.0、铁甲 1.12、人马俱甲 1.25。
  例：精锐的具装 ×1.15；轻骑披了铁甲 ×1.12；具装只披铁甲（马不披甲）×1.12/1.25 ≈ 0.9。
- 战术修正：伏击成功 ×1.3；仓促应战 ×0.85
- 随机修正：双方各乘一个 0.85 到 1.15 之间的随机数
- 地形修正见 terrain.md：守方地利（山 ×1.15、隘口 ×1.25、河 ×1.1、林 ×1.05，只给步兵、弓弩，河岸也给骑兵）；
  城池守方步兵、弓弩 ×1.5，攻城骑兵 ×0.6，守方再乘 (1 + 城防/200)。

### 骑兵对步兵系数（冲击骑兵对近战步兵）

| 地形 | 对没列阵的步兵 | 对严整的长枪阵 |
|---|---|---|
| 草原 | 1.60 | 1.25 |
| 平原 | 1.45 | 1.15 |
| 河岸 | 1.40 | 1.15 |
| 林地 | 1.20 | 1.00 |
| 山地 | 1.25 | 1.05 |
| 隘口 | 1.20 | 1.00 |
| 城池 | 1.00 | 1.00 |

- 骑兵每千人的基础战力是 1.6，步卒 1.0，所以这里的 1.0 已经意味着骑兵打不出冲击优势。
- 严整的步卒（infantry）按七成长枪阵算，民兵按四成算：系数 = 松散值 − (松散值 − 严整值) × 抗冲程度。
  抗冲程度：长枪手 1.0，步卒 0.7，民兵 0.4。
- 具装骑兵：对没列阵的步兵再 ×1.15，对严整步阵只 ×1.05。

### 其他对阵系数

| 对阵 | 系数 e | 说明 |
|---|---|---|
| 冲击骑兵 → 弓弩（没有掩护） | 按上表“对没列阵的步兵” | 被冲到就垮 |
| 冲击骑兵 → 弓手（有步阵掩护） | 1.0 | 弩手 0.9；具装再 ×1.15 |
| 骑射 → 步兵（平原、草原） | 严整 1.25，松散 1.15 | 密集的阵好射 |
| 骑射 → 步兵（河岸） | 1.0 | |
| 骑射 → 步兵（林、山、隘口、城） | 0.8 | |
| 骑射 → 弓手 | 0.95 | 射程相当 |
| 骑射 → 弩手 | 0.8 | 弩射得远 |
| 具装 → 轻骑 | 1.25 | 轻骑披铁甲 1.1，人马俱甲 1.0 |
| 具装 → 骑射 | 开阔地 0.9，其他 1.0 | 追不上 |
| 弓弩 → 严整步兵 | 1.2 | 林地 ×0.9 |
| 弓弩 → 松散步兵 | 0.85 | 被近身吃亏 |

| 其余 | 1.0 | |

“有掩护”：本方严整，且近战步兵不少于弓弩人数的一半；守城时自动有掩护。

## 交战烈度

- `assault`（决战 / 强攻）：伤亡高，能决定地区归属
- `skirmish`（试探 / 袭扰）：伤亡低，不改变地区归属

## 结果

- 战力高的一方获胜。攻方以 55% 以上的战力占比获胜，才能占领地区；守方残部撤往相邻的己方地区。
- 败方士气 -15 到 -25。
- 主将武勇高、又亲自冲阵的，有小概率阵斩敌将，也有小概率自己负伤（由脚本判定）。

## 伤亡

旧版里，两边的伤亡都按“对方战力占比”折成自己兵力的百分比，所以骑兵哪怕打赢，伤亡百分比也常和步兵相近。
现在分开算：胜方死多少，看败方真正打出了多少杀伤，再被胜方的甲和阵形挡掉一部分；败方死多少，看胜方的冲击、追击，以及败方是不是一冲就散。

每个兵种单算，按四步：

### 1. 交锋

```
交锋伤亡率(本方某兵种 v) = 烈度率 × 对方战力占比 × 1.6 × 受创系数(v)
受创系数(v) = Σ 对方各兵种 u 的人数比例 × 透甲(u→v) × 接阵(u→v) × 对方操练杀伤(u) × 本方操练受创(v)
```

- 烈度率 assault 0.30、skirmish 0.10。两边都是皮甲、堪战的步卒对打时，受创系数是 1，和旧版一样。
- **透甲**：对方兵器打在本方甲上透进去几成，以打皮甲为 1。

  | 甲 | 挡近战（透进几成） | 挡箭（透进几成） |
  |---|---|---|
  | 无甲 | 1.0 | 1.0 |
  | 皮甲 | 0.8 | 0.75 |
  | 铁甲 | 0.55 | 0.4 |
  | 人马俱甲 | 0.4 | 0.25 |

  破甲：兵器能把甲的作用抵消几成。具装（骨朵、铁锏、马槊）0.5，长枪 0.2，步卒、轻骑 0.15，弩 0.3，弓、骑射、民兵 0。
  透甲 = [1 − (1 − 甲的透进值) × (1 − 破甲)] ÷ 打皮甲时的同一个值。
  结果：弓、骑射射人马俱甲 ×0.33、射铁甲 ×0.53，射无甲 ×1.33；弩破甲好些，射人马俱甲 ×0.58；步卒砍人马俱甲 ×0.59；具装打具装 ×0.78。
- **接阵**：冲不冲得起来、有没有列阵。下表的“开阔”取地形开阔度（城池按 0 算，城里谈不上冲阵）。

  | 谁打谁 | 倍数 | 意思 |
  |---|---|---|
  | 严整步阵 → 冲来的骑兵 | 1 + 0.4 × 抗冲 × 开阔 | 枪林扎马，长枪阵 1.4 |
  | 没列阵的步兵 → 冲来的骑兵 | 1 − 0.8 × 开阔 | 一冲就散，几乎还不了手；平原 0.2 |
  | 冲击骑兵 → 严整步阵 | 1 − 0.3 × 抗冲 × 开阔 | 长枪阵 0.7 |
  | 冲击骑兵 → 有掩护的弓弩 | 1 − 0.2 × 开阔 | |
  | 没掩护的弓弩 → 冲来的骑兵 | 1 − 0.7 × 开阔 | 被近身，射不了几箭 |
  | 冲击骑兵 ↔ 冲击骑兵 | 1 + 0.25 × 开阔 | 马军对冲，两边都重 |
  | 冲击骑兵 → 骑射 | 1 − 0.65 × 开阔 | 散开退走，冲不着 |
  | 步兵 → 骑射 | 1 − 0.7 × 开阔 | 追不上 |
  | 其余 | 1.0 | |

- **操练**：杀伤 新募 0.85、堪战 1.0、精锐 1.15；受创 新募 1.15、堪战 1.0、精锐 0.85。
- 骑射消耗照旧：一方骑射占全军的比例为 h，它造成的杀伤 × (1 − 0.4h)。
- 守城一方的伤亡再 ×0.8（城垛掩护）。

### 2. 一触即溃

冲击骑兵在开阔地（开阔度 ≥ 0.5）上冲没列阵的步卒、没掩护的弓弩，强攻时可能一冲就散。条件：胜方冲击骑兵占全军四分之一以上，败方这类“露着”的兵占一半以上，胜方战力占比 55% 以上。

```
一触即溃的概率 = min(1, (胜方战力占比 − 0.5) × 8) × 败方露着的比例 × min(1, 胜方冲击骑兵比例 × 2)
               + 0.15 × 胜方披铁甲、人马俱甲的冲击骑兵比例 + 败方操练（新募 +0.15，精锐 −0.2）
```

一触即溃时：胜方交锋伤亡再 ×0.6（败方没怎么还手）；败方交锋伤亡 ×0.7（死在阵前的少，死在追击里的多）；败方算作溃散。

### 3. 溃散

- 一触即溃，或者败方士气跌破 30、有 60% 概率（新募 75%，精锐 40%）崩溃，都算溃散。
- 溃散时败方每个兵种再加 10% 的损失（骑兵 5%），乘本方操练受创。
- 败方骑兵比胜方多的，交锋伤亡 × 脱身系数：1 + 0.6 × (胜方骑兵占比 − 败方骑兵占比) × 开阔度，下限 0.85。

### 4. 追击

```
追杀人数 = Σ 胜方各兵种 [人数 × 追击力 × 操练杀伤] × 士气/80 × 开阔度 × (溃散 1.0，没溃 0.25)
```

- 追击力（每人）：轻骑 1.0，骑射 0.8，具装 0.7（马重，追不远），步卒 0.08，长枪 0.06，弓弩、民兵 0.05。
- 追杀的人摊到败方各兵种：步兵、弓弩按人数摊，骑兵按三成、骑射按两成摊（跑得掉）。
  每个兵种最多再折掉剩下人数的 40%（没溃时 20%），再乘上面的摊分比例。
- 追杀的人里，溃散时四成算生俘，没溃时两成半。俘虏记在输出的 `captured` 里，也算在败方的 `losses` 里。
- skirmish 只在溃散时追，追杀人数再 ×0.4。

单个兵种的伤亡率上限 90%。

## 输出

和旧版相同的字段（winner、power、losses、remaining、morale_after、region_captured、events），另加：

- `notes`：写战报用的提示，例如“步阵严整，骑兵正面冲击受阻”“胜方骑兵追击”“一触即溃，胜方几乎没有折损”。
- `captured`：本方俘获的敌兵，按敌方兵种（和 `tactical.py` 的 `captured` 同义）。这些人已经算在对方的 `losses` 里；怎么处置（编入、放还、充役）由 GM 定。
- `state`：本场用到的地形、双方是否算严整、`pursuit`（败方总伤亡 ÷ 交锋伤亡）、`routed`（败方是否溃散）、`collapse`（是否一触即溃）、`traits`（各兵种的护甲·操练）。

`--trials N`：同一场仗跑 N 次，只输出攻方胜率、夺地率、平均伤亡和伤亡中位数（`attacker_loss_median`、`defender_loss_median`、`winner_loss_median`、`loser_loss_median`），供调平衡时用，不要用来结算正式战斗。

- 骑兵在开阔地上冲垮没列阵的步兵、没掩护的弓弩，胜方伤亡从两成降到百分之几，败方照旧四五成以上。
- 骑兵冲严整步阵冲不动的，自己伤亡比旧版重，步阵伤亡比旧版轻（“冲阵不动，自损在先”）。
- 步兵对步兵、山林隘口里的仗、攻城，和旧版相差无几。
- 平原、草原上，骑兵碰上没列阵的步兵几乎必胜；步兵列好阵，平原上大致五五开，长枪阵占上风。
- 河、林、山、隘口里，同等钱粮的步兵占优；列了阵更稳。
- 随机修正只有 ±15%，双方战力差一成多，胜率就会拉开到七八成，所以“列不列阵”“在什么地形打”“是不是精锐”最要紧。

## 围城

攻城方不强攻、只围困的话：每季城防 -20，城内粮草照常消耗，不发生战斗。
