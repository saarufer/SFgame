# 见闻与支线

每季结算之后，GM 写一两段小景：一个人，在一个地方，碰上一点季节里的事，嘴里带出眼下局势的一角。
不设事件库。脚本只抽素材（种子），小景由 GM 依种子现写。

几条底线：

- **见闻不改主线数字。** 小景里出现的钱粮、兵马、人事，都不进存档，除非玩家搭理了、开成支线、按规则结算。
- **带情报的见闻守战争迷雾。** 小人物只说他在那个地方合理能见到、听到的。可以模糊，可以有误差，可以错。
- **玩家搭理了，才变成支线。** 不搭理，这段小景就只是一段日子。

## 一、种子：`scripts/vignette.py`

```
python3 scripts/vignette.py [--seed N] [--count N] [--intel | --no-intel] [--war] [--apply]
```

每颗种子有四样，外加一样可选：

| 项 | 从哪里来 |
|---|---|
| 人物 | 人格卡（`characters/`）、`kingdom.json` 的官员和人才、小人物名册（`world/people.json`），或者一个“新面孔”（只给身份，比如驿卒、盐户、马贩，GM 起名） |
| 地点 | 己方的地区，人物有驻地就多半在驻地；再按地形挑一个小去处（城门洞、酒肆、烽燧、牧场……） |
| 季节细节 | 本季的一样景物或日常（河冰刚开、新麦晒在城墙根下……），只是落笔的由头。素材表剧本可以在 `scenario.json` 的 `flavor` 里换成本地的 |
| 局势张力 | 近来消息（`kingdom.json` 的 intel）、民情、士气低的军队、敌对或观望的邻境、进行中的支线、待办命令、委任方面的例外 |
| 情报（可选） | 一条真实信息：`gm_secrets.md` 里仍在起作用的条目，或者非己方军队的动向。附“知情程度”：亲眼所见、听人转述、市井传言 |

- 默认太平季抽两颗，战事季（本季经济结算有战乱地区，或加 `--war`）抽一颗。
- 情报默认太平季约四分之一、战事季约四成带上；`--intel` 每颗都带，`--no-intel` 都不带。带情报的种子，人物多半是小人物；和种子地点、近邻、人物沾边的消息更容易抽中。已死、已离去的人的旧秘密不会抽到。
- 不加 `--apply` 只打印。定稿后用同一个 `--seed` 加 `--apply` 再跑一次，把用过的人物、地点、季节细节、张力、情报记进 `world/vignette_log.json`。下次抽种子时，最近六颗用过的人物、最近四颗用过的张力和季节细节、用过的情报都会避开。
- 同一个 seed 在同一份存档上抽出的种子相同。

种子只是素材。人物和地点对不上（例（唐末朔方）：凉州的军使出现在华州），GM 可以替他找个缘由（押送、路过、探亲），也可以换一颗。

## 二、怎么写

- **篇幅**：太平季一两段，战事季零到一段。每段一两百字。和战报放在一起时，写在战报之后。
- **文风**：照 `CLAUDE.md` 的“文风”一节。白描：写他在做什么、说了什么、手边有什么。人物有自己的口吻，有一两样具体的细节（缺了门牙、皮囊里装着奶酒）。不替读者下结论，不点评人物。
- **带情报的**：先看知情程度。
  - 亲眼所见：他见到的那一截，人数、旗号、方向大体对，细节有出入。
  - 听人转述：人数可以差到五成上下，时间说得含糊。
  - 市井传言：大意沾边，会添油加醋，或者把两件事说成一件。
  只写他能知道的部分。真实信息和他说错的地方，记进史书的 GM 备注，不告诉玩家。
- **新面孔**：写完给他起名，用 `persona.py gen 名 --role 身份 [--hint 特征] --apply` 记进名册，同时按身份表生成属性（`rules/people.md`）。只说一句话、不会再出现的龙套可以不建。再写到名册里的人，用 `person seen` 记一笔出场。
- **写人**：名册里的人有属性和性情，写的时候照着来（口吃的人说话磕巴、胆小的人缩着）；写给玩家的只是印象，按主角的识人进度取（`persona.py impress`），不出数字。

## 三、小人物名册：`world/people.json`

例（唐末朔方）：

```
python3 scripts/persona.py gen 胡豁牙 --role 老卒 --hint 缺了门牙 --hint 酒后爱拍桌子 --where 华州 \
    --trait 缺了门牙，酒后爱拍桌子 --event "华州酒肆里说白毦兵吃的是康都统的饭" --apply
python3 scripts/vignette.py person seen 胡豁牙 --event "随军东去虎牢" --where 虎牢关 --apply
python3 scripts/vignette.py person show [名字]
```

每人记：姓名、身份、所在、一句特征、状态（在 / 死 / 离去）、出场记录、人格卡路径（长成人物后），以及属性块、识人进度、伤势（`rules/people.md` 第二节）。
`vignette.py person add` 还能用，但它只记名字和特征，不生成属性；新人用 `persona.py gen`。

`persona.py gen` 也写这本名册（多出属性块 `persona`、识人进度、伤势），两个脚本读写的是同一份，格式见 `rules/people.md` 第二节。

名册里的人会再被种子抽到，可以长大：老卒升了队正，账房做了小吏。到他要独当一面、带兵、或者在大事里有自己的主意时，用 `persona.py promote 名 --card characters/<拼音>.md --kind 将领 --apply` 建人格卡：属性照搬名册（名册里的属性本来就是按身份表生成的，不另设上限），部曲从 10 以下起。

## 四、支线：`world/threads.md`

玩家对某段见闻有了动作（“叫那个账房来问话”“派人去查”），GM 就在 `world/threads.md` 开一条。例（唐末朔方）：

```
### [T3] 华州酒肆的老卒
- 起因：天祐十九年秋见闻，白毦兵老卒胡豁牙在酒肆里说“吃的是康都统的饭”
- 人物：胡豁牙（名册）；牵涉 康怀贞
- 悬念：这是一个老卒的酒话，还是营里的风气
- 可能的结果：情报（白毦兵营中的风气）；心结（查到康怀贞头上，按“查账、派人盯着”记）
- 状态：进行中
- 开启：天祐十九年秋（第 82 回合）
- 最迟：天祐二十年夏（第 85 回合）
- 记录：
  - 第 82 回合：主公命马鸣派人去华州
```

- 编号依次排，字段名照写，每个字段一行。`vignette.py threads` 会读“状态”和“最迟”，列出到期、过期的支线。
- **最迟几季了结**：一般两到四季。到期那一季，GM 把它收束：有结果的结算，没结果的写清“查无实据”或“人已离去”，状态改为“已了结（……）”或“作罢（……）”。
- 进行中的支线也会被抽成种子的“局势张力”，可以在小景里再露一面。

### 支线的结果怎么进存档

支线的结果都要走规则或脚本，不凭叙述直接加数字。

| 结果 | 怎么结算 |
|---|---|
| 人才 | 名册里的人升为人才：写进 `kingdom.json` 的 `talents`；要带兵或常被召见的，`persona.py promote` 建人格卡 |
| 情报 | 写进 `kingdom.json` 的 `intel`，按小人物的知情程度措辞；真实与否记进 GM 备注 |
| 物资 | 一次性的钱粮马走 `economy.py --extra-income / --extra-grain`（或 `--extra-cost`）。一条支线的进项，不超过帅府一季钱收入的一成 |
| 长期收益 | 开成一项工程，按 `rules/economy.md` 的办法投钱，写进 `economy.json` |
| 心结变化 | 牵涉将领的，按 `rules/loyalty.md` 第三节记（`grudge`、`ease`）。比如查到他头上记“查账”心结 2；替他洗清了，可以算一次“补偿” |
| 打仗 | 照常用 `resolve_battle.py` |

支线的事算不算帅府亲裁的一件（`rules/governance.md` 第六节）：玩家亲自过问的算，交给幕僚去办的走 `council --assign`。

## 五、家事小景

`python3 scripts/vignette.py --family [--seed N] [--war] [--apply]` 从 `world/household.json` 抽家里的人和事：最近被冷落、生病、到了人生节点、有孕、待嫁的人更容易抽中。
太平季两颗，战事季或主角出征时一颗，写成一封家书。写法和见闻一样，规则见 `rules/household.md` 第七节。家人卡（身份“家人”）和主角卡不会被普通见闻抽到。

## 六、GM 每回合怎么做

1. 结算、写存档之后，跑 `python3 scripts/vignette.py`，看种子。
2. 依种子写一两段（战事季零到一段）。带情报的，按知情程度写，真实信息和误差记进 GM 备注。
3. 定稿后，同一 seed 加 `--apply` 再跑一次；新面孔用 `persona.py gen … --apply` 记进名册（带属性）。
4. 见闻写进 `chronicle/turn_NNN.md` 的“见闻”一节，并随汇报给玩家（放在战报和数字表之间，或末尾）。
5. 跑 `python3 scripts/vignette.py threads`，到期的支线本季收束；玩家新搭理的见闻，开支线。
6. 跑 `python3 scripts/vignette.py --family`，写一段家事（上一节）。

## 七、示例（唐末朔方）

下面三颗种子取自上一局天祐十九年秋的存档（草稿副本，只读），依次加 `--apply` 抽出。

### seed 11（不带情报）

```
人物：郑元规（官员：同中书门下平章事）
地点：滑州·寺门前
季节：赋税收上来，衙门口排着长队
张力：〔待办〕派使者赴契丹接回周延嗣。（周的抉择待定）
情报：无
```

> 滑州收秋税，衙门口的队排到了寺门前。郑元规巡察河南州县，路过这里，下了车，在队尾站了一会儿。一个挑着两筐枣的老汉打量他，问：“官人也是来交税的？”郑元规说不是。老汉放下担子，说：“听贩羊的讲，北边契丹也收汉人做官，有个姓周的，从前是灵州的大官。”郑元规问他那边的税重不重。老汉说：“这就不知道了，贩羊的只说那人穿的是汉人衣裳。”队往前挪了一步，老汉挑起担子跟上去。郑元规回到车上，叫随从把这几句记下来。

（待办那一条在上一局已经过时，周延嗣早已北去。GM 把它写成市井里的一句旧闻。）

### seed 27（带情报）

```
人物：没藏讹多（官员：安西军使）
地点：华州·酒肆
季节：夜里已经冷，哨兵换上了夹袄
张力：〔近来消息〕王宗播自成都遣使朝贺，献蜀锦千匹。
情报（真实）：〔隐情〕康怀贞兵权过重：白毦兵如今步 13878、骑 2500，全在他手里。
知情程度：听人转述
```

> 没藏讹多押着凉州的贡马东去长安，在华州歇了一夜。酒肆不大，靠门一桌坐着几个白毦兵的老卒，身上已经换了夹袄。一个缺了门牙的拍着桌子说：“白毦兵两万多人，都是康都统一手带出来的。”旁边的人拉他袖子，他甩开，又说：“蜀里送来的锦缎，长安分了一车，我们营里也分了一匹。韩公是韩公，我们吃的是康都统的饭。”讹多端着碗，没出声。店家过来添酒，低声说：“这位军爷天天来，天天这几句。”讹多问他叫什么，店家说营里都叫他胡豁牙。

GM 备注：白毦兵实有步骑约一万六千四，老卒说“两万多”，多说了三成多，合“听人转述”。他知道的只是营里的说法，不知道帅府里有人在掂量这件事。胡豁牙记进名册。

### seed 64（带情报）

```
人物：新面孔——部落少女
地点：许州·城墙马道
季节：马肥了，营里在试新鞍
张力：〔近来消息〕太庙告祭，李洙立为皇太子；加韩逊尚父。
情报（真实）：〔隐情〕没藏营骑 1845，兵籍粮饷归节度府，根子仍在没藏部。
知情程度：市井传言
```

> 许州城墙的马道上，一个贺兰山来的姑娘提着皮囊往上走，皮囊里是给她阿哥的奶酒。阿哥在郑许镇军里当骑卒，这几日营里在试新鞍，马都喂得滚圆。守门的兵拦住她，她掏出阿哥的腰牌，说话带着山里的口音。兵问她怎么一个人走这么远，她说跟着贩马的队伍，走了一个多月。说起京里立太子，她说山里都传遍了，太子的外婆家是回鹘人，“那就和我们是一边的”。临走她又说，没藏家的骑兵领的是节度府的饷，可马和老婆孩子都在山里，“头人说往哪边，他们就往哪边”。守门的兵把这话当笑话，讲给了队正听。

GM 备注：真实的只到“根子在没藏部”。“头人说往哪边就往哪边”是她添的，没藏营眼下没有异动。她叫阿朵，记进名册（贺兰山部落少女，眼下在许州，一句特征：皮囊里装着给阿哥的奶酒）。
