# 人物属性、生成与识人

凡是有名有姓的人，都有同一套属性：主角、将领、君主、家人、幕僚、使者，也包括见闻里碰到的路人。
有了属性，玩家想和谁辩一场、打一架、比一回射，都能交给脚本结算（`rules/contest.md`）。

- 属性怎么来：人格卡上的人，GM 照人物设定填；名册里的小人物，由 `scripts/persona.py` 按身份表生成。生成逻辑固定，同一个人每次生成的结果都一样。
- 玩家看不到数字，只看到印象。主角对每个人有一个“识人”进度，进度越深，印象越准（第七节）。
- 本文的几张表（身份表、特长、短处、提示词、性情、描述词）由 `persona.py` 直接读取。改表就改了生成和印象，不用改脚本；改的时候守住表头和格式。

本文的例子取自唐末朔方剧本，标作“例（唐末朔方）”。

---

## 一、属性

十一项，刻度 1–10，5 是常人中等。

| 属性 | 意思 | 用在哪里 |
|---|---|---|
| 统 | 统兵。带过兵的叫统率，没带过的是潜质 | 战斗的统帅修正（`resolve_battle.py`、`tactical.py` 里的“统率”）、委任方面 |
| 武 | 武艺膂力：刀枪、拳脚、力气 | 单挑、打架、冲阵（战斗输入里的“武勇”） |
| 智 | 谋略：算计、看破、识人 | 诈术和看破诈术、辩论、主角的眼力 |
| 骑 | 骑术：驭马、马上腾挪 | 马上单挑、马上比射 |
| 射 | 射艺：弓弩的准头 | 比射、游走骑射 |
| 体 | 体魄耐力：力气能撑多久、扛不扛伤 | 单挑、打架的体力，伤后恢复 |
| 胆 | 胆气：临阵不慌、敢不敢拼 | 单挑、辩论的气势，比射的最后一轮 |
| 辩 | 口才：说话、应对 | 辩论、出使、说服 |
| 学 | 学识：读书、典故、律令、算学 | 引经据典、断案、文书 |
| 政 | 理事：钱粮、案牍、人事 | 办差、断案、方面治理（GM 参照） |
| 魅 | 人望：让人服气、愿意跟他 | 以情动人、招人、当众说话 |

统、武、智三项和人心账本里原有的同名同义，人格卡上只写一套。

| 刻度 | 说法 |
|---|---|
| 1–2 | 很差 |
| 3–4 | 偏弱 |
| 5–6 | 常人 |
| 7–8 | 出色 |
| 9–10 | 拔尖（10 是一时罕有的） |

另外每人还有：

- **性情**：一句话，写成做事的样子（“说话直，不怕得罪人”）。
- **特长**：一到三个标签（善射、识马、懂算学、熟读经史、水性好、通胡语……）。表里有的特长，在较量里有加成；表里没有的也可以写，只作描写。
- **短处**：一个（性急、贪杯、口吃、胆小……）。表里有的短处会改属性或较量；没有的只作描写。受了重伤可能多一个“旧伤”。
- **伤势**：无，或 轻伤 / 重伤 / 危，带部位和还要养几季（`rules/contest.md` 第六节）。
- **识人**：主角对这个人知道多少，0–3（第七节）。
- **名望**（可选）：他在士林、军中、市井、诸蕃这几种口碑里的名声，0–10。人格卡写一行 `名望: 士林6 军中3 市井4 诸蕃1`，名册写 `名望` 字段；没写的按 2（无闻）。名望是旁人对他的评价，不是本事，流言、廷辩、朝议会改它，规则见 `rules/rumors.md` 第三节。

## 二、人物记在哪里

| 人 | 记在哪里 | 属性怎么来 |
|---|---|---|
| 主角 | 主角卡 `characters/<拼音>.md` 的数值块 | 剧本给默认值；`/newgame` 按出身、性格、年纪调整（第九节） |
| 将领、君主、家人 | 人格卡的数值块 | GM 照人物设定填（剧本作者写卡时就填好） |
| 幕僚、使者、路人、小兵 | 小人物名册 `world/people.json` | `persona.py gen` 按身份表生成 |

人格卡数值块里的写法（例（唐末朔方）：薛崇）：

```yaml
统: 6              # 统兵 1–10（十一项属性见 rules/people.md）
武: 9              # 武艺膂力
智: 4              # 谋略
骑: 9              # 骑术
射: 7              # 射艺
体: 8              # 体魄耐力
胆: 9              # 胆气
辩: 3              # 口才
学: 2              # 学识
政: 3              # 理事
魅: 6              # 人望
特长: 冲阵、使槊、识马
短处: 性急
性情: 粗直，心里有气脸上就看得出来
识人: 3            # 主角对他知道多少：0 初见 / 1 略知 / 2 熟知 / 3 知根知底
伤势: 无           # 无，或 轻伤｜部位｜余 N 季（scripts/contest.py heal 逐季恢复）
```

冒号用半角，值里不要再出现半角冒号和 `#`；特长用顿号隔开。

名册里每人一条（旧字段照旧，`vignette.py` 照常能读），多出 `persona`、`识人`、`injury`。例（唐末朔方）：

```json
{"name": "王二", "role": "老卒", "where": "灵州", "trait": "左手少两指", "status": "在",
 "appearances": ["天复二年春（第 1 回合）：城门洞里讲当年守盐州的事"], "card": null,
 "persona": {"identity": "老卒", "age": 52, "sex": "男", "hints": ["左手少两指"], "seed": "唐末朔方|王二|老卒",
             "attrs": {"统": 4, "武": 5, "智": 5, "骑": 6, "射": 4, "体": 5, "胆": 7, "辩": 3, "学": 1, "政": 3, "魅": 5},
             "tags": ["熟知军中旧事"], "flaw": "贪杯", "temper": "说话直，不怕得罪人", "surprise": null},
 "识人": 0, "识人记录": [], "injury": null}
```

名册顶上另有一张 `acquaintance`：别人对某人知道多少（例（唐末朔方）：`{"薛崇": {"韩逊": 3}}` 是薛崇对韩逊知根知底）。主角对别人知道多少，记在那个人自己的卡或名册条目上（`识人`）。

“年纪”写常见的年纪范围，GM 不给年纪时在这里面取；后面带“女”的，不给性别时默认是女的。

## 四、剧本追加的身份

剧本可以在 `scenario.json` 里加一节 `people`：

```json
"people": {
  "identities": [
    {"name": "盐户", "base": "农夫", "aliases": ["盐丁"], "attrs": {"体": 7, "胆": 5}, "tags": ["能吃苦", "认路"]},
    {"name": "押衙", "base": "军官", "age": "30-55", "attrs": {"统": 5, "政": 4}}
  ]
}
```

- `base` 照抄一行引擎身份，再用 `attrs`（均值，或写成 `"7±2"`）、`tags`（常见特长）、`flaws`（常见短处）、`age`、`sex` 覆盖；不写 `base` 的，十一项属性都要写全。
- `name` 和引擎身份同名的，整行替换引擎那一行。
- 剧本追加的身份只在这个剧本里用。`scenario_check.py` 会核对 `base` 存在、属性在 1–10 之间。

## 五、特长、短处、提示词

### 特长

“生成时”是 `gen` 掷到这个特长时属性的加减；“较量”是它在 `contest.py` 里的加成，写的是种类（马战、步战、打架、比射、辩论）、打法（猛攻、缠抱摔跤、引经据典……）或场合（朝堂）的名字，对上了就加在本方每合的分上。一个人的特长加成合计最多 +1。
“诈术+10%”是诈败回马、使绊子的成功率；“眼力”是识人时的眼力；“体力+10%”是较量里的体力。
GM 手写人格卡时，属性已经照人物设定定好，特长只算较量加成，不再加属性。

## 六、生成：`persona.py gen`

```
python3 scripts/persona.py gen 王二 --role 老卒 [--age 52] [--sex 男] [--hint 左手少两指 --hint 说话带酒气] \
    [--where 所在] [--trait 一句特征] [--event 出场] [--apply]
```

1. **种子固定**：随机种子取“剧本 id｜姓名｜身份”的哈希。同一个剧本里，同一个名字、同一个身份，每次生成的结果都一样；换一个剧本，结果不同。
   名册里已经有这个人的，`gen` 直接给出名册里的属性，不重掷。重名的两个人，名字上加个区分（“东市王二”）。
2. **年纪、性别**：GM 不给，就按身份表的年纪范围和性别取。
3. **掷属性**：每项 = 身份均值 + 正态浮动（默认 1.2），四舍五入，夹在 1–10。身份表写的是掷特长、短处之前的均值，掷完特长、短处，实际均值会偏一点（壮汉常带“力气大”，武、体的实际均值比表上高半点到一点）。
4. **年纪修正**：按下表，算的是和这个身份常见年纪（年纪范围的中间）的差别。身份表的均值已经是常见年纪的样子，
   所以十二岁的“少年”不再减，六十岁的“老卒”（常见五十一岁，已在 45–59 一档）只再减 体−2 武−2 骑−1 射−1 学+1。

   | 年纪 | 修正 |
   |---|---|
   | 15 岁以下 | 统−2 武−2 体−2 政−2 学−1 |
   | 16–24 | 体+1 学−1 政−1 |
   | 25–44 | 不改 |
   | 45–59 | 体−1 |
   | 60 以上 | 体−3 武−2 骑−1 射−1 学+1 |

5. **性别**：身份默认是男的、生成的是女的，武−1 体−1。
6. **提示词**：按第五节的提示词表修正。
7. **特长和短处**：从身份的“常见特长”里取一到两个（三成的人多一个表外的、随机的特长），从“常见短处”里取一个；按特长、短处表加减属性。
8. **意外**：每人有 5% 的机会某一项远超身份：在身份均值 5 以下的属性里挑一项，抬到均值 +4 到 +6（貌不惊人的好手、口拙的书生满腹经纶）；
   另有 3% 的机会某一项远低于身份：在均值 6 以上的属性里挑一项，压到均值 −3（胆小的老卒、开不了弓的猎户）。一个人至多一处意外。
   意外记在 `persona.surprise`，初见时看不出来（第七节）。
9. **性情**：照下面的性情表，按最突出的一项挑一句。

### 性情

| 条件 | 可选的说法（用“；”隔开） |
|---|---|
| 胆≥7 | 说话直，不怕得罪人；爱逞强，被人一激就上；遇事抢在前头 |
| 胆≤3 | 怕事，能躲就躲；说话小声，看人脸色；见了官差先低头 |
| 智≥7 | 话不多，心里有数；爱琢磨人，问一句答半句；凡事先算账 |
| 辩≥7 | 爱说话，一开口就停不下；会讨人欢心；嘴上不吃亏 |
| 辩≤3 | 闷葫芦，问三句答一句；不爱说话，手上有活就安心 |
| 魅≥7 | 爱交朋友，到哪里都有熟人；讲义气，替人出头 |
| 体≥7 | 闲不住，总要找点力气活干；吃得多，睡得香 |
| 学≥7 | 爱讲道理，动不动引书上的话；看不起粗人，嘴上不说 |
| 其他 | 老实本分，交代什么做什么；爱占点小便宜，大事上不糊涂；脾气好，挨了骂也不记仇；有点倔，认准的事不改；爱打听，谁家的事都知道一点 |

`gen` 不加 `--apply` 只打印；加了就写进名册（新人加一条，已有的人补上 `persona`）。
`python3 scripts/persona.py stats --role 老卒 --n 200` 抽样看某个身份的均值和意外比例，调表时用。

## 七、识人

玩家看不到数字，只看到印象。主角对每个人有一个识人进度：

| 进度 | 叫法 | 玩家知道的 |
|---|---|---|
| 0 | 初见 | 只有外表和第一眼的感觉：身形、神色、气度，加上 GM 记下的特征。可能看走眼 |
| 1 | 略知 | 一两项最突出的长处或短处的大概（“听说他射艺不错”）。可能有误 |
| 2 | 熟知 | 大部分有数，连特长、短处（“刀马娴熟，只是体力差些”） |
| 3 | 知根知底 | 心里有底，能拿熟人作比（例（唐末朔方）：“他的武艺约在薛崇之下”），意外也看得出来 |

```
python3 scripts/persona.py impress 王二 [--level N] [--by 观者] [--gm]
```

`impress` 按进度写一段印象，全是白描，不出数字，可以直接改写进叙述。`--gm` 在每句后面标出实数和看走眼的地方，只给 GM 看。

### 眼力和看走眼

- 主角的**眼力** = 主角的智；有特长“识人”再 +2，“眼力好”+1。别人看人（`--by 某将`）用那个人的智。
- 每项印象 = 实数 + 偏差。偏差的大小看进度和眼力：初见 2.2、略知 1.3、熟知 0.7、知根知底 0.3，眼力每比 5 高一点少 0.15（最少是原来的一半），每低一点多 0.15。
- 偏差按“观者｜对象｜进度”取固定的种子，同一个进度下看走眼的地方不会每次都变；进度一涨，重新看。
- **意外**在初见时看不出来（按身份的寻常样子来看），略知时有一半机会看出来，熟知以后看得出来。
- **藏拙**：特长里有“藏拙”，或者性情里写着“深沉”“不露”的，初见、略知时，各项印象往常人那里拉回一半。
- **打听来的误差**：派人打听（见下）时，脚本会在一项属性上记一个传闻偏差（±2），略知时照传闻说，熟知以后才纠正过来。

### 进度怎么涨

| 怎么来的 | 涨多少 | 上限 | 说明 |
|---|---|---|---|
| 见面 | 不涨 | — | 只记一笔 |
| 长谈 | +1 | 2 | 召见深谈一次，不是寒暄；同一人每季最多算一次 |
| 共事 | +1 | 2，满四季的共事可到 3 | 一同出征、一同办一件差，季末记一次 |
| 交手 | +1 | 3 | 较量过一场（单挑、打架、比射、辩论），双方互相 +1；`contest.py --apply` 自动记 |
| 打听 | 到 1 | 1 | 派人打听，最多到略知，而且有一项是传闻，可能不准 |

```
python3 scripts/persona.py know 王二 --how 长谈 [--by 观者] [--note 说明] [--apply]
python3 scripts/persona.py know 王二 --how 共事 --long --apply      # 共事已满四季，可到知根知底
python3 scripts/persona.py know 王二 --set 2 --note "GM 校正" --apply
```

人格卡上的人，初建卡时 GM 照旧事定一个进度：主角一手提拔、朝夕相处的部将，2 到 3；母亲、妻子、兄弟，3；年幼的子女 2；外镇的君主 1，没见过面的 0。

## 八、升格成人格卡

名册里的人有了兵权、成了幕僚，或者在大事里有了自己的主意，就升格成人格卡：

```
python3 scripts/persona.py promote 王二 --card characters/wang-er.md --kind 将领|家人|君主 [--apply]
```

- 照模板（`characters/_template.md`、`_template_kin.md`）生成一张卡：属性、特长、短处、性情、识人、伤势照搬名册；名册里的出场记录抄进“记忆”；人心账本留着模板的占位，GM 当场按 `rules/loyalty.md` 填需求，阶梯从“安分”（家人“亲近”）起。
- 名册里这一条的 `card` 填上路径，以后脚本都读卡。
- 属性照搬，不另设上限：名册里的属性本来就是按身份表生成的。

## 九、主角的属性

主角卡的属性在剧本里有默认值。`/newgame` 按玩家的回答调整，规矩是**总和不变、统兵最多动 1**：

```
python3 scripts/persona.py hero characters/<主角>.md --origin 将门之后 --temper 刚猛 --temper 重情 [--age 39] [--apply]
```

1. 出身：剧本出身选项的 `effect.attrs` 有写的照它；没写的，按下表找关键词。
2. 性格：按下表，每项一加一减。
3. 年纪：三十岁以下 体+1 学−1；五十岁以上 体−1 学+1。
4. 加完以后，总和比原来多的，从加得最多的那几项往回扣；少的，补给出身偏高的那几项。统兵和剧本默认值相差不超过 1。每项夹在 1–10。
5. 出身表里的特长加进主角卡的“特长”（至多三个）。

## 十、GM 怎么用

1. **新面孔**：凡是第一次有名有姓出场、可能再出现、或者可能和主角有交集的人，写完那段之后用 `persona.py gen … --apply` 生成并记进名册（这一步替代 `vignette.py person add`，两者都写同一本名册）。只说一句话的龙套可以不建。
2. **写人**：写他的时候参照属性和性情，但写给玩家的只是印象：用 `impress` 按主角的识人进度取词，不写数字。
3. **涨进度**：召见长谈、一同办事、交过手、派人打听，用 `know` 记下。
4. **较量**：玩家要和谁辩一场、打一架，走 `contest.py`（`rules/contest.md`）。
5. **升格**：小人物有了兵权或成了幕僚，`promote`。幕僚同时写进 `directives.json` 的 `council.staff`，`ability` 取他的智和政里高的那一项。
6. **角色 agent**：给 general、ruler、kin agent 的 prompt 里，提到别人时，用那位角色对那人的识人进度取印象（`impress 某人 --by 这位角色`），不要给对方的数字。

### 命令一览

```
python3 scripts/persona.py gen 名 --role 身份 [--age N] [--sex 男|女] [--hint 特征 ...] [--where 所在] [--trait 特征] [--event 出场] [--apply]
python3 scripts/persona.py show 名 [--json]                 # GM 看属性（人格卡或名册）
python3 scripts/persona.py impress 名 [--level N] [--by 观者] [--gm]
python3 scripts/persona.py know 名 --how 见面|长谈|共事|交手|打听 [--long] [--by 观者] [--set N] [--note …] [--apply]
python3 scripts/persona.py promote 名 --card characters/x.md --kind 将领|家人|君主 [--apply]
python3 scripts/persona.py hero 主角卡 --origin 出身 [--temper 性格 ...] [--age N] [--apply]
python3 scripts/persona.py fill 卡片 [--role 身份] [--apply]  # 旧卡缺属性时按身份补齐（统、武、智保留卡上的）
python3 scripts/persona.py roles                             # 列出身份表（含剧本追加的）
python3 scripts/persona.py stats [--role 身份] [--n 200]      # 抽样检查
```

所有命令都有 `--world 目录`，可以拿存档副本试。卡片先在存档目录旁边的 `characters/` 找，再在项目根目录的 `characters/` 找。

## 十一、例（唐末朔方）：酒肆壮汉的四个进度

草稿副本上：`gen 马大 --role 壮汉 --hint 膀阔腰圆 --hint 提着酒 --apply`，得出 统 4 武 7 智 3 骑 2 射 2 体 9 胆 6 辩 4 学 1 政 1 魅 2，特长摔跤、能说会道，短处贪杯。
主角韩逊（智 7）按四个进度 `impress`：

```
【初见】看样子是个壮汉，三十来岁。身板结实；神色如常；不大起眼。膀阔腰圆、提着酒。
【略知】听说他体魄极壮，几天不睡也撑得住，只是不识字。膀阔腰圆、提着酒。
【熟知】体魄极壮，几天不睡也撑得住，手上有真功夫；只是不识字，理不清账目杂事，骑不了马。摔跤、能说会道，是他的本事。毛病是贪杯。
```
