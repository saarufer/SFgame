# 派系与朝议

朝中的事：谁在哪一派、哪一派说话有分量，谁任什么官、有没有议政之权，眼下悬着哪些议题、各派要什么、底线在哪里；
有人上了一道奏疏，各派附议还是反对，当殿辩一场，最后天子定夺，后果落到官职、声量、恩怨上。
主角若只是朝中一个小官，他的升降、上司对他的器重，也在这里记。

存档是 `world/court.json`，由 `scripts/court.py` 读写。关系网见 `rules/relations.md`，流言和名望见 `rules/rumors.md`，秘密见 `rules/secrets.md`。

几条底线：

- **大事不靠骰子。** 各派附议、反对还是观望，由立场、利害、关系网、圣意算出来，每一项都写明来由。骰子只在廷辩里（`contest.py` 的辩论）。
- **定夺在人。** 天子（或主事的人）怎么定夺，由 GM 调 `ruler` agent 按他的人格卡定；脚本只给“各方意见汇总”和各种定夺的后果。
- **党争有来由。** 派系之间的积怨一笔一笔记，到了一定程度才会互相弹劾、罗织罪名；要到“罗织”“死斗”，两派的人之间得先有私仇、先出过大事（第五节）。
- **朝中的事玩家多半看不全。** 玩家在场的朝议他看得见；不在场的、私下的，只能经关系网、流言、情报透露（第八节）。

本文的例子用一个中性的示例朝廷，标作“例（示例朝廷）”。剧本里的派系、官职、议题写在开局存档的 `court.json` 里（`scenarios/README.md`）。

## 一、存档：`world/court.json`

```json
{
  "version": 1, "sovereign": "李承", "fame_kind": "士林", "review_every": 4,
  "factions": {
    "法度派": {"leader": "裴衡", "members": ["裴衡", "王溥", "冯道"], "voice": 6, "stance": "守祖制，立嫡"}
  },
  "offices": {
    "中书令": {"rank": 2, "holder": "裴衡", "council": true},
    "监察御史": {"rank": 8, "holder": "沈砚", "council": false}
  },
  "issues": {
    "立储": {"title": "立储", "status": "悬而未决", "options": ["立李琮", "立李瑾", "缓议"],
             "sovereign": {"lean": "缓议", "signal": "暗示"},
             "positions": {"法度派": {"want": "立李瑾", "accept": ["缓议"], "bottom": ["立李琮"], "bottom_text": "不许以庶夺嫡", "weight": 3}}}
  },
  "memorials": [], "feuds": {}, "out": {},
  "careers": {"沈砚": {"post": "监察御史", "superior": "杜牧之", "regard": 1, "merit": 0, "duty": null, "since_turn": 1, "log": []}},
  "next_memorial": 1, "last_season_turn": 0, "log": []
}
```

| 字段 | 说明 |
|---|---|
| `sovereign` | 定夺的人（天子）。他的人格卡由 `ruler` agent 扮演 |
| `fame_kind` | 朝议看哪一种名望（`rules/rumors.md` 第三节），一般是士林 |
| `factions` | 派系：首领、成员、声量（0–10）、立场一句 |
| `offices` | 官职表：品级（1–9，1 最高）、谁任、`council` 有没有议政之权 |
| `issues` | 悬而未决的议题：选项、圣意（`lean` 天子心里的主张，`signal` 透露的程度：明示 / 暗示 / 未露，只给 GM）、各派的立场 |
| `memorials` | 奏疏，见第四节 |
| `feuds` | 派系之间的积怨，见第五节 |
| `careers` | 仕途：官职、上司、器重、考绩、差事，见第六节 |
| `out` | 不在朝的人：外放、罢官、下狱、致仕、丁忧、流放、死 |
| `ladders` | 仕途阶梯（可选）：流外小吏、武职这样一阶一阶往上走的路，每阶的品级、俸钱、管什么，见第六节 |
| `review_every` | 几季考课一次，默认 4 |

议题由剧本定，常见的有立储、削藩、清查寺田、科举、对外邦的和战。剧本没写的议题，GM 用 `court.py issue` 新建。

## 二、派系与声量

- 一个人至多在一派。首领代表全派在朝议上表态。
- **声量**（0–10）是这一派眼下说话的分量。朝议计票时，每一派按声量算。
- **根基**：这一派在朝中的位子。每位成员按他的官职算：议政之权且三品以上 3，其余有议政之权的 2，五品以上不议政 1，更低的 0.5；合计四舍五入，夹在 1–10。首领在朝议看的名望里 ≥7 的，根基再 +1。
- **声量每季向根基靠一步**（`court.py season`）。朝议的输赢让声量一时涨落，位子撑不住的，几季后落回去。

| 事 | 声量 |
|---|---|
| 本派所奏得准 | +1 |
| 本派的人被弹劾，处分到降职、外放 | −1；罢官、下狱、流放 −2 |
| 弹劾别人被驳回 | −1 |
| 本派要的主张被定下 | +1 |
| 本派的底线被破 | −1 |
| 举荐本派的人得准 | +1 |
| 外戚得宠或失宠（`rules/household.md` 第九节） | GM 可 ±1 |

GM 手改用 `court.py faction 派 --voice-delta N --why …`，写明缘由。

## 三、官职与议政

- 官职表写品级和议政之权。朝议时，**有议政之权、又不在任何一派的重臣**单独表态，分量按品级：三品以上 3，其余 2。
- 派里有议政之权的人，私人的分和本派差得远（差 3 分以上，而且表态不同）的，**不随本派**，单独记一票，分量照上。他为什么不随本派，脚本列出理由（私恩、私怨）。
- 任免：`appoint 名 --office 职`（新设官职给 `--rank`、`--council`）；`remove 名 --status 外放|罢官|下狱|致仕|丁忧|流放|死 --why …`。去职的人记进 `out`，他原来的官出缺。

## 四、上奏与朝议

### 上奏：`court.py memorial`

奏疏四种：

| 种类 | 要写 | 所请 |
|---|---|---|
| 提议 | `--issue 议题 --ask 主张` | 就一个议题定下一个主张 |
| 弹劾 | `--target 名 --penalty 处分` | 申饬、罚俸、降职、外放、罢官、下狱、流放 |
| 举荐 | `--target 名 --office 职` | 让他任某官 |
| 请辞 | （上奏的人自己） | 准他致仕 |

- `--text`：奏疏原话的摘要。玩家写的奏疏，照玩家的原话。
- `--point -1..2`：奏疏的论点分。GM 照 `rules/contest.md` 第四节的刻度给奏疏打：离题、平平、切中、绝妙。
- `--evidence`：拿出来的凭据（`secrets.py` 的证据编号、人证），每件 +1，最多 +2。
- `--cite 文献=得当|牵强|失当`：引用文献（`rules/rumors.md` 第四节），按引得当不当加减。
- `--bypass`：越过上司直接上奏（第六节）。
- `--fabricated`：弹章里有捏造的罪名（第五节）。
- `--lean 准|驳 --signal …`：这道奏疏上的圣意（GM 才知道）；不写的，提议按议题的圣意算，弹劾、举荐算“未露”。

### 朝议结算：`court.py session`

参与表态的：每一派（首领代表）、不在派里的议政重臣，以及不随本派的人。每人算一个分：

| 项 | 分 |
|---|---|
| 提议：正合本派主张 / 本派可以接受 / 和本派主张相左 / 碰了本派的底线 | +2 / +1 / −1 / −3，再乘“看重”（weight 1–3）÷ 2 |
| 自己上的奏 | +4 |
| 本派的人上的奏 | +2 |
| 上奏的人那一派和本派斗到第 N 步（相安 0 … 死斗 4） | −0.75 × N |
| 表态的人看上奏的人亲疏 c（−3..+3，`rules/relations.md`） | +0.5 × c |
| 弹劾本派的人 / 举荐本派的人 | −4 / +2 |
| 被弹劾、被举荐的人那一派和本派斗到第 N 步 | 弹劾 +0.75 × N；举荐 −0.75 × N |
| 表态的人看被弹劾（被举荐）的人亲疏 c | 弹劾 −0.7 × c；举荐 +0.7 × c |
| 被弹劾的人名重（朝议看的名望 ≥7） | −1 |
| 说被弹劾的人的流言在朝堂传开了、多半信了（`rules/rumors.md`） | +1 |
| 奏疏的论点分 | ±分 |
| 凭据 | 每件 +1，最多 +2 |
| 引文献 | `cite` 算出的加减 |
| 上奏的人名重（≥7）/ 人微言轻（≤1） | +0.5 / −0.5 |
| 圣意：明示 / 暗示，赞成这道奏疏 | +1.5 / +0.75（不赞成反过来）；未露的不算 |

分 ≥ 1.5 **附议**，≤ −1.5 **反对**，中间**观望**。派按声量计，重臣按品级计，合计附议、反对、观望各多少。

**圣意**怎么进来：天子的意思透露了多少（明示、暗示），各派就跟着掂量多少。没透露的，各派只按自己的利害表态。圣意本身只给 GM，不写进给定夺者的汇总（定夺者自己知道自己的意思）。

### 廷辩

两边都有人时，可以当殿辩一场：`session --debate 甲:乙`（甲是上奏这一边，乙是反对那一边），或者 `--auto-debate`（上奏的人对反对那一边口才最好的、在朝有官的人）。

- 走 `contest.py` 的辩论，场合“朝堂”（偏向引经据典）。玩家的原话照第四节打论点分（`--point-a`），对手的话由他的 `courtier` agent 写出来再打（`--point-b`）。打法、引文献同 `contest.py`（`--style-a`、`--cite-a`）。
- 主事者偏向：圣意赞成这道奏疏的，偏向上奏一边；不赞成的，偏向反对一边。在场的人偏向：附议比反对多 2 以上的偏向上奏一边，反过来偏向反对一边。
- **辩完**：占了上风的一边，观望的人分 +1（往他那边靠）；上奏一边把对手**说服**了的，对手那一派再 +1.5。驳倒、各执一词不改对手那一派。
- `--apply` 时：输的一方当众被驳倒，对赢的一方记怨 1（恼羞成怒记 2），公开；赢的一方朝议看的名望 +1（说服、驳倒、对方恼羞成怒），恼羞成怒的一方 −1；交过手互相识人 +1。

### 各方意见汇总和建议提示

`session` 最后打印两段：

- **各方意见汇总**：谁上奏、请什么、原话；附议的、反对的、观望的是谁；廷辩的经过；朝议所向（附议、反对各占几成）。照原样写进定夺者 `ruler` agent 的 prompt，**不写圣意、不写分数**；再加上他的情报包（`secrets.py brief 天子`）。
- **建议提示**（只给 GM）：准、驳、留中各会带来什么后果。

GM 看过再加 `--apply`，奏疏记为“已议”。同一道奏疏已经议过、记过账的，不能再 `--apply`（要重议加 `--force`）。

### 定夺：`court.py decide`

定夺者回复里的“定夺”（`.claude/agents/ruler.md`）：准、驳、留中、折中。GM 照它跑 `decide 编号 --ruling …`，看过再加 `--apply`。

| 奏疏 | 准 | 驳 |
|---|---|---|
| 弹劾 | 被弹劾的人受处分（外放、罢官、下狱、流放的去职）；他对上奏的人记怨（申饬、罚俸 1，降职、外放 2，罢官、下狱、流放 3）；他那一派声量 −1 或 −2；上奏的人那一派 +1；两派积怨 +1 / +2 / +3；罢官以上，他的名望 −1 | 被弹劾的人对上奏的人记怨 1；上奏的人那一派 −1；两派积怨 +1。查实是诬告（`--false`）：**反坐**，上奏的人受他所请的处分，对方记怨 3，那一派再 −1，两派积怨 +3，上奏的人名望 −2 |
| 举荐 | 被举荐的人任职（原任的人去职，GM 另行安置）；他对举荐的人记恩 2；原任和新任分属两派的，两派积怨 +1；举荐本派的人得准，本派 +1 | 被举荐的人仍记举荐的人一份情（恩 1） |
| 提议 | 议题定下；主张正合的派 +1；底线被破的派 −1，和上奏的人那一派积怨 +2，首领对上奏的人记怨 2 | 上奏一派最看重（weight 3）的事被驳，那一派 −1 |
| 请辞 | 致仕，原职出缺 | 挽留：上奏的人记定夺者一份情（恩 1） |

- **留中**：什么都不改；上奏的人心里不痛快，有人格卡的，GM 可记心结 1（“奏疏留中不发”）。
- **折中**：GM 照定夺者的原话，用 `appoint`、`remove`、`faction --voice-delta`、`feud` 逐项记。
- 被处分的人有人格卡的，脚本打印建议的心结（对定夺者、所事之人的账；对上奏的人的怨已经记在关系网，不再加 `--toward`）；罢官、下狱的，季末 `court.py season --trigger 名=罢官下狱`（下狱的再加“性命之危”）。
- **群议和定夺相左**：定夺者不顾群议强行定夺，GM 可以给输的一方首领记一条心结 1（“圣意独断”），写进 GM 备注。这不是自动的，看定夺者怎么说、输的一方是什么样的人。

## 五、党争

两派之间的积怨记在 `feuds["甲派|乙派"]`，一条一条，每条有时间、事由、强度（1–3）。来处：朝议的后果（第四节自动记）、GM 手记（`court.py feud 甲派 乙派 --what … --strength N`）。

### 阶梯

五步：**相安 → 龃龉 → 攻讦 → 罗织 → 死斗**。

```
积怨 = 未了的积怨强度合计
```

| 积怨 | 账面 |
|---|---|
| 小于 2 | 相安 |
| 2–3 | 龃龉 |
| 4–6 | 攻讦 |
| 7–9 | 罗织 |
| 10 以上 | 死斗 |

封顶，要有来由：

- 到“罗织”，两派的人之间得有**私仇**：关系网里一派的某人对另一派的某人记着 ≥2 的怨。没有私仇，最多“攻讦”。
- 到“死斗”，积怨里还得有一条强度 3 的（出过罢官、下狱、流放、诬告反坐这一级的事）。没有，最多“罗织”。

每季（`court.py season`）最多走一步，升降一样。积怨的时间：强度 1 的四季无事就淡了，强度 2 的八季降为 1，强度 3 的不会自己淡。

### 每一步能做什么

`courtier` agent 收到这一步的上限（`court.py hint`），不能超出：

| 一步 | 上限 | 可观察的迹象 |
|---|---|---|
| 相安 | 就事论事：朝议上可以反对对方的主张，不攻击对方的人 | 议事时各说各的 |
| 龃龉 | 议事时讥讽、私下说对方的不是、不附议对方的人；不上弹章 | 话里带刺；两派的人宴集不再互请 |
| 攻讦 | 上奏弹劾对方的人（要有实据，或者照例风闻奏事），朝议上当众驳斥；不捏造罪名 | 弹章一道接一道 |
| 罗织 | 翻旧账、收买对方门下的人作证、借流言造势、把小过说成大罪；捏造的罪名要登记成一条秘密 | 有人在翻对方的旧案；市井里出了来路不明的怪话 |
| 死斗 | 图谋让对方的人下狱、流放、抄家，勾结宫中、外戚、禁军；行刺另走 `household.py plot` 的办法 | 有人下了狱；禁军换防不照常例 |

### 代价

- **弹章被驳**：上奏的那一派声量 −1，对方记怨，两派积怨 +1（第四节）。
- **捏造罪名**（`memorial --fabricated`）：GM 同时登记一条秘密“某某构陷某某”（`secrets.py add`，上奏的人全知，经手的人各按所知），它和别的秘密一样每季掷泄露。一旦查实（秘密泄了、证据呈上），照“诬告反坐”结算：`decide … --ruling 驳 --false`，或者已经准了的，GM 用 `remove`、`appoint` 给被构陷的人平反，再记反坐。
- 斗得越深，两派的人越难在别的事上互相附议（第四节“斗到第 N 步 −0.75 × N”）。

## 六、仕途：小人物

主角若只是朝中的一个小官（`scenario.json` 的 `player.role` 为“臣子”），他的官职、上司、差事、升降记在 `careers` 里。别的小官也可以照样记。

### 器重

上司对他的看重，−3..+3：

| 器重 | 说法 |
|---|---|
| −3 | 厌弃 |
| −2 | 不喜 |
| −1 | 冷淡 |
| 0 | 寻常 |
| +1 | 看重 |
| +2 | 器重 |
| +3 | 倚为心腹 |

这是人心账本反过来记：不是他对上司的心，是上司对他的。每一次升降都写来由（`regard 名 --event … --why …`）：

| 事 | 器重 | 另记 |
|---|---|---|
| 办成差事 | +1 | 考绩 +1 |
| 办得出色 | +2 | 考绩 +2 |
| 办砸 | −1 | 考绩 −1 |
| 误事（连累上司） | −2 | 考绩 −2 |
| 越级上奏（`--bypass`），没准、或者准了但上司那一派没附议 | −1 | |
| 当众顶撞上司 | −1 | 上司对他记怨 1（`relations.py event 羞辱 --strength 1`） |
| 替上司担了干系 | +1 | 上司欠他一份情（`relations.py event 援手`） |
| 出的主意被采纳 | +1 | |
| 和上司的政敌走得近（上司知道的） | −1 | |
| 弹劾上司那一派的人 | −1 | |
| 所奏得准 | | 考绩 +1 |

### 仕途阶梯

有的仕途不是一个个官职，是一条一阶一阶往上走的路：流外的小吏、卫里的骑卒（例（长安夜）：骑卒 → 队副 → 队正 → 执戟 → 司戈 → 中候 → 司阶 → 郎将……）。
这样的路写在 `court.json` 的 `ladders` 里：

```json
"ladders": {"金吾卫": {"unit": "贯", "rungs": [
  {"post": "骑卒", "rank": null, "pay": 2.4, "duty": "随队巡街、守夜、救火、拿人"},
  {"post": "执戟", "rank": 9, "rank_name": "正九品下", "pay": 7.5},
  {"post": "左金吾将军", "rank": 3, "pay": 60, "office": true}]}}
```

- 每阶：`post` 职名；`rank` 品级（流外写 `null`）；`pay` 每季俸钱（剧本的大单位，可以带小数；不写就按下面的品级表）；`duty` 管什么；`office: true` 的阶在官职表里只有一个位子（升到这一阶要占那个位子，原任的人去职）。
- 走这条路的人，仕途记录里写 `ladder`（`career 名 --ladder 阶梯名`），`post` 是他眼下在哪一阶。
- 升降：`promote 名 --why …`（升一阶）、`--down`（降一阶）、`--to 某阶`（跳到某一阶）。升到 `office` 的阶自动 `appoint`。考课“上考”时，`season` 会打印阶梯上的下一阶。
- 升阶多半要有人开口：上司举荐、立了功有人报上去；脚本打印关系网的建议（`relations.py event 提携`），GM 照实记。
- `court.py ladder` 看各阶和谁在哪一阶；`show --person 名` 看他眼下在哪一阶、再往上是什么、每季俸钱。

差事用 `career 名 --duty "…" --due 回合` 交下去，到期用 `duty 名 --result 上|中|下|误事 --what …` 回报，脚本一并改考绩和器重。

### 考课

每 `review_every` 季（默认 4）考课一次（`court.py season` 自动列出），看这一段的考绩和眼下的器重：

| 考绩 | 器重 | 结果 |
|---|---|---|
| ≥3 | ≥ +1 | 上考：可升一阶。上司愿意举荐（`memorial --kind 举荐`），或照资叙迁（`appoint`） |
| ≥3 | ≤ 0 | 功劳够了，上司不报：要升，得另找门路（`relations.py path`） |
| ≤ −2，或器重 ≤ −2 | | 下考：左迁、外放（`remove --status 外放`），GM 照上司的意思定 |
| 其余 | | 中考：照旧 |

考完考绩归零，重新计。升迁本身照常走朝议（举荐）或 `appoint`，不是考课自动给的。

### 俸禄

主角不是一方之主时，不跑 `economy.py`，`kingdom.json` 的 treasury 记的是他自家的钱粮。每季俸禄按品级（钱，单位照剧本的 `money_unit`）：

| 品 | 一 | 二 | 三 | 四 | 五 | 六 | 七 | 八 | 九 |
|---|---|---|---|---|---|---|---|---|---|
| 每季 | 600 | 450 | 330 | 240 | 170 | 120 | 80 | 55 | 40 |

`court.py season --pay --apply` 发主角的俸禄：记了仕途阶梯的照阶梯上的 `pay`，否则照上表。存档里有 `world/purse.json`（个人钱物，`rules/purse.md`）的，俸禄进主角的随身钱，罚俸照扣，和 `purse.py season` 不重复发；没有的，记进 `kingdom.json` 的家财。
吃喝、打点、送礼、借贷、马料这些个人的进出，记在 `purse.json`（`scripts/purse.py`）；没有它的旧存档，GM 直接改 treasury，写进史书。剧本可以在自己的 `rules/` 里另定俸禄和物价。

## 七、朝臣的心迹

没有兵权的人——文臣、宦官、宫人、皇子、公主、后妃、外戚、宗室——用**朝臣卡**（模板 `characters/_template_courtier.md`，身份写上面这几种之一），由 `courtier` agent 扮演。
不在朝、又要拿主意的人也用朝臣卡，身份写：**使节**（在京的外邦使者）、**外臣**（外邦的官）、**僧道**（和尚、道士）、**布衣**（不在官、不在宫的人：商人、老兵、闺秀、乐伎；细作的明面身份也算）。他们的心迹一样由 `court.py season` 推进；“所事之人”写他眼里的上面（使节的君主、寺院的施主、东家）。
账本和家人卡一样：需求、心结、牵扯（外头的拉拢、许诺、要挟），没有开价。心结记的是对他所事之人（天子、上司、所侍奉的皇子）的账；对同僚、政敌的怨记在关系网。

皇子的需求可以有“储位”，后妃有“母家体面”“子嗣前程”，朝臣有“相位”“清名”“所主张的事办成”。

### 心迹阶梯

四级：**恭谨 → 怠慢 → 怨望 → 异志**。为什么照家人的四级而不照将领的六级：朝臣手里没有兵，“留后路、暗通、举事”分不出那么细；他走远，是先怠慢下来，再有怨，最后各自盘算。

每季末（`court.py season`）：

```
怨望分 = 未解心结总强度 + 需求缺口（Σ 权重 × (3 − 满足) ÷ 3）
```

| 怨望分 | 账面 |
|---|---|
| 小于 4 | 恭谨 |
| 4–6 | 怠慢 |
| 6–8 | 怨望 |
| 8 以上 | 异志 |

封顶：没有未解的心结，最多“怠慢”；有心结，最多“怨望”；未解心结 ≥3，**并且**卡上有牵扯、或本季出了触发事件，才能到“异志”。每季最多走一级。

触发事件（`season --trigger 名=事件`）：

| 事件 | 说明 |
|---|---|
| 性命之危 | 被拘审、将被问罪处死，或确知上面要他的命 |
| 罢官下狱 | 被罢官、下狱、流放 |
| 储位被夺 | 已有的储位、许下的名分被夺（皇子、母妃） |
| 当众受辱 | 当着百官、宫人的面被斥辱、责打 |
| 至亲受害 | 至亲因上面的处置被囚、被杀、被逐 |

### 每一级能做什么

| 级别 | 行动上限 | 可观察的迹象 |
|---|---|---|
| 恭谨 | 尽心办事，有话直说或婉言进谏；不和外人私议上面的不是 | 没有异样 |
| 怠慢 | 照章办事，不多出主意，奏对简短；不在外头说上面的不是 | 奏对简短；该上的条陈迟迟不上 |
| 怨望 | 私下发牢骚、称病不朝、议事时顶撞、拖着不办、向亲近的人诉苦；不结外援，不递禁中的消息出去 | 称病不朝；门下的人说他叹过气、摔过东西；和失意的旧人走动多了 |
| 异志 | 私下结党、联络外援（皇子、外藩、敌国、别的派系）、递消息、为自己安排后路；手里有兵或外援接应、又出了触发事件的，可以谋废立、宫变，GM 照兵变的规矩结算。不行刺 | 府上夜里有生面孔；和某位皇子、某个外镇书信往来勤了；家眷细软往别处挪 |

**理由校验**和将领一样（`rules/loyalty.md` 第七节）：`courtier` agent 要做“异志”一级的事，“私下盘算”里得引用未解的心结编号，说清外头是谁（牵扯）或本季出了什么事（触发）。
行动超出心迹这一级、或者超出党争这一步的上限，引用不成立的，GM 驳回，改按能做的最高一档结算，驳回记进 GM 备注。

他手里有了兵（领了禁军、出镇一方），把朝臣卡改成将领卡，照 `rules/loyalty.md` 走六级离心阶梯。

## 八、玩家能看到什么

- **在场的朝议**：玩家在朝、有资格列班的，看得见谁附议谁反对、廷辩的经过、定夺的结果。看不见各人的分和理由，也看不见圣意。GM 写成白描：谁先出班、谁的脸色、谁一言不发。
- **不在场的**：只能经关系网里的熟人转述（他们按自己知道的说）、经流言（`rules/rumors.md`）、经邸报（定夺的结果是公开的）。
- `court.py season` 打印的“可以经旁人透露的迹象”，GM 择一两条，从关系网里找一个玩家熟的人带出来。
- 上司的器重，玩家看不到数字，只看到上司的态度：交给他的差事轻了重了、议事时问不问他、考课时说了什么。

## 九、GM 每回合怎么做

1. **玩家下令时**：玩家要上奏，照玩家的原话 `memorial`，给论点分；越级的加 `--bypass`。玩家要拜访谁、托人引荐，先 `relations.py path`，再召那人的 agent。
   主角是臣子的，没有帅府的亲裁限额，改成每季亲自做的事有个数：上奏、拜访、密谈、托人、写要紧的信、自己起意的场景，太平季 3 件，事多的季（朝中出了大事、他在办急差）2 件（剧本可以在 `scenario.json` 的 `actions` 里改）；
   交下来的差事是本分，不占件数；家事另算（`rules/household.md` 第三节）。件数由 `scripts/actions.py` 记（`add`、`show`、`mode 事多`），场景收场时自动记（`rules/scene.md` 第五节）。超出的先和玩家商量哪几件放到下一季。
2. **调 agent 前**：每位要说话的朝臣跑 `court.py hint 名`（心迹、党争的上限、器重）和 `secrets.py brief 名 --with 在场的人`（情报包），一起写进 `courtier` agent 的 prompt。
3. **朝议**：本季要议的奏疏（玩家的、agent 们交上来的），逐道 `session`；有廷辩的，双方的原话打论点分。看过加 `--apply`。
4. **定夺**：把“各方意见汇总”和天子的情报包交给 `ruler` agent，照回复跑 `decide`，看过加 `--apply`。
5. **季末**：`court.py season [--trigger 名=事件] [--pay]`，看过加 `--apply`：党争走一步、声量向根基靠一步、朝臣的心迹走一步、仕途到期的差事和考课、俸禄。
6. **理由校验**：courtier agent 的行动超出上限的，照第七节驳回。

## 十、例（示例朝廷，草稿副本试验）

三派：法度派（中书令裴衡领，声量 6）、寒门（中书侍郎张籍领，声量 4）、将门（枢密使郭崇领，声量 5）。户部尚书崔琰是皇后之兄，在将门。
主角沈砚是监察御史（八品），上司是御史中丞杜牧之（寒门）。沈砚手里有东郡漕仓的出入簿（`secrets.py` 的证据 E2），越过杜牧之上奏弹劾崔琰，请罢官，论点分 +1。

```
--- 各方初议 ---
  法度派（裴衡领，声量 6）  附议  分 +2.0：奏疏说得在理 +1；有凭据 1 件 +1
  寒门（张籍领，声量 4）    附议  分 +3.4：张籍看崔琰疏（-2）+1.4；奏疏说得在理 +1；有凭据 1 件 +1
  将门（郭崇领，声量 5）    反对  分 -2.7：崔琰是本派的人 -4；郭崇看崔琰亲（+1）-0.7；奏疏说得在理 +1；有凭据 1 件 +1
--- 廷辩：沈砚 对 崔琰 ---
  结果：各执一词，沈砚略占上风
--- 各方意见汇总 ---
  附议：法度派（裴衡）、寒门（张籍）；反对：将门（郭崇）
  朝议所向：附议约占67%，反对约占33%。
```

天子（`ruler` agent）定夺：准，但改罢官为外放（“崔卿掌漕不谨，出为东郡刺史，戴罪自效”）。`decide M1 --ruling 准 --penalty 外放 --where 东郡`：

```
  · 崔琰 外放
  · 崔琰 记 沈砚 一笔怨（2）
  · 将门 声量 −1
  · 越级上奏得准，杜牧之那一派也附议了：面上不说，器重不变
  · 沈砚 考绩 +1（所奏得准）
```

后来郭崇弹劾张籍（驳回，两派积怨 +1），张籍反手弹劾兵部侍郎韩延寿，当殿把郭崇驳得拂袖而去（恼羞成怒），弹章得准，两派积怨再 +2。
积怨 3、郭崇和张籍互相记着 ≥2 的私仇：季末寒门与将门从“相安”走到“龃龉”。再积到 7，才可能到“罗织”。
