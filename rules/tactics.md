# 亲临指挥（战术模式）

玩家亲自到阵前指挥的仗，用 `scripts/tactical.py` 一刻一刻地打。托管的仗照旧用 `scripts/resolve_battle.py`（见 combat.md）。
两个脚本互不依赖。战术模式的结果格式和宏观引擎相近，打完照样写回 `world/armies.json`。
本文的部队名、将领名取自唐末朔方剧本的示范战例（第九节），标作“例（唐末朔方）”；换了剧本照样适用。

什么时候用：玩家明说“我亲自去”“我要临阵指挥”，或者 GM 问过玩家、玩家同意。一季之内其他地方的仗仍然托管。

## 一、战场

```
            敌军（B）
   左翼          中军          右翼
 [后线]        [后线]        [后线]          ← B 的后线
 [前线]        [前线]        [前线]          ← B 的前线
   ↕ 间距        ↕ 间距        ↕ 间距         0 接战 / 1 一箭之地 / 2 相距一里
 [前线]        [前线]        [前线]          ← A 的前线
 [后线]        [后线]        [后线]          ← A 的后线
               [预备队]                       ← 在中军之后
            我军（A，玩家）
```

- 左、中、右三翼是**绝对方位**，按玩家（A 方）面向敌军时的左右来叫。敌军的“右翼”在战场上对着我军左翼，所以写进状态文件时都按我方的叫法。
- 每翼每方有前线、后线；中军后面有预备队。
- 每翼有一个**间距**（gap），是两军前线之间的距离：0 接战，1 一箭之地，2 相距一里。
- 绕出去的部队站在敌军某翼的**侧翼**（flank）或**背后**（rear）位置。

### 地形要素（每翼可以有几个）

| 要素 | 写法 | 效果 |
|---|---|---|
| 河 | `{"type": "river"}` | 正面冲击 ×0.5；两军在河中接战时，涉水前进的一方阵形降一级 |
| 林 | `{"type": "forest"}` | 冲击 ×0.5，骑兵近战 ×0.7，射击 ×0.6；适合藏伏兵 |
| 高地 | `{"type": "hill", "holder": "B"}` | 据守方：近战 ×1.15、射击 ×1.15；敌方正面仰攻冲击 ×0.7 |
| 营垒 | `{"type": "camp", "holder": "B"}` | 据守方前线：受正面冲击 ×0.35，近战 ×1.3，中箭 ×0.6 |
| 雾 | `"weather": {"fog": true}` | 射击 ×0.6；双方只看得见近处（见下“迷雾”） |

## 二、部队

每支部队一行，属性如下：

| 属性 | 说明 |
|---|---|
| `id` | 部队名，命令里用它指代，不能重名 |
| `side` | A 或 B |
| `type` | 兵种，见下表；也可写 `cavalry`、`轻骑`、`枪步` 等别名 |
| `men` | 人数 |
| `morale` | 士气 0–100 |
| `fatigue` | 疲劳 0–100，70 以上不能冲击 |
| `formation` | 阵形：严整 / 松动 / 混乱 / 溃散 |
| `facing` | 朝向：正面（默认）/ 侧面 / 背后 |
| `sector`、`line` | 位置：左/中/右；front/back/reserve/flank/rear |
| `leader` | 统兵将领，名字要在 `sides.X.leaders` 里，带统率、武勇 |
| `standing` | 常令，见下 |
| `hidden` | 伏兵，敌方看不见，直到它出手 |
| `army_code` | 写回存档时算作哪个兵种代码，默认见下表 |
| `armor` | 护甲：`none` 无甲、`light` 皮甲、`heavy` 铁甲、`barded` 人马俱甲；不写用下表默认 |
| `drill` | 操练：`raw` 新募、`regular` 堪战、`elite` 精锐；不写时民兵是新募，其余堪战 |

|---|---|---|---|---|---|---|---|---|---|---|---|
| 枪步 | spear | 1.0 | 0.6 | 2.2 / 1.1 / 0.5 | — | 1.0 | 皮甲 | 0.2 | 1 | 0.4 | infantry |
| 刀盾 | shield | 1.25 | 0.8 | 1.5 / 0.9 / 0.45 | — | 0.6 | 皮甲 | 0.15 | 1 | 0.5 | infantry |
| 步卒（混编） | infantry | 1.1 | 0.7 | 1.8 / 1.0 / 0.5 | — | 0.8 | 皮甲 | 0.15 | 1 | 0.45 | infantry |
| 弓手 | archer | 0.5 | 0.3 | 0.6 / 0.4 / 0.25 | 1.0，射程 1 | 1.0 | 无甲 | 0 | 1 | 0.4 | archer |
| 弩手 | crossbow | 0.5 | 0.3 | 0.6 / 0.4 / 0.25 | 1.15，射程 2 | 1.0 | 无甲 | 箭 0.3 | 1 | 0.4 | archer |
| 民兵 | militia | 0.6 | 0.4 | 1.2 / 0.6 / 0.3 | — | 1.1 | 无甲 | 0 | 1 | 0.4 | militia |
| 轻骑 | light_cav | 0.9 | 1.4 | 0.9 / 0.7 / 0.4 | — | 0.8 | 皮甲 | 0.15 | 2 | 1.6 | cavalry |
| 具装 | heavy_cav | 1.4 | 2.0 | 1.4 / 1.0 / 0.6 | — | 0.3 | 人马俱甲 | 0.5 | 1 | 1.0 | cavalry |
| 骑射 | horse_archer | 0.6 | 0.9 | 0.6 / 0.5 / 0.3 | 0.8，射程 1 | 0.4 | 皮甲 | 0 | 2 | 1.3 | cavalry |

- “中箭”是默认护甲下挨弓箭的系数，已经算进了甲（具装从旧版的 0.45 降到 0.3）。骑射的 0.4 主要是散得开，不是甲厚。

- 民兵士气检定的门槛高 10 点，容易跟着别人溃。

### 护甲与操练

和宏观引擎（`rules/combat.md`“伤亡”）用同一张护甲表：

| 甲 | 挡近战（透进几成） | 挡箭（透进几成） |
|---|---|---|
| 无甲 | 1.0 | 1.0 |
| 皮甲 | 0.8 | 0.75 |
| 铁甲 | 0.55 | 0.4 |
| 人马俱甲 | 0.4 | 0.25 |

```
透甲 = [1 − (1 − 甲的透进值) × (1 − 攻方破甲)] ÷ 攻方打皮甲时的同一个值
伤亡修正(攻方打目标) = 透甲 × 攻方操练杀伤 × 目标操练受创
```

- 冲击、射击、近战、追击造成的伤亡都乘这个修正（追击只乘攻方操练杀伤）。
  “中箭”一栏是按默认护甲折好的；部队改了护甲，按新旧两档透甲的比值调整。
- 几个数：弓射人马俱甲是射皮甲的 0.33，射铁甲 0.53；弩破甲，射人马俱甲 0.58、射铁甲 0.70；
  刀枪砍人马俱甲 0.6 上下（旧版“打具装 ×0.7”并进来了）；具装的骨朵、铁锏打具装 0.78。
- 操练：

  | 操练 | 有效战力 | 杀伤 | 受创 | 溃散门槛 |
  |---|---|---|---|---|
  | 新募 | ×0.9 | ×0.85 | ×1.15 | +5 |
  | 堪战 | ×1.0 | ×1.0 | ×1.0 | 0 |
  | 精锐 | ×1.1 | ×1.15 | ×0.85 | −5 |

  有效战力、溃散门槛按和兵种默认的差算：民兵默认就是新募，写 `raw` 不再额外打折。有效战力也乘在抗冲力上，精锐的枪阵更难冲动。
- 存档里目前只有 infantry、cavalry、archer、militia 四种，所以默认都折回这四种。存档里真有 `spear`、`heavy_cavalry` 这些新代码时，在部队上写明 `army_code`。

### 有效战力

```
有效战力 = 人数/1000 × 阵形系数 × 疲劳系数 × 士气系数 × 统帅系数 × 操练系数
阵形系数：严整 1.0，松动 0.8，混乱 0.55，溃散 0.2
疲劳系数：1 − 疲劳/200（最低 0.5）
士气系数：0.5 + 士气/160（士气 80 时为 1.0）
统帅系数：1 + (统率 − 5) × 0.04；将领负伤后不计
```

### 受击方向

- 从敌军前方打来是**正面**；从侧翼位置打来是**侧面**；从背后位置打来是**背后**。
- 方向系数：正面 1.0，侧面 1.6，背后 2.2（乘在冲击、近战上）。
- 侧面、背后受冲时，抗冲力最多只有 0.6（侧面）、0.4（背后），而且只算靠近的那一截人（人数不超过来冲的人数）。
- **转向**：部队可以下令转向侧面或背后。转过去以后，那个方向来的攻击算正面，原来正面来的攻击反倒算侧面。
  千人以上的严整步阵转向，阵形降为松动；正在接战时转向，也降一级。

## 三、命令

每刻双方同时下令，写成 JSON。没有下令的部队按常令行事，常令默认是坚守。例（唐末朔方）：

```json
{
  "A": [
    {"unit": "左厢轻骑", "order": "charge", "target": "枪阵乙"},
    {"unit": "薛崇牙骑", "order": "flank", "sector": "左"},
    {"unit": "右厢骑射", "order": "shoot", "target": "刀盾营", "standing": "charge_if_loose"}
  ],
  "B": [{"unit": "枪阵乙", "order": "face", "dir": "侧面"}]
}
```

`unit` 写“全军”表示这一方所有在场部队。命令也可以写中文。

| 命令 | 中文 | 说明 |
|---|---|---|
| advance | 前进 | 后线 → 前线；前线部队前进时，本翼间距减 1 |
| charge | 冲击 | 冲 `target`。正面冲击要求间距：轻骑 ≤ 2，其他 ≤ 1；侧翼、背后位置的部队随时可冲。混乱或疲劳 70 以上不能冲 |
| attack | 接战 | 间距 1 时逼上去接战；后线、预备队、侧后的部队用它打进入本方侧后的敌军 |
| shoot | 射击 | 弓弩、骑射射击。后线弓弩隔着本方前线射，打七折；弩能在间距 2 射，打六折 |
| hold | 坚守 | 原地不动；接战中照常厮杀；不接战时疲劳 −5，松动的阵形有一半机会恢复严整 |
| flank | 绕侧 | 骑兵（速度 2）当刻绕到 `sector` 翼敌阵侧翼；具装、步兵要走一刻。`"to": "rear"` 是从侧翼再绕到背后。中军只有在敌军某一翼前线空了时才绕得过去 |
| face | 转向 | `"dir": "侧面"` 或 `"背后"`、`"正面"` |
| withdraw | 撤回 | 前线 → 后线；侧后 → 本阵后线。步兵在接战中撤，伤 2%、阵形降一级；骑兵撤得干净 |
| rally | 回整 | 不接战、本刻没挨打时，阵形升一级，疲劳 −20；溃散的部队要碰运气 |
| commit | 投入 | 预备队投入某翼（`sector`，`line` 默认 back） |
| move | 移动 | 换翼、换线。步兵一刻只能挪到相邻一翼 |
| pursue | 追击 | 追杀溃兵。骑兵能追到别的翼 |
| retreat | 撤出 | 撤出战场。前线要先退到后线，下一刻才离场 |

### 常令

常令写在部队的 `standing` 上，或者在命令里带 `"standing": "..."` 修改。这一刻没有明令时按常令办：

| 常令 | 中文 | 行为 |
|---|---|---|
| hold | 坚守 | 默认 |
| shoot | 见敌即射 | 射程内有敌就射 |
| charge_if_loose | 见敌阵松动即冲 | 骑兵：够得着的敌军里有松动、混乱的就冲；有溃兵就追 |
| pursue | 见溃即追 | 附近有溃兵就追 |

常令是把将领的性子落到数字上的办法，见下面“将领的自主性”。

## 四、每刻的结算顺序

1. **移动**：前进、撤回、换位、绕侧、转向、投入预备队。上一刻在路上的部队到位。
2. **射击**：所有射击同时结算。
3. **冲击**：所有冲击按本阶段开始时的状态算出冲击比，再一起生效。
4. **近战**：接战中的前线部队互相厮杀；下了“接战”令的后队、侧后部队动手。
5. **追击**。
6. **士气**：检定溃散，处理连锁。
7. **恢复**：回整、疲劳变化、溃兵后撤。

### 射击

```
杀伤 = 40 × 射手有效战力 × 射击值 × 目标中箭系数 × 护甲操练修正 × 阵形密度 × 修正 × 随机(0.8–1.2)
阵形密度：严整 1.2，松动 1.0，混乱 0.9，溃散 0.8
```

- 修正：林 ×0.6，雾 ×0.6，据高地射 ×1.15，射营垒里的前线 ×0.6；**弩射骑射 ×1.5，骑射射弩手 ×0.6**；被敌军近身时射击 ×0.4。
- 士气损失 = 伤亡百分比 × 80 + 1。
- 射松阵形：严整的目标有 (0.1 + 伤亡比例 × 6) 的机会降为松动；松动的有 伤亡比例 × 4 的机会降为混乱；骑兵目标只有三成机会；上限 60%。
- 一千弩手射一千严整枪步，一刻大约杀伤四五十人，四成机会把它射松；同样的箭射骑射，杀伤不到一半。

### 冲击

```
冲击力 = 有效战力 × 冲击值 × 方向系数 × 地形修正
抗冲力 = 人数/1000 × 抗冲值 × 疲劳系数 × 士气系数 × 统帅系数 × 操练系数
冲击比 = 冲击力 ÷ 抗冲力 × (正面时再乘 √(守方人数 ÷ 攻方人数)) × 随机(0.85–1.15)
```

正面冲击时，前排宽度有限，人多的一方只按人数比的平方根占便宜。伏兵首次出手，冲击比再 ×1.3，目标士气 −10，骑射来不及散开。

| 冲击比 | 结果 |
|---|---|
| ≥ 2.5 | 冲垮，目标当即溃散。目标伤 6%×比值（最多 25%），士气 −25；冲击方伤 2% |
| 1.5–2.5 | 冲垮，目标阵形混乱（已混乱的直接溃散）。伤亡同上 |
| 1.0–1.5 | 冲动：目标伤 5%，士气 −12，阵形降一级；冲击方伤 3%，阵形也降一级 |
| 0.75–1.0 | 相持：目标伤 2%；冲击方伤 4%，士气 −5，阵形降一级 |
| < 0.75 | 冲不动：目标伤 1%；冲击方伤 7%，士气 −12，阵形混乱 |

- 表里的伤亡百分比再乘护甲操练修正：目标的伤亡按“冲方打目标”，冲方的伤亡按“目标打冲方”。
  所以人马俱甲、精锐的具装冲垮敌阵时，自己只伤百分之一上下。相持、冲不动时，马撞在枪林上被扎倒，甲只挡得住一半：冲方伤亡改乘修正的平方根。
- 正面冲击没冲动的骑兵，自动退回本阵后线；侧后冲不动的留在原地，阵形混乱。
- 冲击后疲劳：骑兵 +30，具装 +40，步兵 +15。冲一次之后通常要回整一两刻才能再冲。
- 骑射被冲时会散开退走：轻骑有五成机会追上，具装两成，步兵追不上。骑射混乱、疲劳 70 以上，或者自己下了冲击、接战令时不会躲。

**几个参照（统率 5，士气 75 到 80）：**
- 一千轻骑正面冲一千严整枪步：冲击比约 0.65，冲不动，骑兵伤七十人左右，枪阵伤十人左右。
- 同一千轻骑冲**松动**的枪步：冲击比约 1.3，能冲动；再冲一次（对方已混乱）就冲垮。
- 七百轻骑从**侧面**冲一千五严整枪步：冲击比 3 以上，当即溃散。枪阵若先转向侧面，又变回冲不动。
- 一千轻骑冲没有掩护的弓手：必定冲乱或冲溃。
- 一千具装（精锐）冲**混乱**的步卒：当即冲垮，步卒伤五百上下（含随后的溃散），具装伤十人左右。
- 同一千具装正面冲一千严整枪步：冲击比 1 上下，多半相持，具装伤近三十人，是冲乱阵时的三倍。
- 一千弓手射一千具装，一刻杀伤十四人上下；射一千轻骑，近四十人。

### 近战

```
杀伤 = 35 × 有效战力 × 近战值 × 方向系数 × 修正 × 随机(0.8–1.2)
```

- 修正：据高地 ×1.15，守营垒的前线 ×1.3，林中骑兵 ×0.7，“前进”逼战 ×1.1，一边射一边被近身 ×0.5；再乘护甲操练修正（见第二节）。
- 士气损失 = 伤亡百分比 × 100，侧面再 −5，背后再 −10。
- 压力比（己方近战力 ÷ 对方近战力）> 1.5 时，对方有五成机会阵形降一级；> 1.0 时两成；从侧后打再加三成。
- 步兵逼向骑射，骑射退开，打不着。

### 追击

```
杀伤 = 150 × 人数/1000 × 疲劳、士气、统帅、操练系数 × 追击值 × 操练杀伤 × (从背后追 ×1.5) × 随机(0.8–1.2)
```

- 一次最多杀伤溃兵现有人数的 40%，其中四成算作生俘。
- 阵形不影响追击（追溃兵用不着阵形）。追击后疲劳：骑兵 +15，步兵 +10。
- 一千轻骑追一千溃兵，一刻杀俘两百四十人上下；一千步兵追，只有六十人上下。
- 溃兵的将领被骑兵追上，有 8% 被擒、4% 阵亡。

### 士气与溃散

- 本刻挨了打、或者阵形混乱的部队要检定：
  - 士气 ≤ 20：溃散。
  - 士气 < 40（民兵 < 50；精锐 −5，新募 +5）：溃散概率 = (门槛 − 士气) ÷ 门槛 × 0.8；阵形混乱再 +0.2；本刻挨了侧击、背击再 +0.2。
- **连锁**：一部溃散，同翼前后线的友军士气 −12，相邻翼的前线和（中军溃时）预备队 −8。
  之后士气低于 45（民兵 55；精锐、新募照上加减）的，按 (门槛 − 士气) ÷ 门槛 的概率跟着溃散（混乱再 +0.2），溃了的再往下牵连。
- **全军动摇**：一方伤亡加上在场溃兵超过开战时总兵力的一半，所有未溃部队士气 −10（只发生一次）。
- **溃兵**：每刻往后退一线（前线 → 后线 → 离场），每刻掉队 3%；离场时再逃散 20%，剩下的人算作生还，战后归队。
  溃兵本刻没挨打时可以下“回整”令收拢：成功率 25% + (统率 − 5) × 5%，不在前线再 +15%；成功后阵形混乱、士气 30。

### 将领

- 统兵将领加统帅系数。将领所在的部队冲击时，有 5% 负伤；冲垮敌阵时，有 3% ×(武勇 − 5) 的机会阵斩对方部队的将领（对方士气再 −15）。
- 将领状态（负伤、阵亡、被俘）记在 `sides.X.leaders`，战后写进人格卡和存档：负伤的用 `contest.py wound 名 --level 轻伤|重伤 --where 部位 --apply` 记伤势，逐季养（`rules/contest.md` 第六节）。
- `leaders` 里的 `统率`、`武勇` 取人格卡上的“统”“武”；带着重伤上阵的，开战时状态就写“负伤”。
- **阵前单挑**：开战前的，在初始战例的 `sides.X` 里写 `"morale_bonus": N`，`new` 时加到该方各部士气上；打到一半的，用 `morale` 命令（第八节）。数字和将领状态由 `contest.py` 给出。

## 五、迷雾与伏兵

- `show --view A` 只输出 A 方看得见的东西，给角色 agent 的 prompt 就用它。敌军人数只给约数（到百位），士气只给“高昂、尚可、动摇、低落”。
- 没有雾时，敌军前线、后线、侧后的部队都看得见；预备队只有本方有部队绕到敌军侧后时才看得见，否则只显示“后方另有一部人马”。
- 有雾时，只看得见：本方前线所在翼、间距 ≤ 1 的敌军前线；本方有部队绕到侧后的那一翼；绕到本方侧后的敌军。看不见的目标不能射。
- **伏兵**：部队写 `"hidden": true`，通常放在林中，或者直接放在敌军某翼的侧翼位置。敌方看不见、也打不着它，直到它前进、射击、冲击、接战。首次出手按突袭算（见冲击）。
- GM 自己用不带 `--view` 的 `show`，看到全部真实数字。

## 六、结束与写回

- 一方所有部队都溃散、覆灭或撤出战场，另一方胜。
- 到了日落（`sunset` 那一刻）还没分出胜负：哪一方能战的兵（未溃、在场）只剩开战时的 40% 以下，算败（都低于时比例低的败）；否则“日落收兵，胜负未分”。
- 战罢时还留在战场上的溃兵：胜方有骑兵，三成被俘；没有骑兵，一成被俘。

`report --json` 的结果（例（唐末朔方））：

```json
{"winner": "A", "outcome": "敌步军兵败撤出战场", "ticks": 8,
 "losses":    {"A": {"cavalry": 150}, "B": {"infantry": 675, "archer": 0, "militia": 0}},
 "remaining": {"A": {"cavalry": 1850, "infantry": 400}, "B": {"infantry": 2325, "archer": 900, "militia": 600}},
 "captured":  {"A": {"infantry": 159}, "B": {}},
 "morale_after": {"A": 72, "B": 61},
 "by_role": {"attacker": "A", "defender": "B"},
 "leaders": {"A": {"薛崇": "无恙", "折嗣宗": "负伤"}, "B": {}},
 "units": [...每支部队的明细...], "events": [...]}
```

- `losses` = 阵亡 + 被俘 + 逃散，按存档兵种代码汇总；`remaining` 包括逃出战场、战后归队的人；`captured` 是本方抓到的俘虏，按敌方兵种。
- 和 `resolve_battle.py` 的区别：双方用 A、B 而不是 attacker、defender（`by_role` 给出对应关系）；地区归属由 GM 按结果判定：胜方是攻方、败方兵败撤出或溃散的，攻方占领该地区。
- 战后士气：取 `morale_after`；胜方另加 5，败方按宏观规则再减 10 左右，由 GM 斟酌。
- 每刻的纪事都存在状态文件的 `log` 里，写史书时可以从头翻。

## 七、将领的自主性与 GM 流程

亲临指挥时，玩家下的是给**各翼将领**的命令，不是直接拨动每支部队。

1. **开战前**：GM 按两军兵力、地形写一份初始状态（照 `rules/tactics_example.json` 的格式），用 `new` 建立战场文件，例如 `saves/当前战斗.json`。它不是存档的一部分，打完写回存档后可以删掉，也可以留作史料。
   每支部队写明 `leader`，每翼的将领就是那一翼部队的统兵将领。
2. **每刻**：
   1. GM 用 `show` 给玩家看本方所见（`--view A`），玩家下令，可以下给某翼将领，也可以下给某支部队。
   2. GM 并行调用该刻有事可做的将领 agent（`general`）。prompt 里给：主公原话、该将领麾下部队、`show --view A` 里他那一翼和相邻翼的情况、命令格式。
      将领按性格解读：可能照办、可能变通，也可能自作主张。例（唐末朔方）：薛崇看见对面枪阵松动，没等军令就冲了；周延嗣接到冲击令，可能先射两轮再说。
      将领回复里的“行动”要换成本文件的命令 JSON。将领的性子也可以落成常令：薛崇的部队常令 `charge_if_loose`，谨慎的将领常令 `hold`。
   3. 敌方由 `ruler`（敌主亲临）或 `general`（敌将）下令，prompt 里只给 `show --view B` 的内容。伏兵、雾中看不见的东西不给。
   4. GM 把双方的实际命令合成一个 JSON，用 `turn` 结算，**不替玩家纠正将领的自作主张**。
   5. GM 把本刻纪事写成两三句战报给玩家。将领私下的盘算不说。
3. **省事的办法**：不必每刻都调用所有将领。玩家没有给某翼新命令、那一翼也没出新情况时，这一翼按上一刻的命令或常令继续。
   通常三五刻有一两次关键决断，调用 agent 就够了。
4. **战后**：用 `report --json` 的数字写回 `world/armies.json`、人格卡（将领负伤、阵亡），俘虏按惯例处置，战报写进史书。

将领 agent 的回复格式见 `.claude/agents/general.md` 的“亲临战阵时”一节。

## 八、命令行

```
python3 scripts/tactical.py new    --from rules/tactics_example.json --state 战场.json [--seed N]
python3 scripts/tactical.py show   --state 战场.json [--view A|B] [--json]
python3 scripts/tactical.py turn   --state 战场.json --orders 军令.json [--seed N] [--dry-run] [--json]
python3 scripts/tactical.py report --state 战场.json [--json]
python3 scripts/tactical.py morale --state 战场.json --side A --delta 10 [--leader 名=负伤|阵亡|被俘|无恙] [--why 阵前单挑]
```

- `turn` 读状态、结算一刻、写回状态文件；`--dry-run` 只演算不写回，可以先看看“如果这么下令会怎样”（GM 自用，不要拿来替玩家试错）。
- 随机数由 `seed` 和刻数决定，同样的状态、同样的命令，结果相同。`--seed` 改种子。
- `--orders -` 从标准输入读命令。
- `morale` 把一方在场各部的士气加减 N（夹在 0–100），可以顺带改将领状态，记进纪事；用于阵前单挑这类场外的事。

## 十、自检

改了战术或宏观规则，跑 `python3 scripts/test_combat.py`。它会检查：正面冲严整枪阵冲不动、冲松动枪阵冲得动、侧击能冲垮、转向后侧击失效、
骑兵追击远强于步兵、弩能射松步阵、弓箭射骑射效果差、弓手被近身就垮、骑射只能消耗、步兵追不上骑射、士气连锁、
具装精锐冲乱阵自损百分之一二、冲严整枪阵自损多得多、弓箭射具装打大折扣、示范战例能跑完；
宏观引擎查几条胜率关系，以及：具装冲没列阵的步卒胜方伤亡很小、败方过半，冲严整枪阵代价大增，重骑对冲两边都重，弓弩射重甲打折，隘口守方照旧占优。
