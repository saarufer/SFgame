# 长安城图（示意）

《长安夜》的地图，给玩家和 GM 查看。只是示意，不按比例；哪里挨着哪里，以 `world/map.json` 为准（下面的“相邻”一表就是从它抄的）。
场景里一步走得到的，是相邻的两处（`rules/scene.md`）。

- 朱雀大街把城分成两半：街东是**左街**（左金吾卫管），街西是**右街**。白玫在左街。
- ★ 是白玫常在的地方：平康坊北门的武候铺（李琰一队住这里），皇城里的金吾卫衙署。
- 李琰一队夜巡的地界：平康坊、崇仁坊、宣阳坊、东市。
- 闭门鼓（戌初）以后，城门、坊门都关；坊里能走，出坊上大街就是犯夜，有公事、文牒的除外。五更二点（寅正）开门。

## 远地

```
   西去                          甘州（回鹘可汗牙帐）
  金光门 ──── 凉州（河西没藏部）──┘
     │             │
     └── 成都      │
                   │
   北去            │
  开远门 ── 宁州 ── 灵州（朔方节度使，韩逊墓）
              │     │
              └──── 盐州（白家、盐池、祖父的坟）

   东去
  春明门 ── 灞桥 ──┬── 金陵（江南）
                   └── 契丹南京
```

- 远地只来消息、偶尔能去。盐州的家书走开远门 → 宁州 → 盐州这条路。
